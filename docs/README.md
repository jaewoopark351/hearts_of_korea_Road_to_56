## 문서 상태 규칙

- **현재 기준**: 이후 구현과 검토가 따라야 하는 규범 문서다.
- **특정 시점 스냅샷**: 기록 시각의 파일, 버전, 해시만 설명한다. Steam이 RT56을 갱신하면 새 기준선을 만든다.
- **결정 기록(ADR)**: 결론과 미결정 항목을 함께 보존한다. 결론이 바뀌면 기존 기록을 지우지 않고 후속 ADR로 대체한다.
- **사건 기록**: 관찰된 실행의 증거다. 수정 완료나 현재 상태를 자동으로 뜻하지 않는다.

## donor 문서 취급

사용자 제공 HOK donor의 C:\hoi\hearts_of_korea\docs 아래에는 standalone HOK/바닐라 1.19.2 복원 과정의 과거 문서가 있다. 해당 문서는 HOK의 의도와 변경 이력을 파악하는 읽기 전용 증거지만, RT56 대상의 현재 결론으로 자동 승격하지 않는다.

특히 donor의 지도 문서는 “바닐라 1.19.2 지도 + HOK 한국 변경”을 전제로 한다. 현재 포트는 “현재 RT56 지도 + 검토된 HOK 한국 delta”가 목표이므로 과거 파일이나 완료 판정을 그대로 복사하지 않는다.

## 기록 원칙

1. 개인 경로는 가능하면 README에 정의된 별칭을 사용한다.
2. 로그·덤프·세이브 원본은 커밋하지 않고 필요한 해시, 시각, 줄 번호와 짧은 발췌만 남긴다.
3. 확인 사실, 강하게 뒷받침되는 판단, 미확인 가설, 반증된 가설을 구분한다.
4. 구현 문서에는 RT56 source fingerprint, donor 출처, 적용 delta, 검증 결과를 기록한다.
5. 새 문서 링크를 README와 이 인덱스에 함께 추가한다.
