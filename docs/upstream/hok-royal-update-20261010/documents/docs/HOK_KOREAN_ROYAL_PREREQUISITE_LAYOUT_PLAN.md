# 왕정 중점 완료 조건과 환제국 물자 가지 배치 계획

작성: 2026-10-10. 상태: **왕정 18개 중점 코드 적용 / 연락망 유지 기준·물자 가지 좌표 확정 / 정적·새 게임 로드·초기 SHOW/HIDE 일부 UI 확인 / 정상 진행 검증 대기**.

연결선 밖의 완료 조건을 정리하고, 환제국의 물자행정 가지를 실제 선행 중점 가까이 옮겼다. 완료 조건을 삭제한 대상은 사진에 나온 14개 중점이며, 선행 교체와 위치 이동은 별도의 물자 가지 4개 중점이다. 총 18개 기존 중점을 수정했고 새 중점이나 보상은 추가하지 않았다. 최초 요청에서는 문서화만 진행했으며, 이후 사용자의 구현 요청에 따라 아래 계약을 적용했다. 코드 적용과 실제 게임 동작의 검증은 구분한다.

## 기준 소스와 기존 구현

기준 브랜치는 `feat/korean-focus-expansion-ai`, HEAD는 `af6fccf2248311c01565c796555ed334ec685015`다. 최초 문서화 시작 시 작업 트리는 깨끗했고, 구현 시작 시에는 이 계획과 README·왕정 후속 명세·2차 계획의 문서 변경만 남아 있었다. [한국 중점 소스](../common/national_focus/korea.txt)의 구현 전 SHA-256은 `e2c2e7b028d8d6d922114c68474b7a569d2aa11cbcf109ca20a4168cacff47ca`이며 아래 조건 표의 행 번호는 이 기준 소스에 대응한다. 적용 소스 SHA-256은 `572c035b21a79d89f7e8fa55aee353f12b4230816cbfd491ff0667efc09ac007`다.

앞서 원료 광종분류의 두 선행 AND 연결과 수출거래 명세·국민 법률구조망·황실 공익후원·군정 실무편람·삼군 연락사무국의 지정 조건 삭제를 적용하고 커밋·푸시했다. 그 여섯 중점의 적용 및 검증 상태는 [기존 계획](HOK_KOREAN_FOCUS_PREREQUISITE_READABILITY_PLAN.md)과 [구현 기록](incidents/2026-10-10-korean-focus-prerequisite-readability.md)을 따른다. 이번 왕정 18개 구현은 그 작업과 별도이며, 이전 정적 검사·초기 UI 관측을 이번 변경 소스의 검증으로 재사용하지 않는다.

현재 왕정 계약과 배치는 [왕정 후속 명세](HOK_KOREAN_ROYAL_FOLLOWUP_SPEC.md)와 [좌표 데이터](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)를 기준으로 삼는다. [물자 가지 오른쪽 배치 기록](incidents/2026-09-23-hwan-focus-right.md)은 이전 위치의 이력이다. 구현 시작 환경은 설치본 HOI4 `1.19.3.0.c01a`, Steam build `25205862`, 플레이셋 `국뽕한국 test01`, 로컬 Hearts of Korea 단독 활성·한국어·활성 DLC 36개로 확인했다. Korean Language는 descriptor에 선언돼 있지만 별도 활성 모드 목록에는 없다. 이 환경 확인과 기존 체크섬 `92cd`는 적용 소스의 새 실행 검증 결과가 아니다.

### 구휼 군제 기술관료 10개의 진행 변경

A2·A3·A4의 시작 선행은 우리황실사랑회 `KOR_urihwangsilsaranghoe`로 유지한다. 구휼과 기술관료는 현재 직렬 연결을 유지하며, 군제는 연대 병적대조에서 하사관 실무교육과 예비 간부명부로 갈라진 뒤 두 중점 모두를 요구하는 동원체계 종합연습으로 합류한다.

별도 완료 조건을 제거해 성리학 질서 재건·비변사 부활·군제개혁 전에 해당 묶음에 진입할 수 있게 했다. 성리학 질서 재건은 현재 입헌군주정과 상호배타다(한국 중점 소스 8927~8930행). 따라서 이 구현은 대기 시간을 줄이는 것과 함께 비동맹 정부를 유지하는 다른 왕정 단계·경로의 접근 가능성도 넓히는 의도적인 진행 변경이다.

원래 한국 `original_tag = KOR`, 비동맹 정부, 내전 없음과 기존 취소·항복 규칙은 유지한다. [왕정 국민정신 소스](../common/ideas/HOK_KOR_royal_followup.txt)의 구휼 I·II, 군제 I·II, 기술관료 정신은 비동맹 정부 상실을 취소 조건으로 사용한다(35·48·61·74·88행). 삭제한 중점의 미완료를 별도로 검사하지 않으므로, 이번 완료 조건 삭제와 충돌하는 같은 중점 유지 조건은 발견되지 않았다. 실제 착수·취소·보상 유지 시점은 현재 소스 런타임 검증 대상이다.

### 연락망 4개의 접근과 국민정신 유지 기준

H2의 시작 선행은 우리황실사랑회를 유지하며 내부 구조는 공문부호 → 연락인계/통신기록 → 두 중점 모두 필요한 종합연습이다. 네 중점 모두 환제국의 부활 완료 조건을 제거했다. 원래 한국, 내전 없음, 독립국, 만주 운영 대상 8개 주 중 적어도 하나의 소유와 완전 통제 조건은 남는다. 대상 주는 716·745·328·717·714·761·715·610이다.

군정 연락인계는 `HOK_KOR_hw_courier_service_1`을 지급하고, 연락망 종합연습은 이를 `HOK_KOR_hw_courier_service_2`로 교체하거나 직접 지급한다. 구현 전 두 정신에는 환제국의 부활 미완료 시 취소하는 조건이 있었다(구현 전 왕정 국민정신 소스 127·140행). 형성 전부터 보상을 사용할 수 있도록 연락망 I·II에서 이 `cancel` 검사만 제거했다. 원래 한국의 `allowed`, `allowed_civil_war = { always = yes }`, `removal_cost = -1`, 그림과 모든 modifier 수치는 유지했으며 새 정부·독립·영토 취소 조건을 추가하지 않았다.

획득한 연락망은 환제국 형성 전에도 유지하는 계약으로 확정했다. 독립·영토·내전 조건은 중점의 착수·진행 조건이며, 이미 획득한 연락망 정신의 새로운 취소 조건으로 옮기지 않는다. 다른 여섯 환제국 국민정신의 형성 완료 유지 규칙은 그대로다. 연락망 I→II 교체·하위 부재 직접 지급과 실제 유지 시점은 런타임에서 별도 확인해야 한다.

## 환제국 물자 가지 4개의 선행 교체

물자 H1은 위 14개 완료 조건 삭제와 별도다. 환국 지방실사 시작의 선행을 **왕의 귀환 `KOR_return_of_the_king` → 환제국의 부활 `KOR_empire_of_hwan`**로 교체했다. 후속 중점의 연결과 내부 AND는 유지했다.

| 중점과 ID | 적용 선행 | 이전 기본 위치 → 적용 기본 위치 |
|---|---|---|
| 환국 지방실사 `HOK_KOR_hw_provincial_inventory` | 환제국의 부활 | (211,5) → (184,11) |
| 지방 물자관리 `HOK_KOR_hw_provision_accounts` | 환국 지방실사 | (210,6) → (183,12) |
| 제국 지방 순찰 `HOK_KOR_hw_inspection_circuits` | 환국 지방실사 | (212,6) → (185,12) |
| 물자 결산통일 `HOK_KOR_hw_supply_returns` | 지방 물자관리와 제국 지방 순찰 모두 | (211,7) → (184,13) |

네 중점 모두 `available`의 환제국의 부활 완료 검사를 유지했다. 시작 중점의 기존 실제 요구를 정식 연결선으로 드러내며, 원래 한국·내전 없음·독립국·영토 조건과 물자관리 국민정신의 유지 규칙도 보존했다. 후속 세 중점의 부모를 환제국으로 바꾸지 않았으므로 내부 진행 단계는 그대로다.

## 환제국 우측 하단에 적용한 배치

후속 위치 요청에 따라 H1 네 중점 전체를 **야뫼도 점령 가지 오른쪽, 형벌부대 도입 아래쪽 공간**으로 옮겼다. 환국 지방실사를 첫 줄, 물자관리와 지방 순찰을 가운데 줄, 결산통일을 마지막 줄에 둔 세 줄 구조를 유지한다. 오른쪽 상단의 이전 위치는 위 전후 좌표 표와 과거 구현 기록에 남긴다.

아래 주변 중점의 기본 위치는 보존했다.

| 주변 가지 | 현재 기본 절대 위치와 점유 범위 |
|---|---|
| 환제국의 부활 | (178,10) |
| 황하문명 정복 줄 | x176, y11~13 |
| 야뫼도 정복 줄 | x180, y11~13 |
| 형벌부대 도입 | (182,10) |
| 환 세계 질서 | (178,14) |
| 전후 복구 H3 / 장병 복귀 H4 | x176 / x180, y15~17 |
| 오른쪽 전제군주 정복 가지 | x188~192, y11~14 |

환국 지방실사는 환제국의 부활 기본 위치 (178,10)를 기준으로 상대 (6,1), 해석된 기본 위치 (184,11)이다. 묶음은 x183~185·y11~13에 배치했다. 사진의 빈 공간과 소스 좌표만으로 모든 표시 상태의 실제 간격을 확정하지 않는다. 기존 정복 줄·형벌부대·H3·H4·오른쪽 전제 가지와의 연결선·아이콘·명판 간격은 현재 소스의 실제 UI에서 확인해야 한다. 이전 오른쪽 배치의 정적·실행 결과를 새 위치의 검증 결과로 사용하지 않는다.

시작의 `relative_position_id`를 왕의 귀환에서 환제국의 부활로 바꾸고 상대값 (25,1)을 (6,1)로 재계산했다. 환제국은 시작 중점보다 먼저 선언돼 있으므로 선언 순서를 유지하며 참조한다. 부모와 배치 기준을 같은 중점으로 지정했지만 두 필드는 별개로 적용했다.

세 자식은 이미 환국 지방실사를 배치 기준으로 삼으며 상대값이 물자관리 (−1,1), 지방 순찰 (1,1), 결산통일 (0,2)이다. 이 상대값과 내부 선행을 유지하면 시작 위치에 따라 묶음 전체가 함께 이동한다. 선행과 위치 기준은 별도 필드이며, 시작의 부모 교체만으로 새 위치가 정해지지는 않는다.

왕정 HIDE 이동은 기존 기준 연쇄를 통해 −101x를 한 번 상속하며 y 이동은 추가하지 않았다. 왕정 경로 완료 후 HIDE에서 계산된 위치는 (83,11) → (82,12)/(84,12) → (83,13)이다. SHOW와 초기·진행 중 HIDE는 기본 위치를 유지한다. 실제 이동·숨김·선·클릭 영역은 표시 상태별 런타임 검증 대상이다. 자식 offset을 복제하거나 주변 가지를 숨기지 않았다.

## 적용 범위와 보존 계약

1. A2·A3·A4의 10개에서 지정 완료 검사 12회, H2의 4개에서 환제국 완료 검사 4회를 제거했다. 표시 부모·내부 선행·나머지 착수·취소·항복 조건은 보존했다.
2. H2 연락망 I·II의 환제국 미완료 취소 검사만 제거했다. 허용 범위·내전 허용·제거 비용·모든 효과 수치·I→II 교체와 다른 국민정신은 보존했다.
3. H1 시작 부모와 배치 기준을 환제국으로 교체하고 상대 (6,1)로 옮겼다. 자식 상대값과 내부 선행, 다른 456개 중점의 위치, 전체 offset·지속적 중점 패널·바로가기 계약은 보존했다.
4. 중점 ID·아이콘·35일 기간·보상·AI 가중치를 유지하고 실제 생산 텍스트 변경에 기여자 주석을 붙였다. 관련 명세와 후보·좌표 데이터도 적용 계약에 맞춰 동기화한다. 최초 구현 요청에는 커밋·푸시·업로드를 포함하지 않았다. 이후 사용자가 전체 커밋·푸시를 별도로 승인했으며 업로드는 여전히 범위 밖이다.

## 남은 런타임 검증

| 대상 | 현재 소스에서 확인할 내용 |
|---|---|
| A2·A3·A4 | 삭제 대상 중점 미완료 상태에서 남은 조건과 표시 부모를 만족하면 착수 가능. 비동맹 정부 상실·내전 시 차단/취소, 다른 왕정 경로의 접근 범위 확인 |
| 내부 진행 | 군제와 물자 가지의 가운데 두 중점 중 한쪽만 완료하면 마지막 중점 차단, 양쪽 완료 시 착수 가능 |
| H2 연락망 | 환제국 미완료 상태에서 남은 조건에 맞는 착수·정신 I·II 유지·교체, 하위 부재 직접 지급. 일회 경험치·연구 보상과 정신의 수명을 구분 |

| 표시 상태 | SHOW·초기 HIDE·경로 완료 HIDE, 기준 중점의 숨김과 조건부 이동, offset 단일 상속 |

최초 문서화 단계에서는 생산 코드·게임 실행 없이 계획과 관련 안내만 갱신했다. 이후 승인된 구현에서 중점 18개와 연락망 정신 2개를 수정했다. **현재 소스의 정적 검사·새 게임 로드·초기 SHOW/HIDE 일부 화면은 확인했고, 정상 착수·35일 완료·국민정신 유지·완료 후 SHOW/HIDE는 미검증이다.** 기존 검증 횟수·화면·체크섬을 이번 변경의 통과 결과로 합산하지 않는다. 위 구현·검증 단계에서는 스테이징·브랜치 변경·커밋·푸시·업로드를 수행하지 않았다. 이후 사용자가 전체 커밋·푸시를 별도로 승인했다.

## 현재 소스의 확인 결과

정적 검사 68/0과 독립 전체 토큰·후보·좌표 대조를 통과했다. 진단 스크립트 없이 별도 한국 새 게임을 열었고 체크섬은 `0dab`이다. 초기 HIDE에서 H1 네 중점·환제국 진입선과 주변 형벌/정복/복구 가지의 분리를 두 확대 수준에서 관측했다. 제국 공문부호의 환제국 완료 조건 삭제와 지방실사의 환제국 부모·미완료 차단도 표시에서 확인했다. 로그의 기존 고유 메시지 40개 대비 신규 정규화 오류는 0개이며, 이는 보존한 사용자 로그와의 비교다.

SHOW를 지정한 별도 새 게임에서도 H1 네 중점과 진입·분기·합류선의 분리를 확인했고 신규 정규화 오류 0개였다. 해당 SHOW 검증 게임은 종료했다. 자동 콘솔 입력이 열리지 않아 형성 전 긍정 착수·정신 유지와 정상 진행은 확인하지 못했다. 사용자의 기존 실행 게임은 보존했고 새 검증 게임은 일시정지해 수동 콘솔 입력 도움을 기다리는 상태다. 정확한 환경·증거·한계는 [현재 구현 기록](incidents/2026-10-10-korean-royal-prerequisites-layout.md)을 따른다. 이전 실행 결과를 현재 소스의 통과로 합산하지 않는다.
