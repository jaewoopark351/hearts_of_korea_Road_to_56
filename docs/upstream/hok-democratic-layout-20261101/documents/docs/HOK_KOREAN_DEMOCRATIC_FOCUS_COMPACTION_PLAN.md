작성일: 2026-10-31, 갱신일: 2026-11-01 (Asia/Seoul). 상태: **요청 범위의 배치 구현·핵심 검증·원복 완료 / 소스 보존 29/0 / HIDE 정상 전환·재로드·한정 합성 UI / 진단 없는 SHOW 정상 완료·위치 유지 관측**.

사용자는 민주주의 중점 화면 두 장을 제시하며 중점 사이의 거리를 줄이되 서로 겹치지 않게 해 달라고 요청했고, 처음에는 **“코드 수정하지 말고 설명만”**, **“문서화 작업만 진행”**으로 범위를 한정했다. 이후 전체 구현 방향을 제시하며 **“AGENTS.md, /docs 읽고 구현해줘”**라고 명시해 민주 구역의 배치 구현과 적절한 검증을 승인했다. 최초 문서화와 이후 구현을 아래에서 구분한다. 커밋·푸시·배포는 수행하지 않는다.

현재 적용 소스 SHA-256은 `6562d4acfd05f791026502a9aeace3668d3c89869df4279f75c2f1016763f163`다. 민주 95개 중 32개의 직접 배치 블록을 수정했고, 상대 기준 이동을 따라 기본 위치가 바뀐 중점은 86개다. 민주 범위는 x108~158에서 x113~151로, 중심 간 가로 폭은 50칸에서 38칸으로 **24% 감소**했다. y2~24와 전체 트리 범위는 유지했다. 실제 엔진 화면에서 모든 겹침이 없다는 판정은 아직 아니다. [구현·검증 기록](incidents/2026-10-31-korean-democratic-focus-compaction.md)을 따른다.

### 4.1 하위 묶음의 폭을 먼저 정한다

시민사회 13개는 구현 전 기본 x132~139/y6~12였고, 이번 적용 후에는 x131~138/y6~12다. 이 영역은 빈칸이 아니다. 기존 상선 추가 징발·영국 구축함 구매는 x140의 y11/y13에 있어 서방 외교를 당길 때 함께 검토한다. 이전 배치는 [시민사회 개정 기록 4절](HOK_KOREAN_CHAEBOL_CIVIL_SOCIETY_REVISION_PLAN.md#4-후속-가지와-민주주의-구역-배치), 적용 배치는 7절을 따른다.

각 묶음의 모든 자손·분기·합류가 차지하는 폭을 먼저 산정하고 묶음 사이 여백을 줄인다. 대통령 두 중점이나 외교 선택 두 중점만 먼저 붙인 뒤 아래쪽 가지가 서로 침범하게 만들지 않는다. 동일한 축소율을 모든 좌표에 적용하지 않는다.

### 4.2 가로·세로 간격과 선을 함께 조정한다

- 단순한 세로 직렬 구간은 불필요한 빈 행을 줄이는 후보로 삼는다. 여러 부모가 합류하거나 다른 선이 통과하는 행은 개별적으로 여백을 남긴다.
- 같은 행의 개별 중점 간격과 여러 중점을 포함한 하위 가지 간격을 구분한다. 과거에 x2 간격이 관측상 적합했던 사례를 모든 이름판·아이콘·배율의 안전한 최소값으로 일반화하지 않는다.
- 긴 한글 이름판, 아이콘 테두리와 진행/완료 광택, 잠김 표시와 상호배타 표식까지 포함해 실제 면적을 본다. 사용할 폰트·언어·GUI 배율과 트리 배율을 기록한다.
- 여러 부모를 가진 중점은 모든 선행선을 함께 본다. 한 연결만 짧게 만들고 다른 연결이 관계없는 중점을 통과하는 안은 채택하지 않는다.
- 실제 분기·합류의 공유 선은 유지한다. 관계없는 선이 같은 선처럼 겹치거나 이름판을 통과하는 사례와 구분한다. 선 교차 전부를 0으로 만들기 위해 진행 관계를 바꾸지 않는다.

### 4.3 상대 기준과 조건부 이동을 보존한다

`relative_position_id`는 배치 기준이고 `prerequisite`는 진행 조건이다. 예를 들어 정부 지원 강화는 배치상 자유당 단독집권을 참조하지만 실제 선행은 민주주의는 우리의 힘과 극단주의 금지의 AND다. 대한의용군단은 배치상 세계 속의 대한민국을 참조하지만 실제 선행은 서방/미국 외교 선택의 OR다. 배치 기준을 손보면서 이 진행 관계를 대체하지 않는다.

목표 기본 위치를 정한 뒤 `상대값 = 목표 기본 위치 - 해석된 기준 중점의 기본 위치`로 계산한다. 기준의 파일상 상대값을 기본 절대 위치로 오인하지 않는다. 참조 ID의 유일성·자기 참조·순환 부재·절대 기준까지의 연결과 **기준이 먼저 선언되는 순서**를 확인한다. 가능한 한 기존 기준 사슬과 선언 순서를 유지한다.

민주 진입의 기존 `HIDE + 진입 완료 → (-35,0)`을 내부 압축의 대용으로 바꾸지 않는다. 자손에 같은 offset을 추가해 두 번 움직이게 하지 않으며, 공화국 공통 진입의 노선별 이동도 그대로 취급한다. SHOW, 초기 HIDE, 민주 중점 진행 중에는 이 완료 조건에 따른 이동이 아직 없다는 점을 구분한다. 기준이 숨겨지거나 선택되지 않은 상태의 자손과, 보이지만 선택 불가능한 중점도 배치 검토에 포함한다.

## 5. 후속 구현 때의 검증 기준

다음은 구현·검증의 기준이다. 최초 문서화에서는 실행하지 않았고, 이후 소스·좌표 대조와 2026-11-01의 한정 HIDE/SHOW 관측을 수행했다. 실제 수행 범위는 6·8·9절과 구현 기록을 따르며, 아래 상태표 전체가 완료됐다는 뜻은 아니다. 단순 좌표 중복 검사나 조용한 로그만으로 시각 합격을 판정하지 않는다.

### 5.1 소스와 배치 자료 대조

후속 구현 전 현재 브랜치·HEAD·작업 트리와 실제 소스를 다시 고정한다. 변경한 배치 필드와 필요한 기여 주석 외에는 게임플레이 정의·반복 키·효과 순서를 보존하고, 이동하는 기준의 모든 자손 및 묶음 밖 연결을 목록화한다. 기본 위치와 조건별 최종 위치를 별도로 계산한다.

구현된 좌표가 확정된 뒤에만 [현재 좌표 명세](HOK_KOREAN_FOCUS_LAYOUT_COORDINATES.md)와 [좌표 JSON](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)을 갱신한다. 기록할 항목은 ID, 기존/변경 기준, 소스 x/y, 해석된 기본 위치, offset 담당과 조건별 최종 위치, 전후 묶음 폭·높이다. 이번 문서의 후보 간격을 적용 좌표처럼 기록하지 않는다.

외부 `runtime-review/independent-hide-runtime-review.json`의 **18/0**은 보관 선택 목록·체크포인트·단계 순서·로그 차이 등의 확인 수이며 게임플레이 시험 수가 아니다. 오류 행은 기준 **47→54→59**였다. 최초 비교에는 frontend 경고 9행 추가·기준 rename 2행 제거가 있고 후속에는 rename 5행이 추가됐다. 기존 다른 하위 시스템 경고와 중복 현지화도 남았다. 새 한국 중점·probe·상대 배치 등록 오류는 보관 error.log에서 발견하지 못했지만 전체 새 오류 0이라고 쓰지 않는다.

진단 없는 SHOW와 실제 원복·최종 Steam 정리 결과는 9절과 구현 기록에 남겼다. 시민 개혁·서방/미국의 합성 완료, 정상 시민사회 보상·영향력 패널, 모든 정치 노선/95개 아이콘 상태·장기 AI·다른 DLC/모드·멀티플레이/OOS는 위 HIDE 결과의 범위 밖이다.

## 9. 최종 진단 없는 SHOW 관측

설치본 PID **18640**, 체크섬 **7572**, 같은 1.19.4.1.99a5/DLC 36개에서 **Korean Language → 저장소** 두 모드만 선택해 전체 재시작했다. probe는 활성 목록과 실행 흔적에 없었고 규칙 창에서 SHOW를 명시적으로 선택했다. `runs/clean-show-paused/`는 1936.1.1.12 일시정지 새 게임의 보관본이다. 비교 기준 `control-full`은 HIDE 기본값이므로 두 실행의 규칙을 같다고 표현하지 않는다.

공화국 부모를 1936.1.1.12 실제 UI로 선택했다. 기본 7일이지만 팝업을 처음 알아본 시각은 1.19.6, 이후 멈춘 시각은 2.4.22다. 이는 관측 지연을 포함하며 부모가 1.19.6이나 2.4.22에 정확히 완료됐다는 뜻이 아니다. 2.4.22에는 비축 10이 있는 상태에서 기본 28일의 민주 진입을 실제 선택했다. 2.21.20에도 진행 중인 상태를 관측했고 3.8.2에 멈췄을 때 완료 팝업을 확인했다. 두 중점 모두 정상 선택·진행했지만 정확한 7일/28일 경과나 비축 없는 28회 적립을 입증하지 않는다.

`clean-show-root-active.png`와 `clean-show-after-root-same-camera.png`는 트리 배율 0.65·같은 카메라에서 상단 민주 기준과 두 대통령 위치가 그대로인 것을 보여준다. 이는 HIDE의 완료 뒤 일관된 이동과 구분되는 **해당 SHOW 상단의 이동 없음** 관측이다. 모든 95개 좌표·정치 전환의 픽셀 측정은 아니다. `clean-show-upper-full-width.png`·`clean-show-lower-full-width.png`에서는 최저 쪽 배율 약 0.2로 민주 상·하단 폭과 하단 잎 접근을 확인했다. 작은 이름판·개별 클릭·광택 전수 검사는 아니다. 속도 5의 디버그 화면에 `SLOW INTERFACE` 표시가 있어 이를 보존하며, 프레임 시간이나 비교 성능·원인은 측정하지 않았다.

보관 오류 행은 **기준 47→SHOW 최초 54→정상 진행 완료 확인 뒤 54→종료 뒤 56**이다. 최초 차이는 frontend 9행 추가·기준 종료 rename 2행 제거이며 벽시각만 제거해도 같은 차이다. 진행 중에는 error/text 추가·제거가 없었고 종료 때 `random.log` rename errno 2가 2행 추가됐다. 기존 오류는 남으며 새 중점·probe·상대 배치 등록 오류는 이 보관 로그에 없었다. 독립 최초 12/0·최종 17/0은 보관 자료 확인 수이고 HIDE 18/0이나 게임플레이 시험 수와 합산하지 않는다.

**정리 완료:** 네이티브 게임을 정상 종료하고 PID 18640 부재를 확인했다. 원복 도구의 실제 적용으로 `settings.txt`·`dlc_load.json`을 사전 해시와 정확히 일치시켰고, 외부 검증 사본을 남긴 뒤 전용 로더 3개·HIDE 시험 체크포인트만 프로필에서 제거했다. 고유 사용자 세션 보존 파일을 포함한 기준 저장 23개의 이름·크기·100ns 단위 수정 시각·해시가 모두 유지됐다. 모르는 파일은 보존했다.

Steam의 일반 Stop 뒤 Stopping이 남아 다른 게임/다운로드가 진행되지 않는 화면을 확인한 뒤 정상 종료·재시작했다. 새 라이브러리 화면 `clean-final-steam-play-restored.png`에서 HOI4의 초록색 플레이 버튼 복귀를 확인했다. 재시작 뒤 읽기 전용 재대조에서도 READY와 기준 저장 23개 일치를 확인했다. 최초 드라이런과 실제 원복, 그 이후 재대조는 구분한다. 원래 선택은 저장소 → 영어 번역 Anime Modder's Edition으로 돌아갔으며 상세 적용/재대조 보고서는 구현 기록을 따른다.
