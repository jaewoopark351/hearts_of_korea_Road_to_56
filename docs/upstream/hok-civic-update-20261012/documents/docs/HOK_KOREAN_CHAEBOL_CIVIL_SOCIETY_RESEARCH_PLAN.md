## 2026-10-12 최종 런타임·원본 보호 확인

진단 없는 d2e6 자유당 게임을 1936.06.07.09에 정상 종료했다. 초기와 종료 직전 오류 내용은 같았고, 해당 내정·주문·구 ID를 직접 가리키는 오류는 없었다. 종료 후에는 기존 random.log 이름 변경 실패 2행이 추가됐다. 정상 진행·합성 표시 검사·정적 확인을 구분한 결과를 외부 `TEST_REPORT.md`와 [최종 기록](incidents/2026-10-12-korean-civic-revision.md)에 정리했다.

등록된 구 완료 저장 B도 d2e6 소스만으로 재저장하고 전체 재시작해 불러왔다. 1936.03.08.23·정치력45·70/35/25/45·세 기업 주문 표시와 잠긴 관리 기능이 유지됐고, 다음 월04.11.05에도 수치가 중복 증가하지 않았다. 초기 구 저장의 누락된 진단 디시전 경고는 재저장 파일에서 재발하지 않았다. 이 한 사례를 일반 저장 호환으로 확대하지 않는다.

기존 저장 71개의 이름·크기·정밀 UTC 수정 시각 차이는 0이다. 신규 테스트 임시 저장 총5개는 보존했고 진단 로더는 제거했다. 모드 목록과 기존 런처 파일의 원본 해시는 일치한다. 자동저장 반년·해상도·창 모드 등 설정은 원본과 같지만, 게임이 같은 로딩 화면 28개의 순서를 바꿔 settings.txt 해시가 다르다. 백업으로 덮어쓰기는 Windows 접근 거부로 실패했다. 설정 기능 복귀와 파일 전체의 byte 일치를 구분하며, 보안 설정을 변경하지 않았다.

실제 한국 AI 선택·DLC 비활성 게임·멀티플레이, 모든 기존 저장의 일반 호환과 모든 표시 조합 등은 미검증이다. 기존 저장 보호 확인을 전체 저장 호환 통과로 해석하지 않는다.

## 사용자 요청에서 확정한 설계 방향

1. 일본 「제국의 영향력」 패널의 구성도 한국화 대상으로 포함한다. 영향력 집단은 **재벌과 시민사회**로 구성한다. 일본식 육군·해군 영향력 칸은 한국판 구상에서 제외한다. 기존 군부 중점·쿠데타 콘텐츠의 삭제를 뜻하지 않는다.
2. 플레이어는 비리의 대가를 알면서도 당장의 국가 운영·산업 확장·군비 때문에 재벌에 의존하게 된다. 두 노선의 처벌을 같은 크기로 맞추는 것은 목표가 아니다.
3. 재벌 우선·시민사회 탄압은 구조적 비리와 조달 사고로 이어진다. 한국화약과 연결한 폭발·부실 납품 사건은 로켓뿐 아니라 **공군과 다른 군수 분야**에도 적용할 구상이다.
4. 시민사회 우선은 소비재공장 요구량의 소폭 증가를 감수하는 대신 안정도·연구속도·국민개병제를 통한 인력 혜택과 **추가적인 실질 보상**을 갖는다. 원본에서 발견한 혜택을 모두 한꺼번에 지급하는 것으로 확정하지 않는다.
5. 시민사회 개혁에는 재벌과 결탁한 기관의 반격, 이른바 **검찰 정변** 사건을 구상한다. 한국화약 관련 사건과 검찰 정변은 이 모드의 신규 대체역사 사건이며, 아래 원본과 실제 역사적 사건을 구분한다.
6. 기업 중점의 중심 마크는 기존 한국 기업 로고를 사용한다. 미쓰비시 등 일본 기업 이미지로 대체하지 않는다.
7. 영향력 패널의 상단은 기존 한국 지도자 portrait를 재사용하고, 프레임·배경·세력 대표 아이콘도 기존 자산에서 우선 선정한다. 지도자 교체에 따라 초상·이름·직위가 함께 바뀌는 표시를 목표로 한다.

### 기존 초상과 이미지 재사용

**사용자 선호로 정한 제작 방향:** 상단 사진은 이미 있는 한국 지도자의 portrait를 그대로 재사용한다. 초상·프레임·세력 아이콘을 새로 그리기보다 기존 자산을 우선 선정하고, 표시 크기와 위치를 맞추는 방식으로 작업량을 줄인다. 이번 요청에서는 이미지 파일이나 UI 연결을 수정하지 않는다.

| 초상 프레임·배경 | 기존 UI 프레임과 배경을 우선 재사용 | 실제 자산과 초상 비율에 맞는 표시 크기·위치 선정 |
| 재벌 세력 대표 | 기존 산업 계열 아이콘에서 우선 선정 | 집단 대표 sprite와 경로는 미선정. 개별 기업 로고와 용도를 구분 |

상단은 특정 인물의 사진을 고정하는 대신 현재 지도자를 따라가는 표시를 목표로 한다. 기존 portrait의 비율을 기준으로 프레임과 표시 영역을 정하며, 일본 패널의 원형 초상이나 꽃장식에 맞추기 위한 별도 이미지 제작을 기본 작업에 넣지 않는다. 기존 자산을 그대로 참조하는 방향이며 이번에는 이미지 생성·복사·편집·규격 변환을 하지 않는다.

현재 정한 것은 **기존 자산 재사용 원칙**이다. 프레임·대표 아이콘의 정확한 파일과 sprite, 초상의 화면 크기·잘림 여부, 지도자 교체 시 실제 갱신은 아직 확인하지 않았다. 원본 파일 재사용과 UI의 동적 연결은 별개의 작업이며 한국 패널에서의 표시 동작은 **UNPROVEN**이다.

### 정책과 사건을 화면에 연결할 제안

각 카드의 설명과 버튼 툴팁에는 현재 단계의 효과, 선택 비용, 선택 뒤 변화를 보여주는 방향을 검토한다. 비리와 기관 장악을 별도로 추적한다면 그 상태가 드러나는 위치도 함께 정한다. 재벌 영향력이 낮아졌다는 이유만으로 누적 비리나 기관 내부의 결탁이 사라진다고 표시하지 않는다.

- **재벌 지원:** 투자·증산·납기 단축의 편익과 감독 약화·시민사회 탄압의 부담을 연결한다. 공군·로켓 조달 사고와 비리 조사 선택도 이 경로의 상태 설명에 연결한다.
- **시민사회 지원:** 안정도·연구·인력과 생산효율·전문성 후보의 혜택, 소비재 부담을 연결한다. 재벌의 반격과 검찰 정변의 징후·대응도 이 경로에서 추적할 수 있게 설계한다.
- **경고와 대응:** 진행 중인 사고·조사·개혁·정변 대비는 관련 디시전과 국민정신을 통해 확인하는 구성을 검토한다. 경고 문구와 발동 조건·확률·비용은 아직 확정하지 않는다.

이 목록은 버튼 한 번으로 모든 보상이나 사건을 발생시키는 사양이 아니다. 중점의 정책 선택, 반복 디시전, 누적 상태, 사건의 연결을 구분하기 위한 설계 제안이다. 육군·해군 영향력 칸 제외는 기존 군부 중점·군종별 조달·군사 사건 삭제를 뜻하지 않는다.

## 한국판 정책과 사건의 연결안

세 정책은 재벌과 협력, 독점 해체, 국유화의 구분을 유지한다. 재벌과 시민사회의 영향력이 항상 합계 100이 되는지, 영향력과 정책 협조를 각각 표시할지는 미확정이다. 두 집단이 동시에 강하거나 약한 상태를 표현할 수 있는 구성을 우선 검토한다.

| 정책 | 당장의 편익 | 누적 부담과 대응 |
|---|---|---|
| 재벌 우선과 협력 | 기업 투자·군수 증산·개발 납기 단축 | 시민사회 탄압과 감독 약화로 비리 축적. 사건 은폐·벌금·전면 조사·공급망 교체의 비용과 편익 구분 |
| 시민사회 우선과 독점 규제 | 안정도·연구·국민개병제에 생산효율과 전문성 보상 추가 | 소폭 소비재 부담과 개혁의 전환 비용. 재벌의 투자 철회·기관 압박·정변 위험에 대응 |
| 국유화와 공공 조달 | 직접 공장 확보·공공 생산 기반 | 기존 업체의 기술·숙련인력과 계약을 어떻게 승계하는지 결정. 국유화만으로 모든 사고와 기관 반발이 즉시 없어지는 것은 미확정 |

재벌 편익은 전쟁 준비나 산업 확장 때 포기하기 어려울 만큼 체감돼야 한다. 시민사회 경로의 장기 생산효율과 전문성은 재벌 의존을 줄일 유인이 된다. 부패의 규모와 반격 위험을 기계적으로 대칭화하거나 양쪽에 같은 사건을 붙이는 안은 채택하지 않는다.

- 선경·삼성·금성·한국화약 로고는 [GFX](../interface/ideas_HoK.gfx) (53행)에 이미 연결돼 있다. 이번에는 이미지 생성·복사·수정·규격 변환을 하지 않는다. 향후 기존 중점용 테두리·배경을 우선 선정하고 프로젝트 내부 상대경로로 연결한다.
- 일본 재벌 협력 원본의 기업 중점 70일→35일 단축은 한국의 기본 35일 중점에 그대로 적용하지 않는다. 일본 파벌 조건·주 ID·변수·기업·MIO와 MD 예산·현대 기체 ID도 개별 대응이 필요하다.

## 구현 승인 전에 남겨둔 설계 과제

1. 확정한 기존 지도자 초상 재사용·두 세력 카드·지원/견제 버튼 골격을 바탕으로 적용 정치 경로, 제목·지도자 표시 연결·기존 프레임과 대표 아이콘·창 위치를 정한다. 한국 트리의 SHOW/HIDE 배치와 기존 군부·왕정 경로의 관계도 정리한다.
2. 영향력·정책 협조·비리·기관 장악의 의미와 초기값, 변화 원인, 플레이어에게 보여줄 경고. 재벌 영향력 감소가 기관 장악까지 즉시 없애는지 별도 판단.
3. 시민사회 보상 후보의 선택·최종값·기간·단계 승계. 사용자 지정의 소비재 부담 및 안정도·연구·국민개병제 혜택과 합계 계산.
4. 조달 분야별 편익·비리 누적·사건 발생 조건·대상 장비·피해·조사·은폐·복구·반복 제한. 공군의 사고 확률과 단발 폭발 사건을 분리.
5. 검찰 정변의 사전 징후·정치력 비용·기관 개혁·타협·발생 결과·회복 경로. 원본의 군부 쿠데타를 단순 태그 치환하지 않음.
6. 실제 기존 중점·디시전·국민정신·MIO 보상 보존, DLC 대체 보상, AI·세이브·멀티플레이. 배치 변경은 [좌표 계획](HOK_KOREAN_FOCUS_LAYOUT_PLAN.md)과 최신 명세를 별도로 적용.
7. 직접 재사용할 코드·문안·이미지를 선택할 경우 해당 파일의 이용 조건과 원작 기여를 확인. 현재는 기능 구조와 수치를 조사했으며 코드·그림의 직접 재배포를 허가받았다는 뜻이 아님.

이 목록은 구현 전 설계 과제다. 문서화가 게임 코드 구현을 승인하지 않는다. 이식 후보의 수량은 신규 중점 수나 제작 분량을 확정하지 않는다.
