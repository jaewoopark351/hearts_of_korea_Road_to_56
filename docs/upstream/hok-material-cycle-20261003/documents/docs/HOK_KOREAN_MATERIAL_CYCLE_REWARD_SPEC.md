## 긴급 원료 순환체계 시설 확충 디시전

표시 이름은 **긴급 원료 순환체계 시설 확충**이다. 원료 순환체계 중점을 완료한 뒤 해금하고, 기본 국민정신 II 위에 별도의 기간제 국민정신을 추가하는 방식으로 설계한다.

| 항목 | 확정한 동작 |
|---|---|
| 비용 | 사용할 때마다 정치력 150. 민간공장 점유나 별도 자원·인력 비용 없음 |
| 효과 시작 | 사용 즉시 임시 국민정신 지급 |
| 임시 효과 | 자원 획득 효율 +30%, 자원 부족 불이익 −30% |
| 지속기간 | 사용 시점부터 90일 |
| 활성 중 재사용 | 불가. 버튼을 비활성화하여 재지불·중첩·기간 갱신을 차단 |
| 만료 | 임시 국민정신만 제거하고 영구 국민정신 II는 유지 |
| 재사용 시점 | 90일 효과가 끝나고 정치력 150이 있으면 다시 사용 가능 |
| 횟수 | 제한 없이 반복 가능. 자동 재실행은 하지 않음 |
| 만료 후 별도 대기 | 없음 |

90일은 효과를 받는 기간이다. 사용 후 90일을 기다려 완공 보상을 받는 구조가 아니다. 시설 확충이라는 이름은 회수·선별·재용해 시설을 90일간 집중 확충·운영하는 정책을 설명하며, 영구 공장이나 영구 누적 보정을 지급한다는 의미가 아니다.

기존 만주 M1~M4 사업의 공통 실행 슬롯과 종료 후 90일 대기시간을 이 디시전에 가져오지 않는다. 기존 사업의 비용·공유 제한·대기시간도 바꾸지 않는다. 활성 중에는 같은 긴급 원료 디시전만 재사용할 수 없으며, 반복 횟수에 따른 강화 변수를 두지 않는다.

## 사용 횟수별 합계와 화면 표시

아래 합계는 **이 원료 정책 묶음만의 보정**이다. 연구·무역법·다른 국민정신을 포함한 국가 전체 표시값이나 실제 자원·생산량을 고정하는 수치가 아니다.

| 상태 | 영구 II | 임시 효과 | 정책 묶음 합계 | 같은 디시전 사용 |
|---|---|---|---|---|
| 해금 후 비활성 | +60% / −60% | 없음 | +60% / −60% | 정치력 150이 있으면 가능 |

국민정신 화면에서는 영구 **원료 순환체계 II**에 +60%/−60%, 별도 임시 **긴급 원료 순환체계 시설 확충**에 +30%/−30%를 표시하는 것을 목표로 한다. +90%/−90%는 두 효과를 합친 설명값이며, II 자체의 툴팁을 +90%/−90%로 바꾸는 방식이 아니다.

2026-10-02 후속 문안 수정: 원료 순환체계 I·II와 임시 국민정신의 설명 본문은 효과 수치·비용·기간·교체·취소 규칙을 반복하지 않고 정책의 필요성을 서술한다. I는 작업장에 버려지는 금속을 수거해 부족한 원료를 다시 확보하는 이유를, II는 채굴과 수입만으로 늘어나는 원료 수요를 감당하기 어려워 폐금속을 다시 생산에 돌려보내는 이유를 설명한다. 임시 정신은 회수할 자재가 있어도 수거·선별·재용해가 수요를 따라가지 못해 긴급 확충이 필요한 상황을 다룬다. 자동 효과·만료 표시와 디시전의 긴 설명 및 사용 규칙은 유지한다.

디시전의 활성 상태와 남은 90일 기간을 화면에서 확인할 수 있도록 설계한다. 실제 진행 표시·남은 기간 표시의 구현 방법은 해당 버전 바닐라의 같은 문맥 사례와 게임 UI로 확인해야 한다. 영구 정신을 임시로 교체하고 만료 시 복원하는 구조나 활성 중 재사용으로 시간을 연장하는 구조는 사용하지 않는다.

> 원료를 확보하는 일은 광산에서 새로운 광석을 캐내는 것으로 끝나지 않습니다. 공장에 쌓인 금속 절삭편, 수명을 다한 기계 부품, 폐차량과 철거 자재에도 산업을 다시 움직일 원료가 남아 있습니다. 그러나 기존 수거망과 평상시의 처리 능력만으로는 급증하는 생산 수요에 맞춰 이러한 자재를 빠짐없이 회수하고, 필요한 공장에 제때 공급하기 어렵습니다. 원료 부족이 생산 현장의 병목으로 이어지기 전에 집하장과 선별 시설, 재용해 설비의 처리 능력을 집중적으로 확충하고 철도·창고·제련소 사이의 운송을 조정해야 합니다.
>

>
> 이번 사업은 상설 원료 순환체계에 더해 시행하는 한시적인 집중 확충·운영 조치입니다. 긴급 지원이 끝나면 추가 처리와 운송 지원은 종료되지만, 이미 정착한 기본 원료 순환체계는 유지됩니다. 다시 수요가 높아지거나 공급에 압박이 생기면 새로운 정치적·행정적 지원을 투입하여 같은 사업을 재개할 수 있습니다. 진행 중인 사업을 겹쳐 시행하기보다, 정해진 기간 동안 회수와 재투입에 역량을 집중하여 자원 확보를 늘리고 원료 부족에 따른 생산 차질을 줄이겠습니다.
