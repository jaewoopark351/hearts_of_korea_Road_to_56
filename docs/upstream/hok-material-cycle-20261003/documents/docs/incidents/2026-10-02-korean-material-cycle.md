같은 날짜에 사용자가 원료 순환체계 II와 긴급 시설 확충 국민정신의 설명이 사무적이며, 효과를 반복하기보다 정책이 필요한 이유를 써 달라고 요청했다. 두 로케일의 `HOK_KOR_cmn_material_cycle_2_desc`와 `HOK_KOR_cmn_emergency_material_cycle_boost_desc`만 다시 썼다. II는 채굴·수입만으로 공장의 수요를 채우기 어려운 상황과 폐금속 재투입의 필요성을, 임시 정신은 자재가 남아 있어도 수거·처리가 따라가지 못하는 문제와 긴급 확충을 서술한다. 본문의 수치·비용·기간·중첩·취소 안내는 덜어내며 자동 효과·만료 표시와 기존 디시전 설명은 유지했다. 헤더 바로 뒤의 동일 기여자 주석을 추가하고 이전 주석을 보존했다.

사용자가 제공한 수정 전 UI 사진에서는 II의 +60%/−60%, 별도 임시 정신의 +30%/−30%, 제거 예정일 표시와 기존 설명을 확인했다. 이는 해당 표시의 증거이며 정치력 지불·90일 자연 만료·재사용의 검증으로 확대하지 않는다. 이번 문안의 BOM·CRLF·짝 본문·키와 두 설명 외 기존 내용 보존 및 `git diff --check`를 확인했다. 앞선 238개 검사와 초기 로드는 문안 수정 전 결과이며 이번에는 게임을 재실행하거나 조작하지 않았다. 새 본문의 실제 화면 줄바꿈·크기는 미검수다. 커밋·푸시도 수행하지 않았다.
