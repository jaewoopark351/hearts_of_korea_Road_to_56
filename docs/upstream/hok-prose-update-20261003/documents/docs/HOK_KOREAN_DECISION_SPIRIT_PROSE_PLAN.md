# 한국 신규 디시전과 국민정신 설명 보강 계획

작성·적용: 2026-10-03. 상태: **설명 124개 현지화 적용 / 파시즘·공산주의 문체 후속 반영 / 정적 보존 검사 통과 / 실제 UI 확인 대기**. 적용 범위와 증거는 [구현 기록](incidents/2026-10-03-korean-decision-spirit-prose.md)을 따른다.

새로 추가한 한국 중점에 연결된 디시전과 국민정신의 설명을 보강하기 위한 계획이다. 정책이 필요한 현장 사정과 실제 행동을 설명하고, 플레이어에게 필요한 운영 규칙은 명확하게 전달하는 것을 목표로 한다. 기존 효과와 진행 방식은 문안의 기준으로 보존한다.

처음에는 사용자의 **문서화만** 요청에 따라 아래 계획을 작성했다. 이후 사용자가 같은 계획을 인용하여 “AGENTS.md, /docs 읽고 구현해줘”라고 요청했으므로, 설명 본문 보강을 적용했다. 아래 검토 표는 적용 전 기준선의 문제와 설계 방향을 보존하며, 실제 적용과 검증은 별도 구현 기록에서 구분한다.

그 뒤 사용자는 파시즘·공산주의 설명의 어투를 HOI4 대사 전반에 비추어 이해하고 AGENTS.md에 기록하도록 요청했다. 해당 규칙을 작성한 뒤의 재적용 요청에서는 이미 보강한 효과·조건 안내를 유지하면서 두 노선의 서사만 후속 수정한다. 앞선 124개를 새 기준선에서 다시 쓰거나 게임 효과를 바꾸는 작업이 아니다.

## 작업 범위

- 원본 한국 중점의 설명은 제외한다. 현재 프로젝트의 `HOK_KOR_` 신규 콘텐츠 중 아래 목록의 디시전 설명 29개, 연결 범주 설명 8개, 국가 국민정신 설명 93개를 검토 대상으로 삼는다. 모든 문구를 일괄 교체한다는 뜻은 아니며, 이미 충분한 설명은 보존한다.
- 적용 대상은 대응 현지화 파일의 해당 `_desc` 본문이다. 명칭, 키, 중점·이벤트 설명, 기존 수동 효과 안내 `_tt`, scripted localisation과 토큰 참조는 직접 수정 대상에서 제외한다. 필요한 정보는 기존 안내를 읽어 `_desc`에 정확히 연결한다.
- 비용·보상 수치, 적용 범위, 기간, 해금·가용·취소 조건, 재사용, 공유 사업 제한, 정신 교체·제거, AI, 중점 배치와 그림은 변경하지 않는다. 설명을 다듬기 위해 게임 동작을 바꾸지 않는다.
- 만주 지역 제도 12개는 국가 국민정신이 아닌 주 단위 동적 변동치다. 만주 디시전의 복구 대상과 적용 조건을 설명하기 위한 참고로 읽되, 해당 12개 설명의 보강을 국가 국민정신 93개에 포함하지 않는다. 근거는 [만주와 공통 후속 명세](HOK_KOREAN_REGIONAL_COMMON_FOLLOWUP_SPEC.md)의 지역 적용 범위다.
- 현재 한국어·영어 현지화 채널은 각각의 헤더 아래 동일한 한국어 본문을 사용하는 계약이다. 향후 설명 적용 시 대응 본문을 함께 맞추며, 별도 영어 번역이나 locale 변경으로 확대하지 않는다.
- 최초 문서화 단계에서는 이 계획과 README 링크만 작성했다. 후속 구현에서는 해당 설명과 필요한 현지화 기여자 주석만 수정한다. 게임 로직·자산·Git 상태 변경과 커밋·푸시·게시의 권한으로 확대하지 않는다.

## 기준선과 증거

문서화 시작 시 브랜치는 `feat/korean-focus-expansion-ai`, HEAD는 `43dbb38ac2553942e898e6093a2a46f0430995fc`이며 작업 트리는 깨끗했다. 저장소 `C:\hoi\hearts_of_korea`의 현재 현지화, 디시전, 국민정신, 필요한 관계 보정과 중점 부여·승계 소스를 읽었다. 아래 행번호는 이 기준선의 위치이며, 이후 편집으로 달라질 수 있으므로 키와 함께 찾는다.

**CONFIRMED**는 현재 파일의 문구·정의·조건을 직접 읽은 사실을 뜻한다. 문장 구성과 몰입에 관한 평가는 **개선 제안**으로 구분한다. 소스에 정의된 효과를 읽었다는 사실을 엔진의 실제 적용이나 UI 표시를 확인했다는 뜻으로 사용하지 않는다.

계획 수립을 위한 검토에서는 게임을 실행하거나 자동 검사를 수행하지 않았다. 이후 설명 적용에 대한 정적 검사는 구현 기록에 따로 남겼다. 실제 툴팁의 줄바꿈·길이, 자동 효과 안내와 본문의 중복, 변경 후 한국어 표시와 런타임 동작은 **UNPROVEN**이다. 과거의 정적 검사나 새 게임 로드 결과를 이번 문안의 검증 결과로 옮기지 않는다.

작성 기준은 [AGENTS.md의 국민정신과 디시전 문체 규칙](../AGENTS.md), 효과 해석은 각 콘텐츠의 현재 소스와 명세를 따른다. 특히 [원료 순환체계 명세](HOK_KOREAN_MATERIAL_CYCLE_REWARD_SPEC.md)와 [2026-10-02 구현 및 설명 수정 기록](incidents/2026-10-02-korean-material-cycle.md)은 사용자 지정 문안과 기존 관측의 한계를 보존하는 근거다.

## 설명 작성 기준

### 디시전의 배경과 실제 행동

먼저 무엇이 막혀 있는지 설명하고, 누가 어떤 조치를 시행하는지 연결한다. 공장·창구·창고·배차·서류·명부 등 정책에 맞는 현장을 사용한다. “안정과 건설을 지원합니다”처럼 효과 이름만 나열하는 문장은 실제 조정·집행 과정을 보여 주는 문장으로 보강한다.

현재 좋은 대사와 인물상은 살린다. 공동구매의 협상, 긴급 군수납품의 강압적 기다림, 국내성 보수의 공사 일정 충돌은 짧은 문장만으로도 행동을 보여 준다. 모든 디시전을 대화로 시작할 필요는 없다. 공산 조합 정책의 협의와 현장 목소리, 계획 정책의 실적 압박, 구국군의 강압적 말투, 민주 협력의 상대국 의사는 기존 맥락에 맞춰 구분한다.

운영 규칙은 본문 다음의 짧은 별도 문단에서 읽히게 한다. 비용·효과 시작 시점·기간·재사용·동시 진행·취소·미환급 정보는 필요한 만큼 유지한다. 자동 툴팁에 실제로 표시되는 것이 확인되지 않은 정보를 “중복”이라는 이유만으로 삭제하지 않는다. 범주 설명에는 공유 제한과 정책 배경을 적되, 범주 공개가 모든 개별 사업의 해금이라는 인상을 주지 않는다.

### 국민정신이 나타내는 제도와 필요성

국민정신은 현재 갖춘 제도가 어떤 문제를 해결하는지 설명한다. “○○의 운용 기준을 정착시킨 제도입니다”라는 공통 문장 대신 해당 제도의 사람·업무·현장 사정을 쓴다. 효과 수치는 자동 효과란에 이미 표시되는 범위에서 불필요하게 반복하지 않되, 적용 범위와 오해하기 쉬운 차이는 남긴다.

I·II·III는 제도의 발전을 설명한다. 예를 들어 지역별 시행에서 전국 조정으로, 단발 협의에서 상설 기준으로, 개별 보고에서 통합 감사로 발전하는 내용을 해당 중점과 보상에 맞춰 서술한다. 단계를 높인다는 이유로 새로운 기능이나 추가 혜택을 만들어 설명하지 않는다. 정신 교체와 서로 다른 계열의 병행 보유도 구분한다.

정부·영토·세력 조건이나 기간제 제거처럼 플레이어가 알아야 하는 규칙은 별도 짧은 문단으로 유지할 수 있다. 기술 용어와 교체 안내가 본문 전체를 대신하지 않도록 한다. 짧은 설명도 필요성과 작동 방식이 충분하면 유지한다.

### 파시즘·공산주의의 HOI4 문체

두 노선의 국민정신·디시전·연결 범주 서사는 [AGENTS.md 8절](../AGENTS.md)의 후속 문체 규칙을 적용한다. 사용자가 제시한 “병무청 와버렸다구^^”, “형벌부대에 끌려갈 시간 이라우 동무”는 권력과 친근한 말투가 함께 드러나는 태도의 예시다. 문구를 복제하거나 모든 정책을 징집·형벌 이야기로 바꾸는 틀이 아니다.

여러 국가의 실제 국민정신과 디시전, 참고용 중점·이벤트·선택지를 읽어 역사적 설명, 국가적 자부심, 연대, 선전, 흥정, 자기정당화와 아이러니의 폭을 함께 참고한다. 설명은 해당 국가·정권·기관·주민의 관점에서 정책의 명분과 현실을 드러낸다. 대화·연설·기관 설명 등 형식을 바꾸며, 모든 항목에 농담이나 같은 반전을 붙이지 않는다.

파시즘은 구국군이 자기 요구를 당연한 국가적 필요로 여기는 확신과 친절한 강제성을 담는다. 조달은 영광과 실제 원가, 참모는 지도와 야전의 차이, 삼군은 국가를 위한다는 각 군의 체면, 점령은 통치의 선의와 주민의 질문, 재건은 발표한 치적과 실행이라는 서로 다른 소재를 쓴다. 병역 명부는 동원 분야에 맞는 장면으로 사용한다.

공산주의는 동무에게 약속하는 연대·평등·교육·산업 발전과 공동체·당·국가가 요구하는 책임을 함께 담는다. 조합은 농민·노동자·교사의 이해와 협의, 계획기관은 원대한 목표와 실제 설비·원료·시간의 간극을 보여 준다. 공통으로 “동무”나 특정 종결어미를 쓰는 것은 가능하지만, 모든 화자가 같은 방언·협박·실적 독촉을 반복하지 않는다.

문체는 서사에만 적용한다. 앞선 구현에서 명확히 한 비용·기간·재사용·취소·미환급·교체·제거 안내는 후속 수정 전 문단을 그대로 보존한다. 형벌부대 신설·숙청·인력 손실·장비 지급처럼 소스에 없는 효과를 문체를 위해 만들지 않는다. 다른 노선과 공통 정책, 중점·이벤트·명칭·`_tt`에는 이 규칙을 확대 적용하지 않는다.

### 이미 정한 원료 순환 문안

[원료 순환체계 I·II와 긴급 국민정신 설명](../localisation/korean/HOK_KOR_common_followup_l_korean.yml)의 54·56·74행은 버려진 금속, 원료를 기다리는 공장, 수거·선별·제련의 연결을 통해 필요성을 설명한 좋은 기준이다. 이 세 문안은 보존을 우선하며, 다른 정신도 같은 구체성을 갖추도록 참고한다. 같은 문장이나 분량을 복제하는 틀로 사용하지 않는다.

긴급 원료 순환 디시전 72행의 긴 본문은 이전 사용자 지정 문안이다. 앞선 검토에서 길이와 반복을 개선 후보로 언급했지만, **이번 보강 계획은 이 문안을 일괄 축약하는 근거가 아니다.** 배경·집중 운영·상설 체계 유지의 세 문단과 규칙 안내를 보존한다. 내용 축약이나 구조 변경은 그 문안에 대한 별도 명시적 요청이 있는 경우에 다룬다. 실제 UI 길이 문제가 이번 검토에서 관측된 것도 아니다.

효과 방향을 설명하는 서사와 실제 적용 범위도 일치시킨다. 예를 들어 특정 부대의 훈련을 배경으로 쓰더라도 modifier가 육군 전체에 적용된다면 그 부대에만 효과가 제한된다고 쓰지 않는다. 연구 혜택·즉시 경험치·정치력처럼 중점이 지급한 일회 보상을 국민정신의 상시 효과로 옮겨 설명하지 않는다.

## 설명 적용 순서

1. 우선순위 1의 조건 주체·효과 종류·복구 대상 문구를 확정한다. 현재 정의를 읽어 설명을 맞추며 로직을 바꾸지 않는다.
2. 공통 분야의 반복 틀과 공산 경제정책의 동일한 I·II 설명을 보강한다. 좋은 기존 문안과 사용자 지정 원료 문안은 보존한다.
3. 산업·군사·민주·파시즘·입헌·전제·환제국별로 필요한 설명만 다듬는다. 배경과 제도의 변화가 이미 충분한 항목은 유지한다.
4. 실제 적용 시 변경 키별로 현재 본문, 제안 본문, 효과·조건 근거를 대조한다. 대응 두 로케일의 본문을 맞추고 BOM·헤더·기존 토큰·인용부호·줄바꿈 이스케이프를 보존한다. 생산 현지화에는 그때의 날짜를 사용한 동일한 `#YYYYMMDD_kpopmodder: <reason>` 주석을 각 헤더 바로 뒤에 추가하고 이전 주석을 유지한다. 문서에는 생산 기여자 주석을 넣지 않는다.
5. 변경 범위를 설명 본문과 필요한 기여자 주석으로 제한하여 검토한다. 게임 로직·명칭·키·다른 설명의 변경이 섞이지 않았는지 확인한다. 실제 UI와 실행 검증은 실행이 허용된 후 별도 기록하며, 소스 대조를 UI 통과로 표현하지 않는다.

## 최초 문서화 단계의 완료 상태

설명 대상 수량, 현재 문구의 개선점, 정책별 서술 방향, 효과·조건 보존 기준과 향후 적용 순서를 기록했다. 관련 소스와 기존 기록을 읽었으며, 계획 문서와 README 링크만 작성했다.

현지화 본문과 게임 정의의 수정, 새 문안의 게임 표시, 자동 툴팁 중복 판단, 실행 검증은 수행하지 않았다. 작업 트리에는 이 문서와 README 링크만 추가했으며, 테스트·검증 스크립트·게임 실행·브랜치 변경·스테이징·커밋·푸시·게시를 수행하지 않았다. 다음 단계는 사용자가 설명 적용을 요청했을 때 이 계획의 범위 안에서 진행한다.
