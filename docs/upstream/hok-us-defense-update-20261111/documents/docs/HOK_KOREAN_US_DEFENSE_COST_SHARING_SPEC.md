# 한미 조약·주한미군 배치 — 미국 선택과 양국 방위비 명세

갱신: 2026-11-11 (Asia/Seoul). 상태: **게임 코드·현지화·AI 이미지 통합 반영 / 최신 정적 검사 144 PASS·0 FAIL / 실제 엔진에서 세 주둔 분기·한국 통보·자치령·KATUSA 조건 확인**. 정상 중점 진행과 후속 검증은 [실행 기록](incidents/2026-11-11-korean-us-defense-sharing.md)에 별도로 기록한다.

한미상호방위조약·주한미군 배치의 미국 수신 사건, 양국 방위비 국민정신, 미국 자치령 전환, 결과 통보·뉴스·사건 사진·아이콘 또는 관련 AI·표시를 검토·변경할 때 이 문서를 먼저 읽는다. 구현된 소스와 실행 관측은 구분한다. 이 문서 자체는 추가 코드 변경·게임 실행·커밋·푸시·업로드의 승인이 아니다.

## 확정 범위와 문서화 이력

최초 문서 전용 단계에서는 조약 ±5%, 미국의 주둔 세 선택, 뉴스 초안과 AI 이미지 방향만 기록했다. 당시 코드·그림 미구현과 한국 추가 +25%/최종 +35% 불일치, 자치령 보상·새 AI 미정이라는 표시는 그 단계의 이력이다. 이후 사용자가 `AGENTS.md, /docs 읽고 구현해줘`로 구현을 요청하고 다음을 확정했다.

- 조약 체결: 대한민국 +5%, 미국 −5%.
- 주둔 협정: 대한민국 **최종 +35%**(조약 단계에서 +30%), 미국 **최종 −15%**(−10%). 앞선 추가 +25%는 현재 사양에 사용하지 않는다.
- 자치령: 기존 양국 방위비 정신 유지, 주한미군 3개 사단 지급, KATUSA의 주둔 승인 조건 충족.
- 미국 AI: 조약 10/0 유지, 주둔 **10/0/0**. 자치령·거부는 미국 플레이어가 선택하는 분기다.
- 사건·뉴스 사진과 국민정신 아이콘은 HOI4 분위기의 AI 생성 창작물로 제작하며, 신규 국민정신 아이콘 네 개 모두 태극기·성조기를 함께 넣는다.

초기 조약 15%·최종 50%, 미국의 실제 한국 합병, 한국 측의 추가 협상 거부권, 무관한 중점·지도·경제원조 재설계는 제외한다. 기존 중점 ID·35일 기간·좌표·선행 연결과 사단 편제는 보존했다.

## 1단계 — 한미상호방위조약

한국의 `KOR_rok_us_mutual_defense_treaty` 완료가 미국에 기존 `kor_events.45`를 보낸다. 중점 완료 자체는 방위비 정신을 지급하지 않으며 미국의 체결 선택이 지급을 실행한다.

| 미국 선택 | 대한민국 | 미국 | 기존 흐름 |
|---|---|---|---|
| 한미 상호 방위 조약 체결 | 「미국 방위비」 소비재 공장 계수 **+5%** | 「대한민국 방위비」 소비재 공장 계수 **−5%** | `rok_us_alliance_formed_flag` 설정, 한국 수락 통보 예약, 통보의 단일 확인 선택지에서 상호 독립보장·군사통행권 실행 |
| 한미 상호 방위 조약 거부 | 신규 방위비·경제 효과 없음 | 신규 방위비·경제 효과 없음 | 기존 한국 거부 통보 유지, 이 선택으로 조약 표식을 새로 설정하지 않음 |

기존 AI 가중치는 체결 `base=10`·거부 `base=0`이다. 체결은 한국 scope의 `HOK_KOR_apply_us_defense_treaty`를 호출하고, helper 내부에서 한국 정신을 지급한 뒤 `USA` scope에서 미국 정신을 지급한다. 한국 통보에서 같은 정신을 다시 지급하지 않는다.

`events/korea.txt`의 후속 호출은 기존 대문자 `KOR_events.46/47`, 정의는 소문자 `kor_events.46/47`로 남아 있다. 이번 구현은 이 상속 표기를 변경하지 않았다. run3에서 .46 통보와 상호 보장·통행권의 실제 실행을 확인했다. .47 거부 경로의 실제 수신은 별도 미확인 항목이다.

## 2단계 — 주한미군 배치와 미국의 세 선택

`KOR_usfk` 완료 시 한국에 요청 표식을 설정하고, 미국이 존재하면 신규 `HOK_KOR_us_defense.1`을 보낸다. 미국이 이미 소멸했다면 사건 발송 대신 배치 무산 helper로 요청을 종료한다. 완료 즉시 사단을 지급하던 기존 보상은 승인 후 실행하는 공용 helper로 이동했다. 미국의 응답 전에는 새 사단·방위비 강화·결과 뉴스가 발생하지 않는다.

| 미국 선택 | 대한민국 | 미국 | 사단·후속·통보·뉴스 |
|---|---|---|---|
| **1. 주한미군 배치 및 방위비 협정** | 독립 유지, 「미국 방위비」를 **최종 +35%** 상위 정신으로 교체 | 「대한민국 방위비」를 **최종 −15%** 상위 정신으로 교체 | 기존 3개 사단 지급, KATUSA 주둔 승인 조건 충족, 한국 승인 통보 `.2`, 「대한민국과 미국 방위비 협정」 뉴스 `.5` |
| **2. 대한민국 괴뢰화** | 미국의 **자치령**으로 전환, 조약 단계 **+5% 유지** | 조약 단계 **−5% 유지** | 기존 3개 사단 지급, KATUSA 주둔 승인 조건 충족, 한국 단일 「수락」 통보 `.3`, 「미국의 51번째 주 대한민국!」 뉴스 `.6` |
| **3. 주한미군 주둔 거부** | 독립·조약·조약 단계 **+5% 유지** | 조약 단계 **−5% 유지** | 사단·추가 경제 효과 없음, 한국 배치 무산 통보 `.4`, 별도 세계 뉴스 없음 |

상위 정신은 기본 정신을 제거하고 하나로 교체한다. **+5%와 +35%를 동시에 중첩하지 않는다.** 표의 수치는 `consumer_goods_factor`에 적용하는 각 국민정신의 계수이며, `consumer_goods_expected_value`에 더하는 퍼센트포인트나 국가 전체의 최종 소비재 비율을 뜻하지 않는다. 한국 공장을 미국에 직접 이전하는 효과도 아니다. 기존 「미국의 경제원조」의 `consumer_goods_factor=-0.07`은 별개로 유지한다.

자치령 분기는 미국 scope에서 `set_autonomy = { target = KOR autonomy_state = autonomy_dominion end_wars = no end_civil_wars = no }`를 실행한다. 한국을 합병하거나 플레이 국가를 바꾸지 않는다. 「미국의 51번째 주」는 정치적 과장을 담은 제목이며 본문은 실제 자치령 지위와 국내 행정의 유지를 설명한다. 한국의 「수락」은 이미 정해진 결과의 확인 버튼 하나이며 효과를 재실행하지 않는다.

미국의 새 사건 가중치는 1번 `base=10`, 2·3번 `base=0`이다. AI가 1번을 선택하도록 소스에 설정했으며, 실제 AI 진행 관측은 별도 검증 항목이다.

### 응답 대기 중 상황 변화

미국의 1·2번 선택은 처리 시점에 한국 scope의 `HOK_KOR_can_finalize_us_defense_stationing`을 다시 평가한다. 양국 존재, 한국 독립, 양국 내전 없음, 한미 전쟁 없음, 한국이 소유·통제하고 완전 통제하는 사단 생성 후보 주가 하나 이상임을 요구한다. 사건의 선택지를 띄운 뒤 상황이 달라진 경우도 이 재검증 대상이다.

조건이 성립하지 않으면 `HOK_KOR_refuse_us_defense_stationing`으로 요청을 resolved 처리한다. 승인·자치령 표식, 신규 방위비·사단·뉴스는 지급하지 않고 `.4` 「주한미군 배치 무산」을 한국에 통보한다. 이 결과 helper는 기존 조약·보유 정신을 직접 변경하지 않는다. 상대국 소멸·양국 전쟁에 따른 국민정신 자체의 취소 조건은 별개로 적용한다. 정상적인 3번 거부도 같은 통보 경로를 사용한다.

### 사단과 후속 중점

`HOK_KOR_grant_usfk_divisions`는 한국 scope에서 실행한다. 기존 `USFK Division` 편제의 보병 9개 대대, 정찰·포병·공병 지원중대, 경험치 계수 0.3, 한국 소유의 용산·평택·오산 3개 사단을 보존했다.

생성 후보는 한국의 소유·통제 주이며 완전 통제 조건을 함께 확인한다. 기존 `prioritize = { 835 }`를 의도적으로 유지했다. 설치본 파일은 `history/states/835-Haraghe.txt`, 주석·영어 표시명은 **Hararghe**이며 한국의 용산·평택·오산 주를 뜻하는 ID가 아니다. 이 저장소에는 835 주 재정의가 없다. 따라서 835를 고정 한국 배치 위치로 문서화하지 않으며, 한국이 그 주를 소유·통제하지 않는 일반 상태에서는 적격 한국 소유·통제 주의 무작위 fallback을 사용하는 소스 구조다. 후보 선택과 실제 생성 위치는 실행 검증에서 확인한다.

기존 한국 중점에서 미국 수신 사건으로 진입점이 바뀌므로, 후보 주 내부의 `ROOT`(미국)를 그대로 사용하지 않고 `KOR = { has_full_control_of_state = PREV }`로 한국을 명시했다. 835 우선값·지도·프로빈스·편제 자체를 교체하는 변경은 하지 않았다.

`units_granted`는 실제 후보 state iterator 내부에서 3개 생성 명령 다음에 `KOR = { set_country_flag = HOK_KOR_us_defense_units_granted }`로 기록한다. 선택할 주가 없으면 지급 표식도 설정하지 않는다. 수정 전에는 iterator 안의 state scope에서 국가 표식을 직접 설정하는 오류가 있었고, 초기 144개 정적 검사가 이를 잡지 못했다. 명시적 한국 scope로 수정하고 검사를 보강한 뒤 전체 재시작한 run3에서 협정·자치령 각각 한국 사단 3개와 지급 표식, 신규 scope 오류 0건을 확인했다.

KATUSA는 기존 `KOR_usfk` 선행을 유지하고, 신규 요청에는 실제 승인 표식을 요구한다. 조건은 `NOT station_requested OR station_approved`다. 신규 요청 대기·거부는 막고 협정·자치령은 통과시킨다. 기존 주둔 중점 완료 저장에는 요청 표식이 없으므로 종전 KATUSA 접근을 보존한다. KATUSA의 연구공유·인력 −20,000은 유지한다. 자유국가기구 창설도 KATUSA 선행과 기존 독립국·외교 조건을 그대로 유지하므로 자치령 선택이 그 후속의 독립국 조건까지 면제하지는 않는다.

## 국민정신·영속 상태·기존 저장

| 대상·단계 | 내부 ID | `consumer_goods_factor` |
|---|---|---|
| 한국 조약 | `HOK_KOR_us_defense_cost_sharing_1` | `0.05` |
| 한국 주둔 협정 | `HOK_KOR_us_defense_cost_sharing_2` | `0.35` |
| 미국 조약 | `HOK_KOR_korean_defense_contribution_1` | `-0.05` |
| 미국 주둔 협정 | `HOK_KOR_korean_defense_contribution_2` | `-0.15` |

네 정신은 기간 제한 없이 유지하며 수동 제거는 허용하지 않는다(`removal_cost=-1`). 상대국이 소멸하거나 양국이 전쟁 상태가 되면 해당 정신이 제거된다. 설명에도 이 조건을 적었다. 평화 회복만으로 자동 복구하지 않으며 기존 조약 global flag를 해제하는 별도 조약 파기 시스템이나 일일 감시를 추가하지 않았다.

한국 country flag로 다음 상태를 저장한다.

| 표식 접미사 — 공통 접두어 `HOK_KOR_us_defense_` | 역할 |
|---|---|
| `treaty_accepted` | 신규 조약 정신 지급 재처리 방지, 주둔 승인 후 하위 정신 재추가 방지 |
| `station_requested` | 미국 응답을 요청한 신규 주둔 경로와 구저장 구분 |
| `station_resolved` | 협정·자치령·거부 중 하나가 처리됐음을 기록, 보상·통보·뉴스의 재예약 방지 |
| `station_approved` | 협정·자치령의 실제 주둔 승인, KATUSA의 신규 승인 조건 |
| `units_granted` | 사단 helper의 반복 생성 방지 |
| `dominion` | 자치령 분기 선택 기록 |

조약 helper는 상위 정신 보유 여부도 확인한다. 주둔 협정·자치령 처리에서는 `treaty_accepted`를 함께 기록하여, 구저장에서 새 주둔 결과를 받은 뒤 조약 helper를 다시 호출해 하위 정신을 중첩하는 경계를 막는다. 실제 반복 실행·저장 후 재호출 증거는 런타임 기록에서 별도로 확인한다.

기존 조약·주둔 완료 저장에 신규 경제 정신·사단·미국 요청을 자동 소급하지 않는다. 구저장의 주둔 완료 이력은 KATUSA 조건에서만 grandfather한다. 구 조약만 완료한 저장에서 새 주둔 협정을 선택하면 상위 정신을 지급하지만, 자치령·거부는 당시 보유한 정신을 그대로 두며 누락된 조약 정신을 새로 소급 지급하지 않는다. 위 결과 표의 ±5% 유지는 새 조약 경로에서 기본 정신을 받은 상태를 기준으로 한다. 실제 변경 전 저장의 호환 판정은 대표 구저장 로드·진행·재저장·재로드와 구분한다.

## 사건·뉴스와 표시 경로

새 정의는 [주둔 사건 파일](../events/HOK_KOR_us_defense_events.txt)의 `HOK_KOR_us_defense` namespace를 사용한다. 기존 `kor_events`·`newsk` ID를 재사용하거나 이름을 바꾸지 않는다.

현재 모듈은 사건·뉴스 6개, [scripted effect helper 5개](../common/scripted_effects/HOK_KOR_us_defense_effects.txt), [공통 scripted trigger 1개](../common/scripted_triggers/HOK_KOR_us_defense_triggers.txt)다. 현지화는 추가 키 없이 각 36키를 유지한다.

| ID | 수신·목적 | 표시 |
