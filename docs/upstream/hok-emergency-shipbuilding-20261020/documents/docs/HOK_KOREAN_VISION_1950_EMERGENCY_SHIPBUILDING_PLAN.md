# 비전 1950 긴급 특별 건함계획 설계·적용 명세

작성·적용: 2026-10-20. 상태: **구현·정적 확인 및 기록한 조건의 기능 검증 완료**.

비전 1950 중점을 완료하면 「긴급 특별 건함계획 시행」 디시전이 해제된다. 회당 정치력 150으로 「긴급 특별 건함계획」 국민정신을 즉시 180일간 부여하며, 함정과 수송선에 생산 비용 −50% 보정을 제공한다. 적용 중에는 목록에 표시하되 사용할 수 없고, 만료 후 추가 대기기간 없이 같은 비용으로 다시 사용할 수 있다. 사용 횟수에는 상한이 없다.

## 작업 범위와 기준 소스

최초 문서화 요청에 이어 사용자가 「AGENTS.md, /docs 읽고 구현해줘」로 구현을 요청했다. 이 명세는 그 후속 구현을 반영한다. 새 디시전·한시 국민정신·현지화·전용 이미지와 중점의 개별 해금 안내를 추가하며 기존 중점·국민정신·단계별 함대 목표는 보존한다. 커밋·푸시·릴리스·Workshop 업로드는 포함하지 않는다.

- 시작 브랜치: `feat/korean-focus-expansion-ai`.

- 최초 문서화 시작 시 작업 트리는 깨끗했다. 후속 구현은 앞서 작성한 README 수정과 미추적 설계 문서를 보존하고 진행했다.

## 사용자 지정 요구와 채택한 구현

| 항목 | 적용 명세 |
|---|---|
| 해제 조건 | 「비전 1950」 중점 완료 |
| 디시전 표시 이름 | **긴급 특별 건함계획 시행** |
| 국민정신 표시 이름 | **긴급 특별 건함계획** |
| 사용 비용 | 회당 **정치력 150** |
| 국민정신 효과 | **함정 및 수송선 생산 비용 −50% 보정** |
| 국민정신 지속기간 | 사용 즉시 **180일** |
| 반복 횟수 | **상한 없음** |
| 적용 중 표시·사용 | 목록에는 유지하고 사용 차단. 중첩과 남은 기간 갱신 없음 |
| 만료 후 사용 | 추가 대기기간 없이 같은 정치력 150으로 재사용 |

명칭·해금·비용·효과·180일·무제한 반복은 사용자가 지정했다. 수송선은 「보통 수송선에도 적용되지 않아?」라는 후속 답변을 반영해 포함했다. 적용 중 차단·만료 후 재개·중첩 및 갱신 방지는 설계에서 제안한 세부 방식을 후속 구현에서 채택한 것이다. 이를 사용자가 처음부터 별도로 지정한 조건으로 소급하지 않는다.

−50%는 `build_cost_ic = -0.5`라는 생산 비용 보정이다. 조선소 생산량 +50%, 해군 연구 비용이나 조선소 건설 비용 감소로 대체하지 않는다. 다른 생산 비용 보정과 합산되므로 이미 보정된 화면 비용이 항상 정확히 절반이 된다는 뜻도 아니다. 실제 MTG 활성 환경에서 기존 비용 +10%가 있는 VIIK는 495→270, IIK는 440→240으로 표시됐고 자연 만료 뒤 495·440으로 복귀했다. 관측 조건과 나머지 함종의 결과는 구현·검증 기록에서 관리한다.

## 디시전과 중점 연결

새 디시전 ID는 **`HOK_KOR_enact_emergency_special_shipbuilding`**, 국민정신 ID는 **`HOK_KOR_emergency_special_shipbuilding`**이다. 각각 [한국 디시전 파일](../common/decisions/KOR_decision.txt)과 [별도 국민정신 파일](../common/ideas/HOK_KOR_emergency_shipbuilding.txt)에 정의했다.

디시전은 기존 「비전 1950」 분류 안에 있다. `allowed = { tag = KOR }`, 표시 조건과 사용 조건의 `has_completed_focus = KOR_vision_1950`, 적용 중 사용을 막는 `NOT = { has_idea = HOK_KOR_emergency_special_shipbuilding }`를 사용한다. 비용은 150, `fire_only_once = no`, `days_re_enable = 0`이다. `complete_effect`에서 180일 국민정신을 즉시 부여하며 별도 사업 대기기간·180일 디시전 타이머·중복 삭제 효과는 두지 않았다. AI는 `factor = 1`로 같은 비용과 사용 조건을 따른다.

중점 완료 효과에는 `unlock_decision_tooltip = HOK_KOR_enact_emergency_special_shipbuilding`을 추가해 **「긴급 특별 건함계획 시행」 디시전 잠금 해제**를 명시한다. 기존 분류 전체를 새로 해제한다고 표시하지 않는다. 새 디시전에 기존 1~3단계 완료·함대 수량·전쟁·연도·정부 이념 조건은 추가하지 않았다.

새 국민정신은 기존 비전 1950 국민정신과 별개다. 후속 요청으로 강화한 조선소 생산량 +30%와 중점의 해군 경험치 50을 유지하며, 새 국민정신 만료 시 기존 국민정신을 함께 제거하지 않는다.

## 적용 함종과 문법 근거

8개 archetype 모두에 `equipment_bonus` 안 `build_cost_ic = -0.5`와 `instant = yes`를 지정했다.

| archetype | 적용 범위 |
|---|---|
| `ship_hull_light` | 구축함 등 경선체 |
| `ship_hull_cruiser` | 경·중순양함 및 같은 archetype의 특수 순양함 |
| `ship_hull_heavy` | 전함·순양전함·초중전함 등 중선체 |
| `ship_hull_carrier` | 항공모함·개장 항모 및 같은 archetype의 특수 항모 |
| `ship_hull_submarine` | 잠수함과 같은 archetype의 특수·핵·미사일 잠수함 선체 |
| `support_ship_hull` | 지원함 |
| `repair_ship_hull` | 수리함 |
| `convoy` | 수송선 |

미사일 장비 자체와 함재기는 대상에 추가하지 않았다. 설치본은 구형 명칭의 함정도 위 선체 archetype을 사용하므로 구형·MTG 이름으로 같은 대상을 중복 나열하지 않는다. MTG 활성 여부는 진단 조건에서 실제로 참임을 확인했다. DLC 비활성 조합의 적용을 확인한 것은 아니다.

설치 바닐라 `common/ideas/usa.txt`의 `bureau_of_ships_focus`가 전투함 5개 archetype 비용 감소와 `instant = yes`를 사용하고, Britain·USA 국민정신에는 수송선 비용 감소 사례가 있다. 설치 `documentation/effects_documentation.md:1180,1188`은 국민정신과 같은 장비 보너스 사용법과 즉시 적용을 설명한다. `instant`를 생략하면 신규 variant 생성에만 적용하므로 기존 설계의 즉시 변경 의도에 맞춰 명시했다. 기간제 반복은 설치 `common/decisions/ENG.txt`의 `ENG_request_trade_union_factory_worker_support`와 같은 구조를 따른다. 자세한 경로·행과 근거 한계는 구현·검증 기록에 정리했다.

## 검증 상태와 남은 범위

2026-10-20 후속 요청으로 기존 비전 1950 국민정신의 조선소 생산량을 +20%에서 +30%로 변경했다. 아래 86개 검사와 체크섬 0655의 실제 게임 관측은 이 강화 전 기록이다. 후속 수치 변경은 소스 차이와 보존 범위를 확인했으며, +30% 상태의 게임 실행은 별도로 수행하지 않았다.

소스·보존·참조·인코딩 검사는 **86 PASS / 0 FAIL**이며 이미지 정적 검수도 통과했다. 이는 엔진 전체 스키마나 모든 함종의 실제 비용 적용을 증명하지 않는다. 초기 최종 기능·자산 소스의 전체 재시작 후 1936 한국 일시정지 로드에서 기존 대비 새 정규화 오류가 없었다. 후속 수동 fixture로 조건을 준비하고 원래 정책 UI의 실제 사용을 확인했다. 진단 제거·정적 검사 재통과 뒤 최종 소스를 완전히 재시작하여 같은 신규 합성 저장의 재불러오기·자연 진행도 확인했다. 정상 선행 중점·35일 진행은 별도 미검증이다.

실제 클릭에서 정치력 500→350, 적용 중 사용 차단, 기존 보상과 8개 −50% 효과 표시, 수송선·수상함·잠수함의 7개 기존 설계 비용 감소를 확인했다. 국민정신 제거·기간 단축 명령 없이 시간을 진행해 6월 23일 적용 중, 7월 4일 만료·비용 원상복귀·정책 사용 가능을 관측했다. 정확한 6월 30일 만료 시각은 보지 못했다. 7월 4일 두 번째 실제 사용은 정치력 754→604와 새 12월 31일 만료일을 확인했다. 임의 횟수의 장기 반복까지 검증한 것은 아니다.

첫 사용 저장은 엔진의 최종명 변경 `errno 2`로 완료되지 않았지만 남은 원래 `_temp.hoi4`를 정상 Load UI로 직접 불러와 정치력·국민정신·남은 기간 유지를 확인했다. 최종 소스에서 이 합성 저장을 읽을 때의 삭제된 진단 ID 잔재 경고와 자동저장 이름 변경 실패를 별도로 기록했으며 조용한 로드라고 주장하지 않는다.

그 뒤 진단 없는 최종 소스를 `-debug` 없이 전체 재시작해 체크섬 **0655**, 기존 DLC 36개·모드 2개로 1936 한국 새 게임을 정상 UI에서 열었다. 일시정지 로드의 오류는 기준과 같은 **128개·고유 40개**, 새 정규화 오류 **0개**였다. 합성 저장 경고와 구분한 이 최종 새 게임 확인까지 완료했다. 설정·playset·로컬 descriptor의 작업 전후 해시도 같았다.

원래 중점의 정상 진행·보상 화면 해금 안내, 항모·지원함·수리함 등 전체 함종군의 실제 설계 비용, 모듈·개장·진행 중 생산선, 정상 최종명 저장 성공, 정확한 만료 시각·만료 직후 재사용, AI 장기 반복, DLC 비활성 조합, 변경 전 기존 저장 호환 및 멀티플레이는 미검증으로 남긴다.

이 문서는 적용 명세를 관리한다. 완료한 검사·UI 관측과 미검증 항목의 최신 상태는 [구현·검증 기록](incidents/2026-10-20-korean-emergency-shipbuilding.md)을 기준으로 삼는다. 과거 비전 1950이나 다른 한국 콘텐츠의 통과 기록을 신규 기능의 검증으로 사용하지 않는다.
