# 한국 지휘관 해금 이관 계획 — 다음 전쟁의 준비

**2026-11-14 후속 구현과 해당 범위 검증·설정 복원을 완료했다. 최종 다섯 파일은 정적 101 PASS / 0 FAIL이며 전체 재시작 재로드를 거친 기존 국뽕 지휘 유지 총 150시간·새 국뽕 중점 전 미해금 총 106시간을 확인했다.** 초기 네 파일의 세 설정 중점 완료·지휘·고문 검증은 해당 소스의 이력이다. 초기 기존 저장의 비표시·지휘 해제 재현 뒤 새 게임 표식과 기존 저장 보존 조건을 추가했고 최종 `6aa1`에서 각각의 표식·지휘 상태를 확인했다. 원래 설정 두 파일의 해시 일치와 시험 포인터 제거도 확인했다. 최종 로그에 기존 오류는 남으며 장기·다른 환경 검증은 별도 범위다. 이 이관의 후속 수정이나 검증 결과를 판단할 때 [구현·검증 기록](incidents/2026-11-14-korean-commander-unlock-transfer.md)을 먼저 읽는다.

## 2026-11-14 적용한 기존 저장 호환 조건

새 한국 게임은 국가 역사에서 `HOK_KOR_commander_focus_unlock_v1` 표식을 받는다. 기본·중견국·일반 국뽕 모두 이 표식이 있으므로 「다음 전쟁의 준비」 완료가 세 군사 역할의 해금 조건이다.

표식 도입 전 일반 국뽕 저장은 기존 국뽕 전역 플래그가 있고 새 국가 표식이 없을 때 세 군사 역할의 사용을 유지한다. 기존 배치·미배치 인물과 재배치를 함께 보존하기 위한 호환 조건이다. 강제 은퇴·재모집·기존 저장 표식 주입은 추가하지 않는다. 실제 시간 경과·미배치·재배치 검증 결과는 구현 기록에 남긴다.

아래는 2026-11-13의 합의와 구현 전 조사·계획을 보존한 이력이다. 당시 문서화 범위·미착수·미검증 표현은 해당 시점의 상태이며, 2026-11-14 구현과 후속 실행 결과는 위 기록을 따른다.

작성: 2026-11-13(KST). **문서화만 완료 / 게임 코드 미적용 / 실행 검증 미실시.**

사용자 요청은 홍범도·김좌진·안중근의 군 지휘관 해금만 국뽕 시작 옵션에서 「다음 전쟁의 준비」 중점으로 옮기는 것이다. 국뽕 옵션은 유지한다. 이 문서는 합의한 동작과 후속 구현 범위를 기록하며, 구현·게임 실행·검사 스크립트 실행·커밋·푸시·배포를 승인하지 않는다.

## 합의한 변경 후 동작

**세 군사 역할의 해금 조건을 「다음 전쟁의 준비」 완료로 단독 이전한다.**

아래 표는 변경 후 새 게임의 목표 동작이며, 현재 적용 결과가 아니다.

| 시작 설정 | 대상 중점 완료 전 | 대상 중점 완료 후 |
|---|---|---|
| 기본 | 세 군 지휘관 미해금 | 홍범도 원수·김좌진 장군·안중근 장군 해금 |
| 중견국 | 세 군 지휘관 미해금 | 같은 세 군사 역할 해금 |
| 일반 국뽕 | 다른 시작 강화 효과는 적용하되 세 군 지휘관은 미해금 | 같은 세 군사 역할 해금 |

홍범도 정치고문은 지금처럼 대상 중점 완료 후 고용할 수 있게 유지한다. 정치고문 자동 임명·무료 고용·새 참모 보직을 추가하는 계획은 아니다.

대상 중점은 민주주의 선행 분기로 접근한다. 해당 중점을 완료하지 않는 공산·파시즘·왕정 경로에는 이번 이관으로 별도 해금 수단을 추가하지 않는다. 다만 대상 중점 자체에 현재 정부가 민주주의여야 한다는 직접 조건은 없으므로, **완료 후 정권 변경을 이유로 지휘관을 회수하는 새 조건도 추가하지 않는다.** 도달 경로와 완료 후 유지 조건을 구분한다.

## 후속 구현의 범위와 보존 사항

1. 기존 세 인물의 원수·장군 역할에 있는 표시 조건만 대상 중점 완료로 연결한다. 인물 ID·역할 종류·기존 국가 역사 모집은 유지한다. 새 인물 생성·재모집·역할 중복 추가로 이관하지 않는다.
2. 레벨·세부 능력·특성·초상화·이름과 저장된 개인 상태를 보존한다. 해금 이관을 재균형이나 지휘관 재생성으로 확대하지 않는다.
3. 대상 중점의 기존 국민정신·정치고문 해금·기간·선행·후속 연결·좌표·아이콘·AI 가중치를 유지한다. [국민정신 정의](../common/ideas/korea.txt) 721행의 기존 효과와 [역사 AI 계획](../common/ai_strategy_plans/KOR_historical_strategy_plan.txt) 50행의 중점 목록도 유지한다.
4. 국뽕의 영토·핵심주·기술·연구 슬롯·산업·군대·보급 장비·일본 대응 병력과 중견국 옵션의 기존 효과는 유지한다. 국뽕 게임 규칙이나 시작 처리를 삭제하지 않는다.
5. 중점 완료 보상에서 국뽕 전역 플래그를 설정·삭제하지 않는다. 이 플래그는 [한국 중점](../common/national_focus/korea.txt) 550·631행의 연구 슬롯 중점 우회와 2117·2608행의 특수부대 보상 분기에도 사용된다. 지휘관 세 역할만 이 플래그 의존에서 분리한다.
6. 대상 중점 효과에 세 군사 역할의 이름·역할·해금 안내를 추가할 대상으로 기록한다. 기존 홍범도 정치고문 안내와 국민정신 보상은 보존한다. 안내 추가만으로 실제 해금이 구현됐다고 판단하지 않는다.
7. 국뽕 옵션 설명에서는 세 지휘관을 시작부터 보유한다는 문구를 제거할 대상으로 기록한다. 다른 시작 강화 설명은 유지한다. 본체 Korean·English 두 채널은 기존 계약에 맞춰 함께 반영해야 한다.

기존 국뽕 저장에서 이미 지휘 중인 인물의 표시·지휘 배치·경험치가 조건 변경 후 어떻게 남는지는 미확인이다. 이번 문서화는 강제 은퇴·부대 지휘 해제·재모집·경험치 초기화·자동 회수 또는 별도 저장 이관을 승인하지 않는다. 새 게임의 목표 동작과 구저장 호환 정책을 구분하고, 실제 영향이 확인되면 후속 범위에서 이관 여부를 별도로 정한다.

## 후속 구현 시 필요한 검증 — 이번에는 실행하지 않음

- **소스 대조:** 세 군사 역할만 완료 조건으로 바뀌었는지, 중점 보상 안내와 국뽕 설명 양 채널이 일치하는지 확인한다. 모집·특성·능력·국민정신·기간·연결·배치·AI·다른 국뽕 소비자의 보존을 별도로 대조한다.
- **새 게임과 UI:** 실제 버전·로드 순서·언어·DLC를 기록하고 전체 재시작한 후 기본·중견국·일반 국뽕 각각에서 중점 전 미해금과 완료 후 세 역할 해금을 확인한다. 실제 부대 지휘와 홍범도 정치고문 채용을 확인하며, 두 역할의 동시 사용 가능 여부를 소스 추정과 구분한다.
- **분기와 정상 진행:** 두 선행 정치 경로의 중점 접근, 실제 중점 완료, 미완료 다른 정치 경로의 차단을 확인한다. 완료 후 정권 변경을 새 회수 조건으로 처리하지 않았는지도 확인한다. 강제 완료 결과를 정상 진행 결과로 기록하지 않는다.
- **설정 보존:** 일반 국뽕은 중점 전 세 지휘관만 미해금이고 다른 시작 강화는 유지되는지 확인한다. 기본·중견국에서 중점 완료가 국뽕 전역 플래그를 켜거나 다른 국뽕 효과를 지급하지 않는지 확인한다.
- **저장:** 새 저장 재로드와 변경 전 저장 로드를 구분한다. 특히 국뽕 저장의 기존 지휘 배치·경험치, 기완료 중점 저장의 해금, 홍범도 정치고문 채용 상태를 대조한다. 기존 저장의 회수·이관 정책은 검증 전 확정하지 않는다.
- **언어·연동:** 본체 두 채널과 실제 활성 번역·서브모드의 덮어쓰기 여부를 확인한다. 이번에 읽지 않은 외부 사본까지 반영됐다고 간주하지 않는다.

검증이 별도로 승인되면 산출물은 `C:/hoi/test/<task-or-run-id>/` 아래에 둔다. 이번 문서화에서는 그 디렉터리나 helper·로그 사본·시험 저장·보고서 파일을 만들지 않았다. 소스 대조, 로드·UI, 실제 효과, 새 저장, 기존 저장, 장기 AI·다른 DLC·멀티플레이 결과는 각각 구분해 기록한다.

## 이번 문서화의 결과와 미실행 범위

저장소 소스 읽기로 현재 세 군사 역할의 국뽕 조건, 홍범도 정치고문 조건, 기존 모집, 국뽕 플래그의 관련 소비자, 대상 중점·국민정신·역사 AI와 본체 두 언어 채널의 관련 문구를 확인했다. 이 계획과 상위 계획의 발견성 링크만 문서 변경 대상으로 삼는다.

문서의 상대 링크 대상 파일 존재와 본문을 읽어 대조했고, 최종 diff·작업 트리에서 문서 두 개만 변경 대상으로 남았음을 확인했다. 이 문서 확인을 게임 코드 검사나 실행 검증으로 계산하지 않는다.

게임 코드·현지화 파일·자산·설정은 변경하지 않는다. 검사 스크립트·게임·진단·저장 이관·패키징·정리·커밋·푸시·업로드는 실행하지 않는다. **이관의 구현 상태는 미착수이며 UI·효과·저장 호환성은 미검증**이다.
