# 한국 중점 선행 조건 가독성 개선 계획

작성: 2026-10-10. 상태: **여섯 중점 코드 적용 / 정적·초기 UI 확인 / 정상 진행 검증 대기**.

연결선에 없는 완료 조건 때문에 중점을 눌러 본 뒤에야 추가 선행을 알게 되는 문제를 줄인다. 사용자 지정안은 원료 광종분류의 두 선행을 모두 연결하고, 나머지 다섯 시작 중점에서는 지정한 완료 조건 하나씩만 삭제하는 것이다. 원료 광종분류는 기존 완료 요구를 유지하는 표시 개선이고, 다섯 조건 삭제는 진입을 완화하는 의도적인 진행 변경이다. 초기 요청은 문서화 작업만이었으며, 2026-10-10 후속 요청에서 이 여섯 중점의 구현을 승인해 적용했다. 실제 확인 범위와 남은 검증은 [구현 기록](incidents/2026-10-10-korean-focus-prerequisite-readability.md)을 따른다.

## 현재 소스와 요청 범위

기준 저장소는 `C:/hoi/hearts_of_korea`, 브랜치는 `feat/korean-focus-expansion-ai`, HEAD는 `062a60287e00ac11352c38bca0fca1ae556e7801`이다. 문서화 시작 시 작업 트리는 깨끗했고 한국 중점은 460개다. 아래 행 번호는 이 기준의 [한국 중점 소스](../common/national_focus/korea.txt)를 가리킨다.

기존 개발 기록의 대상은 HOI4 `1.19.3.0.c01a`이며 descriptor는 `1.19.*`와 `Korean Language` 의존성을 선언한다. 초기 문서화에서는 게임을 실행하지 않았다. 후속 구현에서는 설치본 1.19.3·build 25205862와 저장소 직접 로드 경로를 확인하고 한국 새 게임(체크섬 92cd, DLC 36개·모드 1개)을 실행했다. 별도 Korean Language는 실제 활성 목록에 없으며 상세 구성·로그·검증 한계는 구현 기록에 분리했다.

제공된 원료 광종분류 화면에는 운산 금광에서만 연결선이 내려오지만 함경도 지하자원 개발 완료도 별도 요구 사항으로 표시되어 있다. 소스의 `prerequisite`와 `available` 구분이 이 화면과 일치한다. 구현 전 다른 다섯 항목도 소스상 별도 완료 조건을 가지고 있었다. 이 사실과 아래 변경안의 구현·게임 검증 상태를 구별한다.

범위는 아래 여섯 시작 중점이다. 다섯 항목의 선행을 다른 중점으로 교체하거나 모두 AND로 연결하는 이전 제안은 적용안에 포함하지 않는다. 다른 중점, 후속 단계, 보상, 기간, 국민정신, 결정, AI 가중치, 이미지, 국가·주·지도 ID와 외부 배포 설정은 변경 대상이 아니다.

기존 명세의 ‘총리 지명’은 현재 화면 이름이 **공화주의자들과의 화해**인 `KOR_nomination_prime_minister`를 뜻한다. 이름과 ID를 바꾸는 작업이 아니다.

## 유지할 착수 조건과 보상

모든 대상에서 내전 없음, 기존 `cancel_if_invalid = yes`, `continue_if_invalid = no`, `available_if_capitulated = no`를 유지한다. 국민 법률구조망·황실 공익후원은 민주정부와 `KOR_nomination_prime_minister` 완료를 유지한다. 군정 실무편람·삼군 연락사무국은 파시즘 정부와 을해군란 `KOR_establishment_of_the_national_salvation_army` 완료를 유지한다.

군정 실무편람에는 우리 핵심이 아니며 전역을 완전히 통제하는 주가 최소 하나 존재해야 하는 조건을 그대로 둔다. 세계위에 군림하는 대한 조건을 제거하더라도 실제 비핵심 완전 통제 없이 점령행정을 시작하도록 바꾸지 않는다.

각 중점의 35일 기간과 완료 보상, 후속의 병렬·AND 합류 구조, 국민정신 승계 및 기존 결정 해금은 유지한다. 특히 원료 순환체계의 영구 I·II와 긴급 반복 결정은 [현행 원료 순환 명세](HOK_KOREAN_MATERIAL_CYCLE_REWARD_SPEC.md)의 보상·비용·기간·재사용·취소 규칙을 유지한다. 이번 진입 조건 변경을 이유로 보상을 삭감하거나 추가하지 않는다.

## 남는 조건과 후속 단계

**삼군 연락사무국의 을해군란 완료 조건은 여전히 연결선 밖에 남는다.** 선군주의 삭제만으로 모든 착수 조건이 선행선에 표시되는 것은 아니다. 을해군란 연결 추가나 조건 삭제는 이번 지정안에 포함하지 않는다.

군정과 삼군 조정의 후속 세 중점에도 삭제 대상 조건이 반복되어 있다. 여섯 시작 중점만을 대상으로 하는 현재 범위에서는 다음 항목을 보존한다.

## 진행 시점과 배치

원료 광종분류는 두 광산 모두를 요구하는 정상 진행 조건을 유지한다. 운산 금광을 기준으로 하는 기존 상대 배치와 두 부모의 기본 위치를 먼저 보존하고, 함경도에서 내려오는 추가 합류선이 개마고원 목축업 지원과 인접 아이콘·명판·연결을 가리지 않는지 확인한다. 초기 HIDE 확대 화면에서 추가 합류선이 두 광산·원료·개마고원 아이콘과 명판을 가리지 않는 것을 관측해 기존 좌표를 유지했다. SHOW·정치 선택 이후·완료 상태 검증은 별도로 남는다.

나머지 다섯 중점은 기존 연결선과 배치 기준을 유지하는 안이다. 앞선 ‘추가 조건을 모두 선행으로 연결하는’ 제안에 필요한 넓은 재배치를 이번 안의 필수 작업으로 가져오지 않는다. 코드의 선행을 수정하는 것과 `relative_position_id`로 위치를 지정하는 것은 별개다.

수출거래 명세는 경공업 수출 지원을, 국민 법률구조망은 사법부의 독립 보장을, 황실 공익후원은 현대의 세종대왕을 완료하기 전에 시작할 수 있도록 바뀐다. 군정 실무편람·삼군 연락사무국은 시작 중점의 조건만 완화하며 후속의 기존 완료 조건은 유지한다. 시작 중점을 미리 마치면 조건 충족 뒤 후속 보상에 도달하는 시점도 앞당겨질 수 있지만, 후속의 별도 제한이 삭제되는 것은 아니다. 조건 대기·실제 영토·정부 상태와 기존 중점 진행에 따라 차이가 있으므로 모든 경로가 일괄 35일 빨라진다고 표현하지 않는다. G1·G2 각 175일, C2 140일, C3 105일, F4·F5 각 140일의 모듈 자체 기간은 유지하되, 전체 실제 소요 시간에는 남은 선행과 대기가 포함된다.

## 구현 후 확인할 항목

다음은 이번 변경의 확인 범위다. 실제 수행한 검사와 아직 남은 항목은 아래 결과와 구현 기록에 구분한다.

- 원료 광종분류에서 운산만 완료, 함경도만 완료, 둘 다 완료한 상태를 구분한다. 양쪽 선과 ‘모두 필요’ 안내, 중간 합류·클릭 영역, 개마고원 목축업 가지를 SHOW와 HIDE에서 확인한다.
- 나머지 다섯 시작 중점은 제거한 중점이 미완료여도 남은 조건을 만족하면 정상 UI로 착수할 수 있어야 한다. 내전·정부·항복·영토와 을해군란 조건을 각각 유지하는지도 확인한다.
- F4·F5의 후속 세 중점에 남은 조건이 미완료일 때 차단되고, 해당 기존 중점 완료 뒤 진행할 수 있는지 구분한다. 시작 중점 완화와 가지 전체 해제를 혼동하지 않는다.
- 중점 ID·개수·기간·보상·AI 가중치·기존 좌표·offset·국민정신·결정·현지화를 대조하고, 의도한 선행 관계와 착수 조건 외의 변경을 제한한다. 실제 수정한 생산 텍스트에는 구현일의 기여자 주석을 적용한다.
- 강제 완료와 정상 35일 진행, 실제 AI 선택·저장 재로드·기존 저장·DLC·멀티플레이 확인을 구분한다. 과거 확장 검증을 이번 변경안의 검증으로 재사용하지 않는다. 새 테스트·증거 파일은 `C:/hoi/test/<task-or-run-id>/`에 둔다.

## 적용 및 검증 결과

여섯 시작 중점의 선행·가용 조건을 적용하고 README·관련 명세·2차 계획·후보 JSON을 동기화했다. 정적 38 PASS / 0 FAIL과 독립 diff 검토, git diff --check를 통과했다. 새 게임 error.log의 신규 정규화 오류는 0건이며 원료의 모두 필요 안내·확대 연결선과 다른 다섯의 삭제 조건 표시를 실제 초기 화면에서 확인했다. 보상·기간·AI·좌표·offset·후속의 반복 조건은 보존했다.

콘솔 자동 키 입력이 반영되지 않아 사용자에게 수동 콘솔 도움을 요청했다. 단일 광산 완료·양쪽 완료의 착수, 다섯 시작 중점의 실제 착수·35일 진행, 조건 상실 취소·SHOW·정치 선택 이후 상태·AI·저장·다른 DLC·멀티플레이는 미검증이다. 게임을 진행하거나 저장·커밋·푸시·업로드하지 않았다. 자세한 증거와 소스·환경은 [2026-10-10 구현 기록](incidents/2026-10-10-korean-focus-prerequisite-readability.md)을 따른다.

과거 검증은 [만주와 공통 명세](HOK_KOREAN_REGIONAL_COMMON_FOLLOWUP_SPEC.md), [입헌 명세](HOK_KOREAN_CONSTITUTIONAL_FOLLOWUP_SPEC.md), [파시즘 후속 명세](HOK_KOREAN_FASCIST_FOLLOWUP_SPEC.md), [2차 확장 현황](HOK_KOREAN_SECOND_WAVE_PLAN.md)의 해당 소스 이력으로 보존하며 이번 변경의 정상 진행 검증으로 재사용하지 않는다.
