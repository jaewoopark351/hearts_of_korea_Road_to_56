시작 민공·군공·조선소 총 **9·4·1**과 공군기지·프로빈스 건물·승점 총량을 유지한다. 기반시설은 각 후속 주에 부모의 초기 레벨을 유지하므로 주별 레벨 합은 늘며, 향후 양쪽을 각각 건설해야 한다. 양쪽 카테고리는 부모와 같은 등급이다. 기본 공유 슬롯 합은 **33 → 57**이고 전역 공유 슬롯 25·종류별 20 제한은 변경하지 않는다. 기술·국가 보정과 추가 슬롯을 적용한 실제 슬롯 수와 구분한다.

12개 후속 주는 `HOK_KOR_STATE_<id>` 표시명 키를 사용한다. 기존 `STATE_<id>` 정의는 외부 번역·호환 참조용으로 남긴다. 별도의 한영 헤더 현지화 파일에 같은 한국어 본문을 넣어, 활성 번역 모드가 기존 동명 파일을 덮어쓰는 문제를 피한다. 쓰시마 주 1085가 이미 쓰는 `STATE_1088`은 그대로 보존한다.

옛 도 전체 소유·통제 조건은 두 주의 AND, 주 후보 집합의 membership은 OR로 이전한다. 고정 총보상은 복제하지 않는다. 포항은 경북, 부산·남동임해공업은 경남, 운산은 평북으로 연결한다. 제주 제외·경기 포함 등 기존 집합 예외를 보존한다. 기존 중점에 남은 새만금의 충청 지정 등 별개의 지리 오류는 별도로 기록한다.

### 적용한 콘텐츠와 지도 연결

- 한국 중점 474개 중 지역 참조 24개를 검토하고 23개를 수정했다. ID·배치·상대 기준·offset·선행·상호 배타·비용·AI·기존 비지역 보상과 해금 안내는 보존했다. 대구 프로빈스 13436을 수도로 삼는 중점은 경북 1030을 유지한다.
