### 표기 규칙

1. 목표란 숫자는 특별히 추가라고 쓰지 않은 한 **변경 후 최종값**이다. 기존 정치력25를 목표100으로 바꾸면 지급량은100이며125가 아니다.
2. 기본 안정도 획득은 완료 즉시 지급하는 `%p`다. 국민정신의 안정도 보정과 별개로 기록한다. 일일 정치력은 퍼센트가 아닌 고정 일일값이다.
3. `2회 × 150%`는 해당 연구 혜택을 두 번 사용하는 설계다. 기술 대상 두 줄과 사용 횟수 두 번을 혼동하지 않는다. 모든 연구에 영구 +150%를 주거나 즉시 기술을 지급하는 뜻이 아니다.
4. 같은 계열의 상위 국민정신은 `swap_ideas`로 교체한다. 최종값과 UI의 효과 변화는 다르다. 별도 계열 국민정신은 함께 적용될 수 있다.
5. 반복 무제한은 **완료 횟수 상한 없음**이다. 무료·무조건·동시 무한 실행 또는 무제한 수정치 중첩을 뜻하지 않는다.

후속 신규 개발과 강화 작업에는 [중점 보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)을 함께 적용한다. 체감되는 강한 보상, 기존 혜택 보존, 상위 단계 승계와 사업 비용을 공통 기준으로 삼으며, 아래 1차 설계의 개별 수치와 적용 이력은 구분해 보존한다.

## 4. 이미 강화한 전력 3개와 단계 승계

| 기존 반영 항목 | ID | 현재 효과 및 유지 목표 |
|---|---|---|
| 전국 전력망 연계 | `HOK_KOR_link_power_grids` | 공장 에너지 소비 -10% |
| 산업용 전력 배분 | `HOK_KOR_industrial_power_allocation` | -10%에서 최종 -20%로 교체 |
| 국가전력조정위원회 | `HOK_KOR_national_power_coordination` | -20%에서 최종 -30%로 교체 |

전력은 설계 전부터 적용된 값이며 이 문서의 신규 강화가 아니다. 설계 당시 숙련 단계는 +10%/+20%였고, 후속 구현에서 목표 +30%/+60%를 적용했다.

| 계열 | 강화안의 하위 → 상위 최종값 | 교체 시 증가분 / 보존 효과 |
|---|---|---|
| 전력 | -10% → -20% → -30% | 각 단계 -10%p; 세 단계 합계 -60%가 아님 |
| 숙련 | 성장 +30% → +60% | +30%p; 최종 +90% 누적 아님 |
| 참모 | 계획 속도 +10% → +20% | +10%p; 최종 협동 +6% |
| 양산 | 상한 +15% → +30% | +15%p; 전환 유지 -5% 보존 |
| 유연생산 | 유지 +20% → +40% | +20%p; 상한 -2.5% 보존 |
| 항공 | 임무 효율 +10% → +30% | +20%p; 항공정비 사고 감소는 별도 유지 |
| 군수 조달 | 상한 +3% → +10% | +7%p; 보병장비 생산 +10%를 양 단계에 승계; 최종 보급 -10% |
| 민주 행정 | 일일PP +0.25 → +0.25 | 감찰을 결산으로 교체해도 정치력 감소 없음; 국민정신 안정도 +2% 추가 유지 |

32번에 사용자 지정한 즉시 안정도 +10%p와 국민정신의 안정도 +2%는 별개다. 일일PP +0.25 승계는 51번 제안을 보존하기 위한 연계 설계이며 사용자의 원래 32번 숫자로 표기하지 않는다. 야간학교 연구 +10%는 숙련 계열에 섞지 않고 별도 효과로 두어 숙련 국민정신 교체로 사라지지 않게 한다.

| 함께 보유하는 별도 효과 | 이 설계에서의 합계 |
|---|---|
| 야간학교 +10% + 농촌교육 +10% | 영구 일반 연구 속도 +20% |
| 양산 최종 상한 +30% + 군수창 상한 +10% | 생산효율 상한 +40%; 기존 한국의 다른 보정은 별도 |
| 군수창 보급 -10% + 의용군 보급 -10% | 한국 육군 전체 보급 소비 -20% |
| 기존 대한의용군단 수량 +3 + 온건외교 중단 추가 +5 | 두 국민정신의 추가 파병 수량 +8; 국가의 최종 총한도 자체가8이라는 뜻은 아님 |

이 표는 명시된 수정치의 합산만 설명한다. 실제 생산량·연구 완료일·파병 가능 수량이 같은 비율로 바뀐다는 보장이 아니며, 다른 국가 보정과 기술·게임 조건까지 포함한 최종값은 구현 후 확인한다.

## 5. 반복 결정의 구체적 설계

### 지역 공업 투자 4개

대상은 [산업 결정 파일](../common/decisions/HOK_KOR_industry_expansion.txt)의 `HOK_KOR_pyeongan_industry_project`, `HOK_KOR_gangwon_industry_project`, `HOK_KOR_chungcheong_industry_project`, `HOK_KOR_gyeongsang_shipbuilding_project`다.

- 각 사업은90일, 회당 정치력150과 민간공장5 사용, 기존 건물1개·공유 슬롯1개 보상을 유지한다. 완료 후 같은 사업을 다시 선택할 수 있도록 한다.
- 설계 당시에는 `fire_only_once = no`여도 완료 플래그가 `visible`과 `remove_effect`를 막았다. 완료 플래그 설정 한 줄 또는 기간만 수정해서는 반복형이 되지 않는다. 양쪽 게이트와 기록 의미를 함께 정리한다.
- 같은 지역의 한 진행 사업을 중복 착수하지 않고 완료 또는 취소 후 다음 사업을 허용하는 순차 반복을 기본안으로 둔다. 서로 다른 지역의 병행 가능 범위는 기존 구조와 공장 가용 조건을 유지한다.
- 소유권·완전통제·건설 부지·항복 여부를 착수·진행·완료 시 확인한다. 조건 상실 시 취소하고 정치력 환불은 기존처럼 하지 않으며, 다음 착수에는 비용을 다시 낸다. 취소를 정상 완료로 취급해 공장을 지급하지 않는다.
- 예전 세이브의 완료 플래그가 남아도 횟수 상한을 다시 만들지 않도록 검사 지점을 정리한다. 플래그 ID 삭제나 대규모 세이브 재작성부터 하지 않는다.
- 횟수 제한 해제는 엔진의 건물·슬롯 최대치나 기존 건설 가능 조건까지 무시한다는 뜻이 아니다. 슬롯 추가와 가용 부지 검사의 순서를 확인하고, 부지 부족 때 비용만 내고 공장을 잃는 경로를 재검증한다.

### 관세협약

[민주 결정](../common/decisions/HOK_KOR_democratic_expansion.txt)의 `HOK_KOR_offer_customs_convention`은 현재도 횟수 상한 없는 제안형이다. 설계는 최종 수입 비용 -30%로 강화하고, 정치력25·같은 대상180일 간격·상대국 수락/거절·유효 협정 중복 금지·730일 지속을 유지한다. 할인은 **수락국이 한국에서 수입하는 거래**에 적용한다. 한국의 모든 수입이나 세력 회원국 사이 모든 거래로 범위를 넓히지 않는다. 한국 민주정/지도국 지위 상실, 세력 이탈, 양국 교전 등 기존 취소 조건을 유지한다. 반복 제안할 때 -30%씩 영구 중첩시키지 않는다.

### 아시아 공동개발기금

대상은 `HOK_KOR_finance_allied_industry`다. 설계 당시에는 전체2회 변수, 상대국별 착수 기록, `fire_only_once`, 완료 보상 가드가 함께 반복을 제한했다. 모두 검토하여 **동일 국가에도 완료 후 재투자 가능**하게 한다. 이는 지역 사업과 달리 **180일 유지**다.

- 회당 정치력75·민간공장2 사용·상대국 민간공장1개와 공유 슬롯1개 지급을 유지한다. 한국에 공장을 주는 사업으로 바꾸지 않는다.
- 전체 사업 카운터는 횟수 상한으로 사용하지 않는다. 과거 카운터·committed/completed 플래그가 새 시도를 막지 않도록 설계한다.
- 영구 1회 제한과 진행 중 사업 표시는 분리한다. 한 사업의 보상은 한 번만 지급하고, 완료/취소 후 같은 대상에 다음 사업을 허용한다. 무제한 동시 착수를 뜻하지 않는다.
- 현재의 동맹·관세협약·민주정·독립·세력지도국·부지 조건과 취소/완료 재검사를 유지한다. 취소 시 비용 환불 없이 새 비용으로 재시도하는 기본안이다.
- 성공 완료, 취소, 상대국 소멸, 소유권 변경, 완료 시 부지 부족의 모든 종료 경로에서 진행 잠금이 남지 않아야 한다. 상대국별 1회 제한 해제가 사업별 중복 보상으로 이어지지 않게 한다.

55번 현장 전훈 교류회는 반복 해제 대상이 아니다. 기존 정치력35·30일·1회·실전 또는 의용군 파병 조건을 유지하고 성공 보상을 경험치25로 강화한다. 의료/구호 원조 결정 역시 기존 비용·재사용 간격·재고 차감과 이전량을 유지한다.

연구 횟수를 늘리는 중점은 완료 시점의 미연구 대상 수를 확인한다. 산악 `tech_mountaineers/tech_mountaineers2`, 무전 `radio/improved_radio`, 해병 `marines/marines2`처럼 대상이 좁은 혜택은 기연구 기술 때문에 두 사용분을 모두 소비하지 못할 수 있다. 기본안은 기존 연구 범위를 유지하며, 쓰지 못하는 혜택을 근거 없이 다른 기술·경험치로 자동 전환하거나 연구 범위를 조용히 확대하지 않는다. 구현 전에 이 제한을 실제 UI와 대상 버전 기술 목록으로 확인한다. 23번의 선행연구 완화도 해당 DLC에서 실제 전투기 연구에 적용되는지 검증한다.

15번 보병장비 생산량 +10%는 **보병장비 한정**이라는 의도를 보존해야 한다. 설치본의 `equipment_bonus` 안 `build_cost_ic = -0.1` 사례는 비용 감소이며 생산량 +10%와 같은 수치가 아니다. 국가 전체 군수공장 생산량 +10%로 바꾸면 적용 범위가 달라진다. 현행 버전의 장비 한정 생산량 표현을 확인하기 전에는 그 키가 존재하거나 구현이 완료됐다고 기록하지 않는다. 정확한 표현이 없으면 가능한 대안과 수치 차이를 별도 설명하고 최종 방식을 정한다.

30번은 경기525·전라1082·충청1031에 민간공장 각2, 총6개 추가다. **기존 전자공학 1회 ×25%는 유지**한다. 구현 기본안은 각 주에 필요한 공유 슬롯2개와 즉시 완공 보상을 함께 제공하고 소유·통제를 확인하는 것이다. 설계 당시 미정이었던 미소유/미통제 주의 처리 정책은 후속 승인으로 확정했다. 세 주 모두 한국 소유·완전통제·필요 부지를 충족할 때 중점 착수를 허용하고 완료 시에도 재검사하며, 다른 주로 대체 지급하지 않는다. 무조건 주 ID에 건물을 넣어 타국을 강화하거나 일부 보상을 조용히 생략하지 않는다. 역사 파일의1939 소유 변경도 검사한다. 주 ID·지도·역사 파일을 바꾸는 설계는 아니다.

25번 우방 항공기술 도입의 설명 초안: “우방의 공개 기술자료와 항공기 제작·정비 경험을 도입하여 국내 연구진의 개발을 지원하겠습니다. 완성된 전투기 설계나 특정 국가의 비밀 기술을 직접 넘겨받는 대신, 확보한 자료를 우리 공군의 요구에 맞게 연구하고 시험할 것입니다.” 현재 조건은 같은 정부의 비적대 강대국이며 미국 전용 또는 동맹 가입 조건이 아니다. 기존 조건을 유지하고 실제 완료 효과인 항공장비 연구 2회 ×75%와 공군 경험치15를 설명한다.

59번은 수락국과 한국 사이의 양방향 관계 수정치다. [관계 수정치](../common/modifiers/HOK_KOR_democratic_expansion.txt)의 `license_production_speed`와 `license_tech_difference_speed`만 각각0.1→0.3 목표다. `ai_license_acceptance = 20`, `license_purchase_cost = 0`은 보존한다. 전자는 수락 확률20%가 아니고 후자를 무료 면허라고 해석하지 않는다. 상대국 동의,730일, 대상별180일 재제안 간격, 실제 면허 계약 필요, 기존 취소 및 양방향 제거 처리를 유지한다.

- **적용:** 중점 37개의 완료 보상, 관련 국민정신·결정·관계 수정치와 산업/군사/민주 현지화 3쌍(6개 파일)을 갱신했다. [현행 60개 명세](HOK_KOREAN_FOCUS_FIRST_60_SPEC.md)는 실제 적용값을 반영한다. 기존 326개 중점의 ID·기간·배치·연결·상호배타·AI 가중치는 보존했다.
