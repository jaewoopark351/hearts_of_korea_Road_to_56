# 한국 중점 2차 확장 — 전체 구성과 첫 정책 묶음

작성: 2026-09-22. 대상: 설치본 HOI4 1.19.3. 의도적인 후속 콘텐츠 개발이며 호환성 복구와 구분한다.

**현재 코드 적용: 기존 326개 + 2차 확장 134개 = 460개.** 공산 28개·파시즘 24개에 이어 입헌 14개·전제 14개·환제국 14개·만주 20개·공통 산업군사 20개를 적용했다. 이번 82개는 기존 378개를 보존하고 새 국민정신 32개·주 단위 동적 변동치 12개·사업 4개를 포함한다. 2차 확장 누계는 국민정신 63개·기간제 사업 18개이며, 주 단위 변동치는 국민정신 수와 별도로 센다. 적용 수량은 트리에 정의된 수이며 정치·외교·영토의 기존 배타 경로 때문에 한 게임에서 전부 완료하는 수가 아니다. 이번 검증 상태는 [잔여 확장 작업 기록](incidents/2026-09-23-korean-remaining-followup.md)을 따른다. 전체 정상 플레이 검증 완료를 뜻하지 않는다.

공산의 지도자별 첫 묶음은 각각 한 쌍의 정책 배타 선택을 유지하고 후속 내정·기술보급은 병렬로 접근한다. 파시즘 F1~F6는 각 4개이며 F4의 참모업무 조건·F6의 예산 배타 선택을 보존한다. 신규 왕정·공통 모듈은 독립된 짧은 병렬 가지로 설계했으며 만주 M2·M4는 기존 다민족 포용/추방 경로의 배타성을 따른다. 상세 조건은 [입헌 명세](HOK_KOREAN_CONSTITUTIONAL_FOLLOWUP_SPEC.md), [전제·환제국 명세](HOK_KOREAN_ROYAL_FOLLOWUP_SPEC.md), [만주·공통 명세](HOK_KOREAN_REGIONAL_COMMON_FOLLOWUP_SPEC.md), 기존 정치 묶음의 명세를 함께 읽는다.

묶음의 확정 기준은 정책 선택 또는 운영 기능, 기존 보상과의 합계, 실제 연결점, 실패·취소·복구 처리, 이미지·좌표·AI·검증 조건이다. 단순 행정 절차만 나열한 입헌 사법·만주 정착 초안은 상시 제도·연구·반복 운영사업을 포함하도록 재설계했다. 기존 기관 ADD·KAI·팔도 개발·함대 목표는 다시 만들지 않았다.

## 잔여 82개 검증 현황 — 2026-09-23

후속으로 H1 시작 이름판을 가로지르는 기존 상호배타선을 수정한 뒤, 사용자 요청에 따라 네 중점을 오른쪽 상단 공간으로 다시 옮겼다. 현재 `1cedaf78…2b6735c`는 시작 (211,5) → (210,6)/(212,6) → (211,7)이며 계연수 축출과 시작 높이를 맞췄다. 소스 보존 10/0·배타선 포함 20상태 모델 접촉 0건은 [오른쪽 배치 기록](incidents/2026-09-23-hwan-focus-right.md)을 따른다. 현재 위치의 실제 SHOW/HIDE 검수는 컴퓨터 제어 연결 장애로 미완료다. 직전 `dd2334a0…85613b4`의 (185,10) 배치와 화면 관측은 [이전 H1 수정 기록](incidents/2026-09-23-hwan-focus-layout.md), 아래 검증 횟수는 그보다 이전 `905a3868…1ccf852`의 통합 이력이다. 통합 당시 모델은 배타선을 누락했으며 이전 화면·보상 결과를 새 소스 재실행으로 주장하지 않는다.

통합 정적 검사 **896 PASS / 0 FAIL**, 좌표 검사 **335 PASS / 0 FAIL**이다. 진단 없는 최종 새 게임 `clean-03`은 체크섬 `9787`로 로드했고 이전 사용자 로그의 고유 오류 40개 대비 신규 0개였다. 최종 강제 보상 검사 1,213개와 사업 즉시 검사 147개는 합계 **1,360 PASS / 0 FAIL**이며 정상 진행과 구분한다. 측정 probe 8개는 별도이고, A1의 PP 전용 첫 중점 시점에 관측된 +0.05 안정도 집계 갱신의 정확한 원인은 미확정이다.

실제 날짜 진행에서는 C1 첫 중점의 UI 시작·35일 완료와 M1 UI 정치력 150·90일 자연 만료를 확인했다(10/0). C4 세력 이탈에 따른 정신 제거와 M2 민주정부 상실에 따른 취소·제거는 7/0이다. M1의 통제 상실 후 자동 취소·탈환만으로 복구되지 않음·90일 공통 대기 만료·UI 재착수 정치력 150·II와 기간제 복구는 15/0이다. 별도의 소유권 상실·취소·제거·재확보 후 비자동 복구 검사는 8/0이다. 경로·영토·조건 상실은 별도 새 게임에서 합성 준비했으므로 정치·정복 경로 전체의 정상 진행으로 표현하지 않는다.

HIDE 1600×900·GUI 1.0에서 C1~C4, H2/H3/H4, M1~M4와 G3 전체, G1 연결 전체, 전제 일부를 관측했으며 해당 영역의 새 명판·선 겹침은 없었다. G1 시작 아이콘은 화면 상단에 걸려 있었다. 만주 바로가기는 기존 시작 중점 제목이 하단에 걸리지만 스크롤로 신규 전체에 접근할 수 있다. 나머지 영역·SHOW·정치 전환의 이동·전체 패널, 남은 정상 중점 진행·연구 사용·사업 UI 수명·장기 AI·저장·다른 DLC·멀티플레이는 미검증이다. 기존 저장 13개·설정·플레이세트와 production 파일을 보존했고 검증 게임·임시 진단은 정리했다. 상세 실패·진단 보완·실행별 범위는 [최종 작업 기록](incidents/2026-09-23-korean-remaining-followup.md)을 따른다.

보상은 [중점 보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)에 따라 충분히 강하고 체감되게 설계한다. 이번 연구 150%·100%, 건설 +15%, 생산 +10%, 일일 정치력 +0.5·+1.2는 참고 사례이며 모든 중점의 공통 하한은 아니다. 기존 효과와 상위 단계 승계를 보존한다. 위 후보의 문제는 수량 채우기와 묶음 전체의 선택·운영 부족이며, 의미 있는 단일 보상 자체를 금지하는 뜻은 아니다.

## 작업 순서와 요청 범위

2026-09-23 사용자 요청으로 지금까지의 진행 방식을 명문화한다. 공산 확장은 10개 → 9개 → 9개, 파시즘은 4개 → 4개 → 4개로 나누어 명세·구현·검증 기록을 이어왔다. 구현한 수량과 실제 플레이 검증 완료 여부는 구분하며, 현재 상태는 위 적용 현황과 각 묶음의 최신 작업 기록을 기준으로 판단한다.

1. **현재 작업부터 확인한다.** AGENTS.md와 관련 명세·작업 기록, 브랜치·커밋·미커밋 변경을 읽고 완료된 구현과 남은 검증을 구별한다. 과거 326개 계획을 다시 인용하더라도 현재 적용분을 다시 만들지 않는다.
2. **다음 정책 묶음을 상세화한다.** 대체로 3~5개 규모의 일관된 정책 묶음을 작업 단위로 삼아 이름·ID·진입점·선행조건·기간·보상·국민정신·필요한 결정·AI·이미지·좌표·검증 조건을 정한다. 공산 첫 10개처럼 서로 다른 경로의 묶음을 함께 다룰 수 있으며, 이 크기는 할당량이나 요청된 전체 작업을 중단하는 기준이 아니다. 후보 JSON의 임시 보상과 직렬 연결을 그대로 적용하지 않는다.
3. **승인된 범위의 묶음을 연결까지 구현한다.** 중점과 필요한 국민정신·결정·현지화·이미지·배치·AI를 함께 완성한다. 기존 이점을 보존하면서 [보상 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)에 맞는 체감되는 혜택을 설계하고 상위 정신 승계를 확인한다. 독립 정책은 병렬로 배치하되 실제 정치·영토·단계 조건은 유지한다. 이미지는 프로젝트 내부 파일과 상대경로로 연결하고, 디시전에는 별도 소형 이미지를 사용한다.
4. **검증 종류를 나누어 확인한다.** 소스·참조·좌표의 정적 검사, 강제 완료를 통한 보상 검사, 진단 없는 새 게임 로드, 실제 화면과 정상 진행을 각각 기록한다. 해당 변경에 필요한 비용 차감·만료·취소·재착수·정신 교체·양쪽 진행 순서도 확인한다. 강제 완료 통과나 조용한 로그를 정상 플레이 검증으로 대신하지 않는다. 실행 중인 사용자 세션과 기존 저장을 보호한다.
5. **결과와 미검증 범위를 남긴다.** 명세·좌표·이미지 출처와 작업 기록을 실제 변경에 맞춰 갱신한다. 검사한 소스와 환경, 통과·실패·수정 내용 및 실제로 막힌 검증을 구별한다. 구현 완료를 해당 경로 전체의 플레이 검증 완료로 표현하지 않는다. 필요한 검증을 단순히 미검증 목록에 넘기는 것으로 작업을 끝내지 않는다.
6. **커밋·푸시는 요청된 때 수행한다.** 명시적으로 요청된 범위만 커밋·푸시하고 커밋 제목과 본문은 모두 영어로 쓴다. 앞선 커밋·푸시 요청이 완료됐다고 이후 작업까지 자동 승인된 것으로 보지 않는다.

이미 구현을 요청한 작업에서 “하던 거 계속해줘” 또는 “AGENTS.md, /docs 읽고 구현해줘”라고 하면 이 순서로 이어가며, 문서화만 할지 구현까지 할지 같은 질문을 반복하지 않는다. 반대로 **“문서화 작업만”, “설명만”, “코드 수정하지 말고”라는 제한이 있으면 그 범위에서만 작업한다.** 계획을 인용하거나 남은 작업을 묻는 것만으로 새 구현을 시작하지 않는다. 이번 절 추가는 문서화이며 새 중점 구현이나 게임 검증을 수행했다는 기록이 아니다. 세부 범위 판단은 [AGENTS.md](../AGENTS.md#1-obey-the-requested-operating-mode)를 따른다.

한 묶음은 대체로 3~5개를 출발점으로 검토한다. 긴 직렬 연쇄가 필요하면 이유를 적고, 단순히 x좌표만 바꾼 지그재그 구조로 대체하지 않는다. 해당 정치 경로 안에서 독립된 병렬 묶음은 원칙적으로 모두 완료할 수 있으며, 기존 입헌·전제 등의 배타 경로를 서로 동시에 열거나 배치용 상호배타를 새로 만들지 않는다.

각 상세 명세에는 진입 조건·필수 선행과 배치 기준의 구분, 최장 필수 연쇄와 실제 행 수, 폭·높이·인접 가지 여백, 주요 보상·결정의 최초 도달 시점과 전체 소요 시간을 기록한다. 어느 묶음을 먼저 진행해도 해당 결정 범주·개별 사업·정신 승계가 작동하는지와 필요한 차단 조건을 함께 설계한다. 보상·기간·기존 경로를 임의로 바꾸지 않고, 선행 변경이 필요한 경우 해당 구현의 의도적인 진행 변경으로 명시한다.

이 원칙은 처음에는 문서화만 했으며, 이후 승인된 구현에서 파시즘 F1~F6를 각각 4개씩 적용했다. F4는 참모 규정에 기반한 군정 행정이라는 명시적인 이유로 F2에 연결하고, F5·F6까지 같은 말단에 연달아 붙이지 않는다. 2026-09-23에는 왕정 42개에도 독립 모듈과 기존 정치·형성 조건을 적용했다. 공산 병렬화의 정적 결과나 이전 게임 검증을 새 묶음의 검증 결과로 사용하지 않는다.

## 첫 두 묶음의 구현 계약

- [첫 10개 명세](HOK_KOREAN_SECOND_WAVE_FIRST_10_SPEC.md)의 ID·조건·보상만 적용한다. 기존 중점의 필수 선행, 보상, 기간, AI 가중치는 바꾸지 않는다.
- 여운형은 기존 `KOR_rural_support_plan`, 박헌영은 `KOR_heavy_industry_concentration`에서 옆가지로 시작한다. 공산정부·내전 없음·해당 기존 지도자 선택 완료를 요구한다.
- 양쪽 정책은 선택한 국민정신만 I→II로 교체한다. 하위 정신이 이미 제거됐다면 선택된 상위 정신을 직접 부여한다. 공산정부를 잃으면 제거되며 정권 복귀만으로 자동 복구되지 않는다.
- 2026-09-22 후속 보상 조정은 [첫 10개 명세](HOK_KOREAN_SECOND_WAVE_FIRST_10_SPEC.md)의 최종값으로 적용한다. 기존 수치에 가산하지 않으며 기존 326개, ID, 배치와 이미지는 유지한다. 협동 작업장의 공동구매 경로 산업 연구 75% 1회와 자율금융 II의 민공 건설 속도 +2% 등 기존 부가효과도 보존한다. 자율금융 II의 정치력은 별도 추가 강화값이 지정되지 않아 I의 일일 +1.2를 승계한다.
- 말단 중점에서 선택한 기간제 사업을 해금한다. 공동구매 조달·군수설비 집중 건설은 정치력 150을 쓰며 민공 점유와 사람·AI의 민공 수량 요건을 없앤다. 자율금융·현행생산 사업은 정치력 75와 민간공장 2개를 유지한다. 네 사업 모두 90일 동안만 효과를 받으며, 최대 동시 하나와 종료·취소 후 공통 90일 대기시간, 기존 취소 조건을 유지한다. 무료 공장·정치력·경험치를 반복 지급하지 않는다.
- 민공을 점유하는 자율금융·현행생산 사업에서는 2개 공장을 다른 건설에 사용할 수 없다. 이 두 사업의 사람 가용 민공 요건은 2개, AI 요건은 각각 24개·6개다. 모든 사업의 기존 AI 정치력 150 이상 조건과 기본 가중치 0.5는 유지한다.

## 배치와 이미지

**최신 460개 배치:** 절대 기준 7개·상대 배치 453개, 범위 x0~212·y0~24다. 직전 378개와 정치 offset·패널·바로가기를 보존하고 신규 82개만 상대 배치했다. 후속 H1 이동은 기존 왕의 귀환 기준 상대값을 (−1,6)에서 (25,1)로 바꾸어 네 중점만 옮기고 나머지 456개 위치를 보존한다. C2 진입선과의 모델 접촉을 피하면서 3행 대칭 구조를 유지하도록 이전 전체 폭보다 오른쪽 끝만 1칸 넓혔다. 아래 326~378개 설명은 해당 단계의 변경·검증 이력이다. 신규 82개의 기존 화면·정상 진행은 잔여 확장 작업 기록, 현재 H1은 오른쪽 배치 기록의 검증 범위를 따른다.

2026-09-22 승인된 구현으로 **공산·민주·파시·비동맹 모두의 선택 후 압축**을 적용했다. 사용자가 정상 작동을 확인한 가지 숨김과 정책 묶음 내부의 병렬 구조를 유지하고, HIDE에서 해당 분기 중점을 완료한 뒤에만 정치 구역을 이동한다. 정치 압축 당시 362개에 F3 4개를 추가한 366개 단계는 절대 기준 7개·상대 배치 359개였다. F4·F5·F6 12개를 추가한 당시에는 378개·절대 기준 7개·상대 배치 371개이며 기본 범위 x0~204·y0~24는 유지한다. SHOW·선택 전·진행 중 및 공통 산업·군사·만주 위치는 기본 배치를 따른다. F3 추가는 기존 362개의 진행 조건·보상·기간·AI·기본 좌표와 정치 offset을 바꾸지 않는다.

직접 offset은 공화국 공통 진입 3개·정치 기준 4개다. 공산·민주·파시·왕정 구역은 각각 x -5/-35/-84/-101을 적용해 기준점이 x79/92/83/85, 현재 구역 범위가 x68~95/73~123/74~91/75~103으로 계산된다. 공화국 공통 진입은 공산·민주·파시에서 x79/92/83으로 맞추고 왕정에서는 기존 조건대로 숨긴다. F3는 기존 파시 offset을 상대 기준 체인으로 한 번 상속하며 별도 offset을 추가하지 않는다. 기본 위치와 조건별 위치는 [현재 좌표 JSON](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)에 구분한다. 조건 정의는 [정치 압축 계획](HOK_KOREAN_POLITICAL_COMPACTION_PLAN.md)을 따른다. **정치 압축의 코드·정적 검사·새 게임 로드 확인은 F3 추가 전 362개 소스의 결과다. F3의 130 PASS / 0 FAIL과 초기 화면 관측은 이전 배치 소스의 결과이며, 이후 확대 HIDE에서 진입선 공선을 발견하여 새 4개만 재배치했다. 2026-09-23 최종 소스에서 추가 정적 검사 44 PASS / 0 FAIL, 보상 재검사 130 PASS / 0 FAIL, 진단 없는 새 게임 로드(53b0)와 신규 정규화 오류 0건을 확인했다. 이전 ESC 중지 뒤 별도 새 게임에서 최종 상단 구역의 HIDE/SHOW와 병역행정 명부 한 개의 정상 35일 완료를 확인했다. 두 화면은 각각 정치 분기 완료 합성 상태이며 초기부터의 압축 전환 검사는 아니다.** 당시 일시정지 한국 새 게임의 신규 정규화 오류 0건과 상세 환경은 [정치 압축 구현 기록](incidents/2026-09-22-korean-political-compaction.md)을 따른다. 이 결과나 과거 326개 초기 화면, F1/F2 보상 검사를 F3 검증으로 재사용하지 않는다. 소스별 F3 결과는 [별도 구현 기록](incidents/2026-09-22-korean-fascist-mobilization.md)에 기록한다.

새 10개는 실제 기존 부모 옆에 상대좌표로 붙였다. 공산주의 구역 오른쪽의 공간을 확보하기 위해 공화국 진입·민주·구국군·황실의 절대 기준점 4개를 오른쪽 10칸 이동했다. 해당 상대 자손은 함께 이동한다. 전체 범위는 x0~204·y0~24이며 높이·지속적 중점 패널·바로가기 설정은 유지한다. 이 이동은 기존 기능 변경과 별도로 기록한다.

기준선 실행에서 발견한 개마고원·소양강댐의 선행 선언 오류 2건은, 먼저 선언된 `KOR_devalue_the_won`을 기준으로 상대값을 재계산해 수정했다. 계산된 위치 (2,5)·(8,5)는 보존한다. 존재하는 ID라도 뒤에 선언되어 있으면 엔진이 상대 기준으로 등록하지 못한 실제 로그가 근거다.

[현재 좌표 데이터(378개 단계 포함)](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)는 이전 326개 명세와 구분한다. 사용자가 승인한 병렬 개편은 첫 경제정책 10개를 그대로 두고, 전국 협동조합 연합 `(75,13)`에서 Y1 x73·y14~17과 Y3 x77·y14~18로, 중공업 종합배정 `(98,13)`에서 P1 x96·y14~18과 P3 x100·y14~17로 나눈다. 네 시작 중점의 상대좌표는 왼쪽 `(-2,1)`·오른쪽 `(2,1)`이며 각 묶음 내부는 직전 부모 기준 `(0,1)`을 유지한다. 경제정책 뒤의 직렬 9개가 최대 5행의 병렬 묶음이 되어 공산 추가분의 범위는 y10~22에서 y10~18로 줄고, 전체 범위 x0~204·y0~24는 유지한다. 기존 326개와 첫 10개의 위치·조건·보상, 모든 중점의 ID·보상·35일 기간·AI·기존 상호배타 선택은 보존한다. 정적 좌표·직사각형 검사는 실제 연결선, 이름판, SHOW/HIDE, 이념 선택 후 화면 검증을 대신하지 않는다.

중점 진행 순서의 변경은 두 시작 선행조건에 한정한다. `HOK_KOR_yeo_rural_service_survey`는 `HOK_KOR_yeo_social_compact` 대신 `HOK_KOR_yeo_cooperative_federation`을, `HOK_KOR_pak_planning_secretariat`는 `HOK_KOR_pak_integrated_output_plan` 대신 `HOK_KOR_pak_heavy_industry_dispatch`를 요구한다. 후속 개발을 우선하면 Y3 보상은 종전보다 최대 140일, P3는 최대 175일 빨리 도달할 수 있다. 두 묶음을 모두 진행할 때 지도자별 완료 가능한 13개·기본 455일은 바뀌지 않는다. 이는 중단·다른 조건 대기를 제외한 계산이다.

새 중점 10개·정신 8개는 기존 공개 팩의 허용된 소재와 합성 방식을 재사용했다. 공산 경로색 RGB(116,45,48)을 배경에만 적용하고 소재·금속 테두리를 보존했다. 정책 단계 정신의 기존 I·II 표기는 보상 조정 후에도 유지한다. [출처·가공 기록](HOK_KOREAN_SECOND_WAVE_ICON_CREDITS.md)과 [매니페스트](data/HOK_KOREAN_SECOND_WAVE_ICON_MANIFEST.json)에 원본·가공·해시를 기록했다.

기존 신규 60개에 사용한 광택 오버레이도 프로젝트의 `gfx/interface/goals/HOK_KOR/shine_overlay.dds`로 복사하고 상대경로로 연결했다. 바닐라 오버레이는 공개 팩의 사용 허가와 구별해 기록한다. 기존 89개 아이콘 본체는 재생성하지 않았다.

## AI와 검증 경계

새 중점의 기본 AI 가중치는 2다. 전시에는 공동구매·현행 생산, 평시에는 지역금융·군수설비 선택에 각각 2배 가중한다. 선택을 강제하거나 기존 민주 역사 계획에 공산 중점을 삽입하지 않는다. 실제 진행 경쟁과 주요 보상 도달 시점은 장기 AI 검증 대상이다.

[326개 기준선 검증](HOK_KOREAN_FOCUS_VALIDATION_20260922.md)과 [이번 구현 기록](incidents/2026-09-22-korean-second-wave-first-policies.md)을 함께 읽는다. 정상 35일 진행, UI 비용 지불, 90일 완료·재착수, 협정 수락·거절·만료, 기존 저장, 다른 DLC, 멀티플레이는 각각 실제 관측 여부를 표시한다.

보상·비용 조정 전의 짧은 실행에서는 네 정책 선택의 중점 보상·정신 승계·기간제 사업 효과·정권 변경에 따른 취소를 재검증해 149 PASS/0 FAIL을 확인했다. 당시 임시 진단을 제거한 새 실행에서도 상대 기준 선언 오류 두 건과 진단용 dynamic token 경고가 사라졌다. 기존의 다른 오류는 남아 있다. 변경 후 최종값도 새 기대값으로 네 경로를 별도 실행해 149 PASS/0 FAIL을 확인했다. 두 사업의 민공 사용량 0과 다른 두 사업의 기존 사용량 2를 포함한 현재 결과는 [보상 변경 검증 기록](incidents/2026-09-22-korean-policy-rewards.md)에 구분했다. 강제 완료·활성화 검사는 정상 진행·비용 지불·연구 보너스 소모·90일 종료·화면·장기 AI 검증을 대신하지 않는다.

보병장비 한정 생산량 +10%는 이번 두 정책 묶음과 분리한 미결 항목이다. 약 -9.09% 생산비 대안은 아직 선택되지 않아 기존 조달 국민정신에 적용하지 않았다.

후속 내정 9개는 최초 추가 때 기존 336개 정의를 원문 그대로 보존했다. 당시 별도의 네 개 새 게임 진단은 **199 PASS / 0 FAIL**이며 기존 경제정책 선택 보존·새 정신 강화·사업 활성화와 정권 변경 취소를 확인했다. 이는 병렬 개편 전의 기록이다. 첫 10개의 149 PASS나 정상 35일·90일·화면 검증과 합쳐 표현하지 않는다. [후속 작업 기록](incidents/2026-09-22-korean-communist-governance.md)에 결과와 한계를 기록한다.

기술보급·계획행정 9개를 최초 추가할 때 기존 345개 중점 정의·좌표와 기존 내정 4개 사업의 정의를 보존했다. 이 보존 기록은 병렬 개편 전의 상태다. 새 사업 4개는 기존 후속 내정 범주의 활성·대기 플래그를 공유한다. 후속 내정 전체 8개 중 최대 하나와 기존 경제정책 4개 중 최대 하나를 병행하는 구조이며 새 범주나 세 번째 동시 실행 슬롯을 만들지 않는다. 병렬 가지 어느 쪽을 먼저 진행해도 사업이 보이도록, 원래 한국인 국가에서 지방협의회 정례화·생산능력 정기점검·공동업무 회계 공개·현장 기술대표단 중 하나를 완료하면 공유 범주를 표시한다. 개별 사업의 해금·지도자·정부 조건은 유지한다. 이번 결과는 [기술보급·계획행정 작업 기록](incidents/2026-09-22-korean-communist-development.md)을 따르며 앞선 149·199 검사에 합산하지 않는다. **현재 병렬 배치의 새 선행 경로·사업 범주 공개·연결선·명판·SHOW/HIDE는 아직 런타임 검증 전이다.**

병렬화 후 소스·좌표·선행·보상 보존과 가지별 도달성의 정적 검사 결과는 [병렬 배치 기록](incidents/2026-09-22-korean-communist-parallel.md)을 따른다. 게임 실행 결과와는 구분한다.

## 파시즘 첫 묶음 F1 — 군수계약

기존 재벌 길들이기에서 군수조달 실무정비 → 원가심사·납기조정 병렬 → 통합 군수계약으로 연결한다. 두 가운데 정책은 모두 완료할 수 있고 최종 중점은 양쪽 모두를 요구한다. 기존 354개 정의·좌표·보상은 유지했다. 신규 4개는 3행이며 최초 사업 해금은 우선 진행 시 70일, 전체 완료는 140일이다. 전체 범위 x0~204·y0~24를 유지한다.

감독 I의 군공 생산량 +10%를 II에서 +15%로 강화하고 자원 부족 불이익 -10%를 더한다. 납기 조정의 산업 연구 150% 1회와 함께, 정치력 150·민공 점유 0·90일의 긴급 납품(+15% 생산량) 또는 원자재 계약조정(-20% 자원 부족 불이익)을 연다. 두 사업만 공통 동시 하나·종료/취소 후 90일 대기를 공유한다. 기존 재벌 주문은 유지한다.

중점 4개·정신 2개·소형 결정 2개·범주 1개의 새 이미지를 차콜·갈색으로 프로젝트 내부에 통합했다. 세부 계약과 AI 가중치는 [전용 명세](HOK_KOREAN_FASCIST_PROCUREMENT_SPEC.md), 실제 검사와 남은 한계는 [작업 기록](incidents/2026-09-22-korean-fascist-procurement.md)에 구분한다. 이전 공산 검증 횟수를 F1 결과에 합산하지 않는다.

F1의 시작 직후 강제 보상 검사 결과는 두 경로 합계 **68 PASS / 0 FAIL**이며, 진단 없는 새 한국 게임 로드에서도 신규 오류가 없었다. 장기 진단이 첫날 말에 정체되어 사업·대기의 자연 만료와 취소는 미검증이다. 정상 진행·UI 비용·화면·장기 AI까지 검증됐다는 뜻은 아니다.

## 파시즘 두 번째 묶음 F2 — 참모업무

기존 선군주의(`KOR_prussia_in_the_far_east`)에서 참모보직 정비 → 작전기획국·야전보고 체계 병렬 → 참모업무 규정으로 연결했다. F1 군수계약과 독립적으로 접근하며 가운데 두 정책은 모두 완료할 수 있고 최종 중점은 양쪽 모두를 요구한다. 기존 358개 정의·위치·보상과 F1 사업·플래그는 유지한다. 신규 4개는 `(172,6)` → `(171,7)/(173,7)` → `(172,8)`의 3행이며 전체 범위 x0~204·y0~24를 늘리지 않는다.

참모보직 정비는 육군 경험치 50, 야전보고 체계는 전자공학 연구 100% 1회와 육군 경험치 25를 준다. 작전기획국의 참모업무 체계 I은 계획 수립 속도 +15%·최대 계획 보정 +10%, 최종 II는 각각 +20%·+15%다. 최대 계획은 `max_planning_factor`이며 고정 계획 보너스 가산과 구분한다. 기존 계룡대·공통 참모·독일 장군참모 정신은 교체하지 않는다. 첫 정신 또는 연구 보상은 우선 진행 시 70일, 두 가운데 정책은 105일, 전체 완료는 140일이다. 별도 결정은 추가하지 않아 2차 기간제 사업 누계 14개는 유지한다.

중점 4개·정신 2개의 새 이미지는 차콜·갈색 배경에 명부·작전 지도·야전무전기와 지도·업무 교범을 구분했다. 이미지 근거와 누적 보상은 [F2 명세](HOK_KOREAN_FASCIST_STAFF_SPEC.md), 실제 검증 상태는 [작업 기록](incidents/2026-09-22-korean-fascist-staff.md)을 따른다. 정적 검사는 **84 PASS / 0 FAIL**이며 기존 358개 중점 원문 보존과 당시 362개의 참조·좌표 등을 확인했다. 설치본 1.19.3에서 두 정책 순서와 하위 정신 부재를 나눈 강제 완료 보상 검사는 **125 PASS / 0 FAIL**이고, 진단 없는 최종 새 게임도 로드했다(ee60). 오류 로그는 기존 128행과 동일하며 추가 오류는 0건이다. 정상 진행·연구 보너스 소모·정부 상실 취소와 화면 제어 연결 실패로 확인하지 못한 실제 배치는 미검증이다. 이전 F1의 68 PASS를 F2 결과에 합산하지 않는다.

## 파시즘 세 번째 묶음 F3 — 병역행정과 필수인력 배치

최종 진입점은 군내 극우인사 포섭(`KOR_gathering_the_farright_in_the_military`, 기본 `(167,3)`)이다. 병역행정 명부 → 예비인력 소집계획·필수인력 배치기준 병렬 → 병역행정 일원화로 연결한다. 이전 세계위에 군림하는 대한 진입선이 확대 HIDE에서 F2 합류선과 겹쳐 새 묶음의 선행·상대 기준을 옮겼다. 새 4개는 세계위에 군림하는 대한 완료를 더 이상 요구하지 않아 진입 시점이 앞당겨지지만, 파시즘 정부·내전 없음·을해군란(`KOR_establishment_of_the_national_salvation_army`) 완료 조건은 유지한다. F1·F2의 완료나 정신을 요구하지 않으며 가운데 두 정책은 모두 완료할 수 있고 최종 중점은 양쪽 모두를 요구한다. 기존 362개 정의·보상·조건·기간·AI·좌표와 정치 offset은 보존했고 새 중점은 각각 35일이다.

| 병역행정 명부 | (174,4) | 국가 인력 25,000·정치력 100 일회 지급 |

명부는 기존 부모 기준 `(7,1)`, 나머지 3개는 먼저 선언한 명부 기준 `(-1,1)`·`(1,1)`·`(0,2)`다. 3행 대칭 병렬 구조이며 기본 범위 x173~175·y4~6으로 전체 범위 x0~204·y0~24를 늘리지 않는다. 파시즘 분기 완료 후 HIDE에서는 기존 x -84를 상속해 `(90,4)`·`(89,5)`·`(91,5)`·`(90,6)`으로 계산되며 파시 구역의 현재 범위는 x74~91이다. 새 배치의 독립 정적 검토에서 SHOW/HIDE 사각형·선 접촉·공선 후보가 없었지만 실제 화면 검증과는 구분한다.

최초 일회 보상은 35일, 먼저 선택한 정책의 정신 또는 연구는 70일, 두 가운데 정책은 105일, 전체 완료는 **140일**이다. 부모까지의 진행과 조건 대기·중단은 제외한다. II는 I를 교체하고 하위 정신이 없으면 직접 지급하며, 필수인력 정신과 F1·F2·공통 정신을 제거하지 않는다. 징병 가능 인구 계수 +20%·+30%는 전체 인구의 해당 비율을 추가 징병하거나 인구 비율을 +20%p·+30%p 늘리는 효과가 아니다. 기존 이점과 다른 산업·징병 보상을 보존한다.

중점 4개·국민정신 3개에 신규 이미지 **7개**를 통합했다. 차콜·청동 계열의 명부·군번표, 헬멧·소집 달력, 노동자·공장·명부를 사용한다. 병역행정 정신만 I·II를 표시하며 필수인력 정신에는 배지를 넣지 않는다. [이미지 출처](HOK_KOREAN_FASCIST_MOBILIZATION_ICON_CREDITS.md)와 [매니페스트](data/HOK_KOREAN_FASCIST_MOBILIZATION_ICON_MANIFEST.json)를 따른다. 새 결정·기간제 사업은 추가하지 않아 기존 14개를 유지한다. 새 중점 AI 기본 가중치는 2이며 기존 민주 역사 AI 목록에 넣지 않는다.

정확한 효과·누적값·정부 상실 처리와 진행 조건은 [F3 명세](HOK_KOREAN_FASCIST_MOBILIZATION_SPEC.md)를 따른다. 이전 배치 소스 `6a5d06…f17a5d`의 수정된 강제 완료 검사는 소집계획 우선 41·필수인력 우선 41·하위 정신 부재 48, 합계 **130 PASS / 0 FAIL**이며 각 실행의 신규 정규화 오류는 0건이다. 최초 45 PASS / 1 FAIL의 합성 초기 상태 진단은 보존하고 이 합계에서 제외했다. 같은 이전 소스의 초기 HIDE에서 완료 중점 4개·정신 II/필수인력 표시를 확인했으나, 이후 확대된 분기 완료 HIDE 화면은 F2 합류선과 F3 진입선이 겹침을 보여줬다. 새 4개의 진입점과 좌표를 바꾼 최종 소스 `91520275…49b61f`에서는 2026-09-23 추가 정적 검사 44 PASS / 0 FAIL과 별도 보상 재검사 130 PASS / 0 FAIL, 진단 없는 새 게임 로드(53b0)·신규 정규화 오류 0건을 확인했다. 2026-09-23 별도의 정치 분기 완료 합성 새 게임에서 최종 F3 상단 구역의 HIDE와 SHOW를 각각 관측했다. 네 중점과 부모·을해군란·인접 F2의 선·아이콘·명판이 분리되어 있었고 SHOW의 인접 왕정 구역도 가리지 않았다. 이는 선택 전부터 완료 후까지의 압축 전환 검사가 아니다. 병역행정 명부의 UI 시작·35일 진행·완료와 이후 두 자식의 시작 가능 상태도 확인했다. 이전 130건을 최종 소스 통과로 재사용하지 않는다. [작업 기록](incidents/2026-09-22-korean-fascist-mobilization.md)에 실패·수정·소스별 검증을 구분한다. 나머지 3개 중점의 정상 진행·최종 AND 차단·전체 140일·연구 소모·정부 상실·실제 동원과 생산효율·AI·다른 아이콘 상태·세이브·다른 DLC·멀티플레이는 별도 검증 대상이다.

2026-09-23 후속 요청으로 위 파시즘 후보의 상세 명세와 코드를 적용했다. 이때 미적용이었던 입헌·전제·환제국 각 14개, 만주 20개, 공통 산업·군사 20개는 같은 날짜의 잔여 확장에서 적용했다. 각 단계의 구현과 실제 플레이 검증은 계속 구분한다.

## 파시즘 F4·F5·F6 — 점령행정·삼군 조정·재건예산

[후속 12개 명세](HOK_KOREAN_FASCIST_FOLLOWUP_SPEC.md)를 적용한 당시 378개다. 기존 366개 블록·보상·조건·좌표·AI와 정치 offset은 보존한다. 점령행정은 참모업무 규정에서 `(174,9)` → `(173,10)/(175,10)` → `(174,11)`로 이어지고, 세계위에 군림하는 대한 완료 및 비핵심 주 최소 하나의 완전 통제를 요구한다. 참모업무의 행정 규정을 군정에 확장하는 F2→F4 연결은 명시적인 정책 의존성이다. 삼군 조정은 구국군 정치 진입점 옆 `(159,3)` → `(158,5)/(160,5)` → `(159,6)`에 두되 선군주의 완료를 별도 착수 조건으로 유지한다. 재건예산은 같은 정치 진입점 옆 `(163,3)` → `(162,4)/(164,4)` → `(163,5)`에 두고 세계위에 군림하는 대한 완료·평시·경기 소유 및 완전 통제를 요구한다.

F4·F5는 두 중간 정책을 모두 완료하는 AND 합류로 각각 140일이다. F6는 행정예산과 건설예산 중 하나를 선택하는 OR 합류로 실제 경로는 105일이며 정의는 4개다. F4는 저항 목표·주둔군 요구량을 낮추고 상위 단계에 순응도 증가 속도와 주둔군 피해 감소를 추가한다. F5는 육군 보급 및 해·공군 연료 소비를 최종 −15%로 줄이고 경험치·전자공학 연구를 제공한다. F6는 일일 정치력 +1.2와 수리 +15%, 또는 민공 건설 +20%와 수리 +25% 중 선택한 상위 예산만 부여한다. 하위 단계의 다른 이점을 보존하며 기존 정신을 제거하지 않는다. 신규 국민정신은 8개, 이미지 대상은 중점 12개·정신 8개이며 별도 결정은 추가하지 않는다.

이번 추가분은 독립 정적 검사 183건·좌표 검사 57건과 강제 보상 진단 272건을 통과했다. 진단 없는 새 게임 로드와 HIDE/SHOW의 해당 구역을 확인했으며, 삼군 조정 4개를 실제 UI로 선택하여 자연 완료하고 한쪽 정책만 완료했을 때의 AND 차단 및 국민정신 I→II 교체를 관측했다. 점령지가 없을 때 F4 착수가 차단되는 것도 확인했다. 명목 140일과 관측 사이 대기·누적 진행 시간이 포함된 실제 날짜는 구분한다. 이후 F5 네 중점의 필터 메타데이터만 수정했으며, 최종 소스에서 정적 183건·필터 변경 검토 21건을 통과하고 진단 없는 새 게임을 다시 로드했다(`38c4`, 기준 로그 대비 신규 오류 0건). 최종 화면에서 삼군 연락사무국의 필터 한글 표시도 확인했다. 보상·좌표·정상 진행 검사는 필터 수정 전 소스의 결과로 별도 보존한다.

F4의 적격 점령지·상실·취소, F6 두 예산의 정상 진행, 정권 상실·연구 혜택 소모·저장 호환성·장기 AI·다른 DLC·멀티플레이는 아직 별도 검증이 필요하다. 정상 진행에서 자동저장 파일 1개가 바뀌어 검증 결과를 별도 보존한 뒤 원본을 복구했고 기존 저장 13개의 해시를 대조했다. 날짜 진행 중 자동저장 이름 변경과 스페인 관련 오류도 발생하여, 새 게임 로드의 신규 오류 0건과 장기 진행을 같은 결과로 취급하지 않는다. 소스별 검사·필터 표시 수정 후 재확인·화면·복구 기록은 [F4~F6 구현 기록](incidents/2026-09-23-korean-fascist-followup.md)을 따른다. 이전 366개 단계의 검사를 이번 신규 12개의 통과 결과로 재사용하지 않는다.
