# 공산주의 후속 내정 — 노농 협약과 국가 생산계획

작성: 2026-09-22. 기준 커밋: `d8558937db1e9c984a16e75eed35d5a6f8914bb2`, 한국 중점 336개. 사용자가 다음 확장으로 공산주의 후속 내정을 선택했다. 아래 수치는 [보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)을 적용한 이번 구현 설계값이며, 사용자가 개별 숫자를 직접 지정한 것으로 기록하지 않는다.

## 연결과 보상

여운형 4개와 박헌영 5개를 각각 기존 신규 정책 말단에 연결한다. 후보 JSON의 초기 부착점이었던 민주적 공산주의·중공업 집중 대신 전국 협동조합 연합·중공업 종합배정을 부모로 삼는다. 최초 추가 때 기존 336개 중점의 선행·보상·기간·AI·좌표를 보존했다. 이후 사용자가 승인한 병렬 배치에서는 후속 내정의 부모와 내부 순서를 유지하고, [기술보급·계획행정](HOK_KOREAN_COMMUNIST_DEVELOPMENT_SPEC.md)을 같은 경제정책 말단의 다른 가지로 연결한다. 두 묶음은 상호배타가 아니며 모두 완료할 수 있다. 기존 공동구매/지역금융 및 설비/현행생산 중 어느 정책을 선택해도 해당 지도자의 후속 내정을 진행할 수 있다.

모두 기본 35일(`cost = 5`)이며 공산정부, 내전 없음, 해당 지도자 선택 완료를 요구한다. 항복 중 시작할 수 없고 조건 상실 시 중단한다. 표의 ID에는 `HOK_KOR_` 접두사가 붙는다. 위치는 현재 병렬 배치의 절대 해석값이다. 여운형의 첫 중점은 전국 협동조합 연합 `(75,13)`, 박헌영의 첫 중점은 중공업 종합배정 `(98,13)`을 기준으로 각각 상대좌표 `(-2,1)`을 쓴다. 나머지는 먼저 선언된 직전 부모 기준 `(0,1)`이다. 첫 경제정책 10개의 배치·조건·보상은 유지한다.

## 후속 정책 사업

범주 ID: `HOK_KOR_communist_governance_programs`. 아래 네 사업은 정치력 150을 지불하고 민간공장을 점유하지 않는다. 90일 동안 효과를 받으며, 현재는 기술보급·계획행정의 네 사업까지 **총 여덟 사업이 동시 실행 한 자리와 종료·취소 후 공통 90일 대기시간을 공유**한다. 비용은 취소 시 환급하지 않는다. 안정도는 사업 중의 보정이며 반복 완료로 영구 안정도를 지급하지 않는다.

병렬 가지 어느 쪽을 먼저 진행해도 사업을 볼 수 있도록, 원래 한국인 국가에서 지방협의회 정례화·생산능력 정기점검·공동업무 회계 공개·현장 기술대표단 중 하나를 완료하면 범주를 표시한다. 각 사업의 개별 해금·지도자·정부 조건은 그대로 적용한다. 범주가 표시된다는 이유로 다른 가지의 사업까지 해금하지 않는다.

|---|---|---|
| `yeo_labor_compact_project` / 노사협약 이행 | 지방협의회 정례화 | 안정도 +10%p, 군수공장 생산량 +10% |
| `yeo_community_welfare_project` / 지역민생 협약 | 지방협의회 정례화 | 안정도 +10%p, 전체 건설 속도 +10% |

| `pak_production_retooling_project` / 생산계획 전환 지원 | 생산능력 정기점검 | 생산 효율 성장 +25% |

원래 한국, 해당 지도자 선택, 해금 중점, 공산정부, 비내전·비항복 상태를 요구한다. 정권 변경·내전·항복·경로 조건 상실 시 효과를 회수하고 진행 플래그를 해제하며 대기시간을 부여한다. 정부가 바뀌어도 실제 조건과 재착수 제한을 다시 확인한다.

새 네 사업은 `HOK_KOR_communist_governance_active/cooldown`을 공유한다. 기존 공동구매·지역금융·군수설비·현행생산의 경제 사업 플래그와는 별개다. **기존 경제 사업 하나와 새 내정 사업 하나를 동시에 운영할 수 있으며**, 이는 이번 추가의 의도적인 효과다. 기존 네 사업의 비용·조건은 변경하지 않는다.

누적 보상은 실제 경로별로 계산한다. 예를 들어 공동구매 II의 민공 건설 +15%, 기존 공동구매 사업 +15%, 새 지역민생 사업의 전체 건설 +10%가 동시에 있으면 이 세 효과가 민공 건설에 기여하는 합은 +40%p다. 이는 다른 국민정신·기술·법률 등을 제외한 부분 합이다. 박헌영의 새 생산계획 II와 전환 지원 사업은 효율 성장에 +40%p를 더하며, 기존 공통 산업 정신의 성장 +30%/+60%는 별도로 누적된다. 상호배타 정책의 두 대안이나 I·II를 동시에 합산하지 않는다.

## AI·이미지·문법 근거

새 중점은 기본 가중치 2로 연결한다. 선행 중점과 지도자 조건이 경로를 제한하며 민주 역사 AI 목록에는 넣지 않는다. 새 결정은 기본 0.5, 정치력 150 이상일 때 고려하고 전시에 노사협약·물자 배정, 평시에 지역민생·전환 지원을 2배 선호한다. 이는 선택 가중치이며 실제 AI 진행·성장 속도 검증과 구분한다.

9개 중점·4개 국민정신은 공산 계열 짙은 적색 배경과 주제별 소재를 사용한다. 국민정신에만 I·II를 표시하고 그림·마스크·광택은 프로젝트 내부 상대경로로 연결한다. 결정은 관련 중점의 중심 소재를 공유하되, [크기 수정](incidents/2026-09-22-korean-decision-icon-size.md)에 따라 카테고리 51×40·개별 결정 32×32의 별도 이미지를 사용한다. 출처·가공·해시는 [아이콘 기록](HOK_KOREAN_COMMUNIST_GOVERNANCE_ICON_CREDITS.md)을 따른다.

설치본 HOI4 1.19.3의 `common/ideas/japan.txt`에 생산 효율 성장·상한·자원 부족 불이익 수정치의 국민정신 문맥이 있다. `common/decisions/SWI.txt`의 `SWI_focus_on_military_production`은 같은 생산 수정치를 기간제 결정에 사용한다. 같은 파일의 90일 안정도 보정, `HOL.txt`의 90일 건설 보정을 대조한다. 기존 공산 정책 10개의 단계 교체·조건 상실 취소 구조도 확인한다. 바닐라 파일은 읽기 전용이다.

## 검증 상태

구현·검증 결과는 [이번 작업 기록](incidents/2026-09-22-korean-communist-governance.md)에 기록한다. 최초 추가 때 기존 336개 정의 보존과 ID·선행·좌표·아이콘·현지화 검사를 통과했다. 당시 네 개의 새 게임에서 중점 보상·국민정신 승계·기존 선택 보존·사업 활성화·정부 변경 후 취소를 검사해 **199 PASS / 0 FAIL**을 확인했다. 이는 병렬 배치 변경 전의 기록이며, 이전의 149 PASS와도 별개다. 현재 병렬 배치의 새 선행 경로·범주 공개·명판·연결선·SHOW/HIDE는 아직 런타임 검증 전이다. 실제 버튼의 비용 지불·동시 실행 차단, 35일 정상 진행·90일 자연 종료·대기 만료, 화면·장기 AI·저장 호환성은 각 작업 기록의 실제 관측 범위와 구분한다.

병렬화 후 소스·좌표·선행·보상 보존과 가지별 도달성의 정적 검사 결과는 [병렬 배치 기록](incidents/2026-09-22-korean-communist-parallel.md)을 따른다. 게임 실행 결과와는 구분한다.
