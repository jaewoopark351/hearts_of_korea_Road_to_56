# 한국 신규 중점·국민정신 아이콘 색상 재구성 계획

작성일: 2026-09-22. 현재 상태: **배경색 구현 완료 / 정적 검증 통과 / 이번 색상 런타임 미실행**.

> 후속 제작 방침 — 2026-09-22: 새 중점·국민정신 그림은 직접 제작·AI 생성 또는 오픈소스·명시적으로 재사용이 허용된 공개 소재의 복사·가공 중에서 선택하고, 두 방식을 혼합할 수 있다. [현재 제작 방침](HOK_KOREAN_FOCUS_SPIRIT_ICON_PLAN.md)을 따른다. 아래 정치·분야별 색상과 가독성 기준은 모든 제작 방식에 동일하게 적용한다. 기존 합성기로 배경만 바꾼 8절은 완료된 작업의 기록이며, 앞으로 새 그림도 같은 방식으로만 만들어야 한다는 제한이 아니다. 이번 방침 갱신은 문서화만 수행한다.

> 문서 이력: 아래 **1–7절은 색상 변경 전 설계와 당시 상태를 보존한 기록**이다. 미실행·후속 선정 등 표현은 최초 문서화 시점을 뜻한다. 실제 적용 내역은 8절, [색상 구현·검증 기록](incidents/2026-09-22-korean-focus-icon-colors.md), [새 색상 비교](assets/korean-focus-icon-colors/index.html)를 따른다.

사용자가 신규 아이콘의 붉은 배경이 지나치게 반복되는 문제를 지적하고, 정치 계열과 정책 용도에 따라 배경색을 구분하도록 방향을 제시했다. 최초 요청은 그 방향의 문서화였고, 이후 사용자의 구현 요청과 기존 합성 방식 선택에 따라 배경색을 적용했다.

기준 브랜치·커밋은 `feat/korean-focus-expansion-ai` / `698b6eb160efbaa04a4d43846330ba002f5e8cc7`이다. [앞선 아이콘 구현](incidents/2026-09-22-korean-focus-icons.md)과 관련 문서의 미커밋 변경을 보존했다. 게임 기준은 HOI4 1.19.3이며, 이번 색상 구현에서는 게임 실행·런타임 검증을 하지 않았다.

## 1. 현재 배경과 재구성 이유

현재 신규 중점 60개에는 Ultimate HOI4 GFX의 `Focus Backgrounds/Circle with Ribbon2.png`를 공통 배경으로 사용했다. 중심 소재는 정책별로 다르지만 자주색·짙은 빨강 원판과 금색 장식이 반복된다. 국민정신은 산업에 붉은 원판, 육군·민주 계열에 파란 방패, 해군에 파도 배경, 공군에 은색 배경을 사용했다. 실제 대상·소재 연결은 [현재 매니페스트](data/HOK_KOREAN_FOCUS_ICON_MANIFEST.json)에 기록되어 있다.

붉은색 반복의 원인은 중점 배경을 일률적으로 선택한 구성 방식이다. 다운로드나 DDS 변환 과정에서 자동으로 공산주의용 그림으로 바뀐 문제가 아니다. 해당 원판을 사용했다는 사실만으로 그 중점이 공산주의 정책을 의미하지도 않는다. 민주 계열까지 같은 붉은 배경을 쓰면서 정치적 의미를 혼동할 수 있어, 다음 규칙으로 시각적 구분을 개선한다.

앞선 소재 확인에서 구분한 배경·프레임은 다음과 같다. **동일한 중점 프레임의 색상별 완성 세트가 아니라, 형태와 용도가 다른 소재들**이다. 다운로드하여 확인한 소재 전부를 실제 게임에 채택했다는 뜻은 아니다.

| 색상 | 확인한 소재 | 구분할 점 |
|---|---|---|
| 자주색·짙은 빨강 | 중점 `Circle with Ribbon2.png`, 국민정신 `Circle.png` | 현재 붉은 배경의 원본 |
| 파랑 | 국민정신 `Shield Blue.png` | 방패 형태. 중점용 파란 원형 프레임 완성본이 아님 |
| 청회색·남색 | 국민정신 `Naval.png` | 파도 무늬 해군 배경 |
| 은색·회색 | 국민정신 `Airforce.png`, 중점 `Ring Silver.png` | 공군 배경과 원형 테두리는 서로 다른 소재 |
| 갈색·청동색 | 국민정신 `Naval2.png`, `Upgrade.png` | 방패·계급장 형태. 정치 계열용 완성 세트가 아님 |
| 금색 | 중점 `Ring Gold.png`, `Naval Frame.png` | 원형 테두리·현창 형태의 장식 |
| 짙은 초록 | 중점 `Green Laurel.png` | 월계수 장식이며 초록 원판 완성본이 아님 |

## 2. 정치 계열의 색상 기준

다음 색상 구분은 사용자가 지정한 기준이다. 오른쪽의 명암·장식은 가독성을 위한 제안이며, 정확한 색상값은 아직 선정하지 않았다.

| 정치 계열 | 배경색 기준 | 명암·장식 제안 |
|---|---|---|
| 민주주의 | 파랑 | 채도를 낮춘 짙은 파랑. 해군과는 파도·닻 등의 형태로 구분 |
| 공산주의 | 빨강 | 짙은 빨강. 금속 부품과 겹쳐도 중심 소재가 읽히는 명암 |
| 파시즘 | 갈색·검정 | 갈색 바탕과 검정 장식 또는 짙은 회색 바탕과 청동 장식. 순검정으로 형태가 묻히지 않게 조정 |
| 비동맹주의 | 흰색·회색 | 순백보다 밝은 회색·은색 중심. 비활성·잠금 상태처럼 보이지 않도록 테두리와 음영 유지 |

이 규칙은 **정치 경로의 소속**을 나타낸다. 현재 집권 이념에 따라 모든 중점·국민정신을 동적으로 다시 칠하는 규칙이 아니다. 비정치 분야에서 같은 계열의 색을 사용하더라도 정치적 소속을 뜻하지 않는다. 색상만으로 의미를 전달하지 않고 중심 소재·배경 형태·단계 표시를 함께 사용한다.

## 3. 공통 분야의 용도색과 우선순위

산업·군사 등 공통 분야는 정치색을 일괄 적용하지 않고 정책의 용도에 맞춰 구분한다. 다음 표는 용도별 재구성 방향이며, 세부 색조와 대상별 최종 배정은 후속 미리보기에서 확정한다.

| 공통 분야 | 배경·장식 방향 | 유지할 중심 소재의 예 |
|---|---|---|
| 산업·생산 | 중간 회색 배경, 청동·금색 장식 | 발전·송전, 공장, 규격 부품, 조정 도구, 검사표 |
| 교육·연구 | 밝은 회색·은색 | 책, 등불, 숙련 노동자, 실험 도구 |
| 육군·군수·참모 | 짙은 초록·올리브색 | 탄약·보급 상자, 지도·작전계획, 철모 |
| 해군 | 남색·청회색 | 함선, 닻, 파도, 항만·보급 소재 |
| 공군 | 은색·옅은 파랑 | 항공기, 편대, 날개, 정비 도구 |

배정 우선순위는 다음과 같다.

1. 민주 등 특정 정치 경로에 속한 정책은 그 경로의 색을 우선한다. 민주 계열의 시민·농촌교육은 파랑이며, 공통 교육 분야의 회색으로 바꾸지 않는다. 민주 계열의 의료·의용군 지원과 경제·군수 협정도 같은 원칙을 따른다.
2. 공통 분야에서는 정책 용도를 적용한다. 군종에 속한 학교·연구·정비 중점은 해당 군종의 색을 유지한다. 예를 들어 항공정비학교는 공군색을 사용하고, 일반 교육색으로 분리하지 않는다.
3. 산업 가지 안의 조선 산업처럼 분야가 겹치는 항목은 중심 정책과 연결된 국민정신을 대조해 개별 배정표에 명시한다. 현재 매니페스트의 `family`·조합용 `category`만으로 새 배경색을 자동 결정하지 않는다.

민주의 파랑과 해군의 남색, 비동맹의 회색과 산업·교육·공군의 회색은 색상 계열이 겹칠 수 있다. 정치 경로와 비정치 분야를 구분한 적용 규칙, 서로 다른 중심 소재와 프레임 형태로 의미를 보완한다.

## 4. 이번 적용 계획의 범위

| 대상 | 중점 수 | 국민정신 정의 수 | 후속 색상 재구성 방향 |
|---|---:|---:|---|
| 산업·교육 | 20 | 11 | 산업·생산과 교육·연구 용도색으로 구분 |
| 군사 | 25 | 12 | 육군·군수·참모, 해군, 공군 용도색으로 구분 |
| 민주 내정·외교 | 15 | 6 | 민주주의 파랑을 공통 적용하고 정책별 중심 소재 유지 |
| 합계 | 60 | 29 | 기존 신규 아이콘 대상 안에서만 재구성 |

정확한 대상 ID 목록은 [60개 명세](HOK_KOREAN_FOCUS_FIRST_60_SPEC.md)와 [89개 아이콘 매니페스트](data/HOK_KOREAN_FOCUS_ICON_MANIFEST.json)를 따른다. 29개에는 강화 단계별 교체판과 외국 협정 수혜국용 정의가 포함되며, 한국에 동시에 29개를 표시한다는 뜻이 아니다. 최초 구현 기록의 28개는 당시 수량으로 보존한다.

현재 신규 60개에는 공산·파시즘·비동맹 정치 중점 묶음이 없다. 세 계열의 색은 **장래의 정치 아이콘 제작 기준**으로 기록하며, 이를 이유로 기존 원작 정치 경로를 수정하지 않는다. 이번 범위에서 정치색을 실제 적용할 대상은 민주 중점 15개와 민주 국민정신 정의 6개다.

기존 원작 중점·국민정신, 초상화·장비, UI 배치, 중점 연결·보상·기간·AI, 국민정신 효과·획득·해제 조건, 현지화·저장 식별자는 이 계획의 변경 범위에 포함하지 않는다.

## 5. 중점·국민정신과 강화 단계의 연결

중점과 보상 국민정신은 **같은 핵심 소재와 색상 계열**로 연결한다. 중점의 장식까지 작은 국민정신에 그대로 축소하기보다는, 중점은 프레임을 포함하고 국민정신은 핵심 소재가 먼저 읽히도록 간결하게 구성한다.

| 정책 계열 | 유지할 연결과 구분 |
|---|---|
| 전력 1·2·3단계 | 발전·송전 소재와 같은 배경 계열 유지, 기존 `I`·`II`·`III` 표식으로 단계 구분 |
| 숙련공, 대량생산, 유연생산 | 각 정책 안에서는 같은 소재·색을 유지하고 단계 표식을 보존. 서로 다른 정책 간 소재 차이는 유지 |
| 함대 수리·호위·보급 | 해군색을 공유하되 정비 도구·수송선 보호·보급 상자 등 역할별 그림을 구분 |
| 편대전술·항공정비 | 공군색을 공유하되 항공기 대형과 정비 도구를 구분 |
| 민주 행정·회계·농촌교육·지원 | 파랑을 공유하되 문서·장부·책·보급 소재로 정책 구분 |

실제 강화 관계가 없는 항목에는 새 단계 번호를 부여하지 않는다. 기존 단계 표식도 배경과 함께 일괄 변색하지 않는다.

민주 계열의 `HOK_KOR_customs_participant_idea`와 `HOK_KOR_license_participant_idea`는 외국 협정 수혜국용 정의다. 파랑은 협정이 비롯된 정책 계열을 표시하며, 수혜국의 집권 이념을 뜻하지 않는다. 수혜국 이념별 이미지 분기나 새로운 민주주의 조건을 추가하지 않는다. 농촌교육·의용군 지원을 포함한 나머지 국민정신의 기존 유지·해제 조건도 색상 규칙과 별개로 보존한다.

## 6. 후속 이미지 작업 방식과 출처 기록

배경색 변경은 원본 부품과 배경을 분리한 상태에서 진행하는 방향으로 잡는다. 중점은 원판의 색을 조정하면서 금속 테두리·월계수·중앙 그림·단계 표식의 색과 질감을 보존한다. 국민정신은 선택한 원판·방패·군종 배경에 같은 정책의 색상 계열을 반영한다.

완성 DDS 전체에 일괄 색조 필터를 씌우면 금색 장식, 종이·항공기·함선 같은 중앙 소재까지 변색될 수 있으므로 배경 영역을 분리해 처리한다. 현재 배경에 색상별 완성본이 모두 있는 것은 아니어서, 기존 소재의 재조합이나 배경 부분의 색상 편집이 필요하다.

현재 채택한 외부 소재는 Ultimate HOI4 GFX이며, 고정 원본 커밋과 공개 팩의 사용 근거는 [출처·가공 기록](HOK_KOREAN_FOCUS_ICON_CREDITS.md)에 보존되어 있다. 이번 문서는 그 기록을 이어 쓰며 새 사용 허가를 취득했다고 주장하지 않는다. 다른 모드 전체에 대한 허가로 확대하거나, 재색칠한 원본을 계속개발 팀의 신규 원화로 표시하지 않는다.

실제 색상 변경을 수행할 때 원본 파일·기여자 표시·고정 커밋을 유지하고, 변경한 배경 영역·색조·재조합 내역과 결과 DDS 해시를 기록한다. 이번 문서화 단계에서는 현재 자산을 설명하는 매니페스트, 크레딧, 전후 비교 이미지를 미래 상태로 덮어쓰지 않는다.

## 7. 후속 선정·검수 기준

색상 편집·게임 적용을 진행하는 후속 작업에서는 다음을 확인한다. 아래는 앞으로 수행할 항목이며 이번 문서 작업의 검증 결과가 아니다.

1. 대상 ID별 현재 그림·후보 그림·배경색 분류·핵심 소재·단계·출처·필요 가공을 나란히 기록한다. 정확한 색상값과 분야가 겹치는 항목의 배정은 이 단계에서 확정한다.
2. 민주 중점과 연결 국민정신의 파랑이 일관적인지, 산업·교육·육군·해군·공군이 작은 크기에서도 구분되는지 확인한다.
3. 같은 정책의 강화 단계는 색·소재의 연속성을 유지하고, 단계 표식이 배경에 묻히지 않는지 확인한다.
4. 원본 알파·투명 여백·테두리·중앙 소재의 명암을 보존한다. 현재 중점 100×88, 국민정신 60×68의 DDS 치수와 형식·참조 체계를 기준으로 확인한다.
5. 실제 게임의 잠금·선택 가능·진행·완료 상태와 광택에서 색·형태를 확인한다. 흰색·회색이 비활성처럼 보이거나 검정이 배경에 묻히는지, 민주·해군의 파랑이 혼동되는지도 살핀다.
6. 국민정신의 실제 표시 크기, 획득·단계 교체, 외국 협정 수혜국 표시를 확인한다. 색만 바꿨다는 사실로 동작·호환성이 검증되었다고 간주하지 않는다.

앞선 구현의 화면 표본·정적 검증은 현재 이미지에 대한 기록이다. 아직 만들지 않은 색상 변형의 가독성이나 게임 내 동작을 입증하지 않는다. 이번 작업에서는 문서와 안내 링크만 추가했으며 이미지 편집·변환·게임 코드 수정·게임 실행·커밋·푸시·업로드는 수행하지 않았다.

## 8. 배경색 구현 — 2026-09-22

사용자가 선택한 기존 `System.Drawing` 합성기로 배경 레이어만 색상 조정했다. 중심 소재·장식·단계 표식의 구성은 유지했고, 게임 코드와 GFX 참조를 변경하지 않았다. AI 이미지 생성과 새 도구 설치는 사용하지 않았다.

| 분류 | 기준 RGB | 기준색 | 중점 | 국민정신 |
|---|---|---|---:|---:|
| 산업·생산 | 100, 100, 95 | `#64645f` | 15 | 8 |
| 교육·연구 | 159, 170, 179 | `#9faab3` | 5 | 3 |
| 육군·군수·참모 | 70, 85, 45 | `#46552d` | 10 | 5 |
| 해군 | 40, 59, 82 | `#283b52` | 10 | 4 |
| 공군 | 138, 162, 183 | `#8aa2b7` | 5 | 3 |
| 민주 내정·외교 | 53, 91, 126 | `#355b7e` | 15 | 6 |
| 합계 | — | — | 60 | 29 |

표의 RGB는 기준 색상 견본이다. 원본 픽셀의 밝기에 따라 음영을 반영하므로 해당 RGB로 단색 채우기를 한 것이 아니다. 매니페스트의 `color_revision`에는 원본 RGB의 상대 밝기를 이용한 다음 변환식과 선택 마스크 조건을 기록했다. 알파는 원본을 유지한다.

```text
shade = pow((0.2126 R + 0.7152 G + 0.0722 B) / luminance_reference, 0.9)
output RGB = clamp(round(reference_rgb * shade), 0, 255)
```

중점 60개와 국민정신 22개, 합계 DDS 82개의 배경색을 수정했다. 기존 남색 파도 배경의 해군 국민정신 4개와 은색 배경의 공군 국민정신 3개는 이미 분야색에 맞아 바이트 그대로 유지했다. 따라서 89개를 분류·검수하되 전부 다시 칠한 것으로 기록하지 않는다. 산업 가지의 경상 수출조선 지원은 산업색, 민주 경로의 교육·지원·협정 수혜국 국민정신은 민주색, 군종 소속 학교·연구는 군종색으로 배정했다.

배경 파생 PNG 10개와 해당 마스크 PNG 10개는 [배경 기록 폴더](assets/korean-focus-icon-colors/backgrounds)에 보존했다. [기존 경로의 매니페스트](data/HOK_KOREAN_FOCUS_ICON_MANIFEST.json)에서 각 항목의 `color_background`는 정확한 원본·파생 배경·마스크 경로와 해시를, `pre_color_sha256`은 변경 전 DDS 해시를, `sha256`은 현재 DDS 해시를 기록한다. `color_revision`은 기준 RGB·변환식·배정 예외를 기록한다.

원본 소재는 기존 48개 그대로이며 고정 커밋과 원 기여자 표시는 유지한다. [크레딧](HOK_KOREAN_FOCUS_ICON_CREDITS.md)에 배경 색상 가공을 추가했고, [새 갤러리](assets/korean-focus-icon-colors/index.html)는 기존 붉은 공용 배경과 분야별 배경을 비교한다. 정적 검증 결과는 [이번 사건 기록](incidents/2026-09-22-korean-focus-icon-colors.md)을 따른다. 이전 UI 표본은 새 색상의 잠금·진행·완료·광택·국민정신 표시를 입증하지 않는다.
