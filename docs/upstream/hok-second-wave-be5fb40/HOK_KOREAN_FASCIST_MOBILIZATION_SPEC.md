작성: 2026-09-22. 시작 기준은 `691ffa37740237feddf0b44fc68cfa47b10d76bf`와 기존 미커밋 변경 50개를 포함한 한국 중점 **362개**다. F1 군수계약·F2 참모업무와 정치 선택 후 압축 배치가 이미 포함된 작업 상태이며, 시작 중점 파일 SHA-256은 `e65e15f6b101d624e5838e15969eb3a6471ef72a5313dc3a6a53f80359795fc4`다. [보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)과 [독립 정책 묶음 원칙](HOK_KOREAN_FOCUS_LAYOUT_PLAN.md#46-후속-정치-확장의-긴-직렬-가지-방지)에 따른 신규 개발이다. 아래 수치는 이번 설계에서 채택한 최종값이며 사용자가 개별 수치를 직접 지정했다는 뜻이 아니다.

## 범위와 기존 내용 보존

후보 F3의 중점 4개와 국민정신 3개를 추가하며, 별도 결정이나 사업은 만들지 않는다. 적용 후 전체 중점은 **366개**, 2차 적용은 **40개**, 미적용 후보는 **94개**다. 파시즘 후보 24개 가운데 F1·F2·F3의 12개가 적용되고 12개가 남는다. 2차 국민정신은 23개, 기간제 사업은 기존 14개이며, 450~470개 목표까지는 84~104개가 남는다.

최종 진입점과 상대 기준은 군내 극우인사 포섭(`KOR_gathering_the_farright_in_the_military`)이다. 최초 후보 `KOR_stop_democracy` 아래에는 3행 공간이 부족하여 처음에는 세계위에 군림하는 대한 뒤에 붙였으나, 실제 확대 HIDE에서 그 진입선이 F2 합류선과 겹쳤다. 새 4개만 상단 옆가지로 이동하고 세계위에 군림하는 대한 완료를 더 이상 요구하지 않는다. 이는 새 F3의 접근 시점을 앞당기는 변경이다. 다만 `available`의 을해군란(`KOR_establishment_of_the_national_salvation_army`) 완료 조건을 유지하므로 군내 극우인사 포섭 직후 바로 시작할 수 있는 것은 아니다. 기존 362개 본선의 조건·연결·보상과 `KOR_stop_democracy`의 내분 정부 제거·안정도 −10%도 보존한다. F3는 병역 기록 정비, 예비 인력 소집, 산업 필수 업무의 배치, 두 정책의 행정 통합을 다룬다. 실제 역사상 기관의 존재나 설립 시기를 주장하지 않는다.

F3에는 F1·F2의 중점 완료나 국민정신 보유 조건이 없다. 세 묶음의 순서를 강제하지 않으며 기존 362개 중점의 ID·보상·조건·기간·AI·기본 좌표와 정치 압축 offset을 보존한다. F1의 사업 비용·취소·대기 플래그와 F2 참모업무 정신을 변경하지 않는다. 군대 수량, 실제 영토 소유권, 징병법과 기존 산업 선택도 바꾸지 않는다.

## 중점과 병렬 진행

표의 새 ID에는 모두 `HOK_KOR_` 접두사가 붙는다. 새 중점은 각 35일(`cost = 5`)이며 파시즘 정부·내전 없음·구국군 수립 완료를 요구한다. 항복 중 진행할 수 없고 조건 상실 시 취소하며 계속 진행하지 않는다. 기존 정치 경로의 상호배타 관계를 유지하며 F3 내부에는 상호배타 조건을 추가하지 않는다.

가운데 두 중점은 어느 순서로도 모두 완료할 수 있다. 최종 중점은 별도 `prerequisite` 블록 두 개로 AND를 표현한다. 하나의 블록에 둘을 넣어 OR로 만들지 않으며, 배치 기준인 `relative_position_id`와 실제 선행 관계를 구분한다. 후보 문서의 기존 4개 직렬 연결은 이 3행 병렬 명세로 대체한다.

기존 부모의 기본 좌표는 `(167,3)`이며 명부는 이 부모 기준 `(7,1)`이다. 소집계획·필수인력 기준·최종 일원화는 모두 먼저 선언한 명부 기준으로 각각 `(-1,1)`·`(1,1)`·`(0,2)`다. 가운데 두 정책이 병렬이고 최종 합류가 명부와 같은 열인 대칭 3행 배치다. 새 묶음의 중심점 범위는 x173~175·y4~6이며 전체 기본 범위 x0~204·y0~24를 늘리지 않는다. 좌표는 [좌표 자료](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)와 함께 유지한다.

파시즘 진입 완료 후 HIDE에서는 기존 파시즘 루트의 x offset −84를 상대 배치 체인으로 상속한다. 새 4개의 최종 모델 좌표는 순서대로 `(90,4)`·`(89,5)`·`(91,5)`·`(90,6)`이고 파시 구역 범위는 x74~91이다. 새 자식에 offset을 중복 추가하지 않는다. 정치 선택 전 및 SHOW 기본 위치와 선택 후 HIDE 위치를 구분한다. 새 배치의 실제 이미지 크기 무여백 모델에서 SHOW/HIDE 사각형·선 접촉·공선 후보는 없었다. 8px 여유 모델에는 을해군란 인근 후보 1개가 남으며 실제 화면 검증을 대신하지 않는다. 이전 배치의 공선 발견과 최종 화면 재검증은 [구현 기록](incidents/2026-09-22-korean-fascist-mobilization.md)에 따로 기록한다. F1·F2를 필수 선행으로 삼지 않는다.

명부부터 가장 긴 연결 사슬은 3개다. 최초 인력·정치력은 35일, 병역행정 I 또는 산업 연구·필수인력 정신은 해당 정책을 먼저 선택하면 70일, 두 정책 모두 완료는 105일, 최종 정신 II까지 전체 **140일**이다. 기존 부모·을해군란까지의 진행과 조건 대기·중단은 제외한다. 병렬 배치는 중점 둘을 동시에 진행한다는 뜻이 아니다.

## 국민정신·일회 보상·정부 상실

| 국민정신 ID | 표시 이름 | 실제 modifier |
|---|---|---|
| `HOK_KOR_nrsc_manpower_administration_1` | 병역행정 체계 I | `conscription_factor = 0.20`, `mobilization_speed = 0.20` |
| `HOK_KOR_nrsc_manpower_administration_2` | 병역행정 체계 II | `conscription_factor = 0.30`, `mobilization_speed = 0.30` |
| `HOK_KOR_nrsc_essential_workforce` | 필수인력 배치정책 | `production_factory_efficiency_gain_factor = 0.15` |

II는 I의 두 수정치를 각각 10%p 강화한 최종값이다. I와 II를 합산하지 않는다. 하위 정신을 보유하면 해당 계열만 교체하고, 제거된 상태라면 II를 직접 지급한다. 최종 합류는 별도 필수인력 배치정책을 제거하거나 다른 정신으로 덮어쓰지 않는다. 따라서 정상 완료 후 F3 정신은 II와 필수인력 정책의 2개가 남는다.

세 정신은 `original_tag = KOR`에 허용하고 내전 국가에서도 적용 가능한 기존 F1·F2 선언 방식을 따른다. 파시즘 정부를 상실하면 `cancel` 조건으로 해당 F3 정신만 제거하며, 정부 복귀만으로 자동 재지급하지 않는다. 시작한 중점의 조건 상실 취소와 이미 보유한 정신의 정부 상실 제거는 별도 동작이다. 내전 여부만으로 이미 지급된 정신을 제거하지 않는다.

인력 25,000과 정치력 100은 국가 범위의 즉시 보상이다. 특정 주의 인구를 늘리거나, 그 주의 소유권을 바꾸거나, 실제 배치된 사단 병력을 25,000 늘리는 효과가 아니다. 정부 상실 후 일회 지급분을 회수하지 않는다.

산업 연구 혜택은 이름 `HOK_KOR_nrsc_skilled_worker_exemptions`, `bonus = 1.5`, `uses = 1`, `category = industry`다. 영구 연구 속도와 앞서가기 불이익 감소가 아니며 F1 또는 기존 산업 연구 혜택을 삭제하지 않는다. 필수인력 정책은 숙련 인력을 생산 현장에 유지하는 제도를 생산효율 증가로 표현한다. 별도 노동인구 자원이나 징병 면제 인원을 실제 계산·차감하는 시스템을 만들지 않는다.

## 기존 효과와 누적 범위

`conscription_factor`는 **징병 가능 인구 계수**이며 `conscription`의 인구 비율과 다르다. I의 +20%를 전체 인구의 20% 추가 징병이나 +20%p로 설명하지 않는다. 동원 속도는 인력의 동원 진행을 보정하며, 이미 동원 가능한 인력이 없는 상황에서도 매일 새로운 인구를 생성하는 효과가 아니다.

| 실제 함께 보유한 정책 | 같은 수정치의 부분 합 | 보존·구분 사항 |
|---|---|---|
| 기존 농업사회 + 새 병역행정 I | 인구 계수 −40% +20% = −20% | 기존 농업사회 자체는 유지 |
| 기존 농업사회 + 새 병역행정 II | 인구 계수 −40% +30% = −10% | 기존 산업 경로로 농업사회가 제거되면 그 −40%만 사라짐 |
| 기존 여성 비전투 임무 + 새 II | 기존 `conscription = 0.01` 유지, 새 `conscription_factor = 0.30` 별도 적용 | 인구 비율 +1%p와 인구 계수 +30%를 같은 항목으로 더하지 않음 |
| 공통 도제 정신 I + 필수인력 정책 | 생산효율 증가 +30% +15% = +45% | 도제 정신 I→II 교체는 기존 경로에서 수행 |
| 공통 도제 정신 II + 필수인력 정책 | 생산효율 증가 +60% +15% = +75% | 두 단계 도제 정신을 함께 합산하지 않음 |

기존 근거는 `common/ideas/korea.txt:4–20,246–263`, `common/ideas/HOK_KOR_industry_expansion.txt:39–62`다. F3가 기존 여성 비전투 임무·도제 정신을 자동 지급한다는 뜻이 아니며 실제 보유 시의 같은 수정치 부분 합만 표시한다. 기존 법률·기술·주 인구·비핵심 보정·다른 정책을 포함한 최종 동원 인원과 생산효율 증가 시간은 실제 게임에서 따로 확인한다.

F1 군수조달 II의 공장 생산량 +15%와 F3의 생산효율 증가 +15%는 서로 다른 수정치다. 양산/유연생산의 효율 한도·전환 보존과 불이익을 모두 유지한다. `KOR_jaebeol`의 생산량 +20%는 공산 자산몰수 경로의 보상이므로 일반적인 파시즘 누적 보상으로 가정하지 않는다. 신규 누적량 검토를 이유로 기존 강화값을 낮추지 않는다.

이번 보상은 국가 국민정신·국가 인력·정치력·산업 기술 보너스만 사용한다. 정보기관·MIO·특정 DLC 장비나 교리 항목을 호출하지 않으므로 별도 DLC 게이트를 추가하지 않는다. 이는 다른 DLC 구성에서 실행 검증을 완료했다는 뜻이 아니다. 단계 교체와 정부 상실 취소는 기존 F1·F2 구조를 따른다.

새 중점 AI 기본 가중치는 2다. 두 가운데 정책의 순서를 강제하지 않고 기존 민주 역사 AI 목록에 넣지 않는다. F1·F2·공통 산업·기존 파시즘 정복 경로와의 선택 경쟁 및 실제 400,000·700,000 배치 병력 조건 도달 시점은 별도 AI 검증 대상이다. 명부의 국가 인력 보상 자체가 배치 병력 조건을 직접 충족하지는 않는다.

## 이미지와 검증 경계

중점 4개와 국민정신 3개의 이미지에는 해당 파시즘 가지의 갈색·차콜 바탕과 금속 장식을 사용한다. 명부와 신원표, 소집 일정과 예비군 철모, 산업 필수 작업자와 작업대, 통합 병적 기록으로 소재를 구분한다. 실제 단계가 있는 병역행정 정신에만 I·II를 붙이며 필수인력 정신에는 임의 단계 번호를 붙이지 않는다. 이미지·GFX·마스크·광택은 프로젝트 내부 실제 파일과 상대경로로 연결한다. 이번 묶음에는 결정이 없으므로 결정 아이콘을 추가하지 않는다. 이미지 통합 결과와 출처 기록은 별도 제작 산출물과 대조한다.

이전 F3 배치 소스 `6a5d06e4548784454fa6a969e4c80b5e01d79726c84b837efdaf560bf8f17a5d`의 정적 검사는 50 PASS / 0 FAIL, 초기 상태 설정과 기준 측정을 분리한 강제 완료 보상 검사는 130 PASS / 0 FAIL이었다. 최초 45 PASS / 1 FAIL은 합성 초기 상태의 기존 F1 생산량 기대값 비교 문제로 보존하고 합계에서 제외한다. 실제 연결선 공선에 대응한 최종 소스 SHA-256은 `91520275c5ce45e670e921355603b860fec524372ce0ee58c622b4c6d049b61f`다. 2026-09-23 최종 추가 정적 검토 **44 PASS / 0 FAIL**과 세 보상 시나리오의 별도 재실행 **130 PASS / 0 FAIL**을 확인했다. 이전 50·130건과 최종 결과를 합산하지 않는다. 인력 25,000·정치력 100, I/II 수정치와 교체·부재 시 직접 지급, 필수인력 정신 및 기존 합성 정신의 효과 보존을 확인했다. 산업 연구는 범주의 존재를 조회했고 +150%·1회는 소스로 대조했으며 실제 소모는 검사하지 않았다. 2026-09-23 별도 새 게임에서 최종 상단 HIDE·SHOW 화면과 명부의 정상 UI 시작·진행·완료를 확인했다. 진단 없는 새 게임 로드(53b0)도 완료했고 신규 정규화 오류는 0건이다. 다음은 전체 검증 목록이며 실제 관측 여부는 [구현 기록](incidents/2026-09-22-korean-fascist-mobilization.md)의 소스별 결과를 따른다.

1. 기존 362개 중점 원문·정치 압축 offset·미커밋 runtime 변경 보존, 새 ID 중복·참조·상대 기준 선언 순서·연결 구조 검사.
2. 두 가운데 중점의 양쪽 진행 순서와 한쪽만 완료했을 때 최종 AND 차단, 전체 140일 설계 확인.
3. 명부의 국가 인력 25,000·정치력 100, 산업 연구 +150%·1회·범주, 각 국민정신 modifier의 실제 지급 확인.
4. I→II 교체와 하위 정신 부재 시 II 직접 지급, 필수인력 정신 유지, F1·F2 및 공통 인력·산업 정신 보존 확인.
5. 파시즘 상실 시 세 정신 제거·복귀 시 자동 재지급 없음, 내전/항복에 따른 새 중점 시작·취소, F1·F2와의 독립 접근 확인.
6. 명부 1개의 UI 시작·35일 진행 표시·자연 완료는 관측했다. 나머지 3개와 전체 140일 진행, 연구 혜택 소모·동원 속도·생산효율·AI 선택, 새 저장/재로드와 기존 저장, DLC 구성·멀티플레이는 각각 별도 검증.
7. 정치 선택 전후 SHOW/HIDE, 숨은 기준점, 명판·연결선·아이콘 잠금/진행/완료/광택을 실제 화면에서 확인.

이전 배치의 실제 화면은 1600×900·GUI 배율 1, 중점 확대 수치 미측정의 초기 HIDE에서 먼저 확인했다. 파시즘 정부지만 정치 진입은 미완료이고 F3 4개를 강제 완료한 합성 상태였다. 완료 4개와 정신 II·필수인력 아이콘을 확인했고 인접 아이콘·명판 가림을 관측하지 않았으나, 이를 연결선끼리의 분리까지 확인한 것으로 보지 않는다. 이후 확대된 분기 완료 HIDE의 `03-f3-fascist-hide-connector-overlap-0.png`에서 세계위에 군림하는 대한→명부 진입선이 F2 합류선과 공선으로 겹침을 확인했다. 최종 상단 배치는 이 진입점을 바꾼 것이다. 당시 컴퓨터 제어 중지로 최종 화면을 확인하지 못했으나, 2026-09-23 별도 합성 선행조건의 새 게임 두 개에서 최종 상단 HIDE·SHOW를 관측했다. 관측한 구역의 아이콘·명판 가림과 관계없는 연결선 공선은 없었다. 두 상태를 따로 본 것이며 실제 정치 선택에 따른 전환 검증은 아니다. 진단 없는 최종 새 게임 로드(53b0)는 완료했고 신규 정규화 오류는 0건이다.

정적 검사, 강제 완료 보상 검사, 화면 관측, 진단 없는 새 게임 로드는 서로 다른 검증이다. 명부는 1936.1.1 12시 UI에서 시작해 1월 15일 03시 15/35 진행 표시와 2월 4일 03시까지 자연 완료를 관측했고 양쪽 후속 중점의 시작 버튼이 활성화됐다. 강제 완료·날짜 변경은 사용하지 않았다. 정확한 완료 틱·초기 적립 진행도는 계측하지 않았으므로 정확히 35×24시간 경과했다고 단정하지 않는다. 나머지 3개 정상 진행·한쪽 선행만 완료한 UI의 AND 차단·연구 혜택 소모·정부 상실 취소·시간에 따른 동원과 생산효율·장기 AI·기존 저장·다른 DLC·멀티플레이는 별도 확인이 필요하다. 최종 소스의 명부 선택 가능·진행·완료 표시와 미완료 자식 아이콘을 관측했다. 이전 소스의 정신 II/필수인력 화면과 구분하며, 광택 전체 주기·정신 I 및 다른 3개 중점의 진행·완료 표시는 별도 확인이 필요하다. 좌표 모델이나 조용한 오류 로그만으로 장기 플레이와 모든 화면이 검증됐다고 표현하지 않는다.
