## 1. 목표와 범위

한국 중점 326개(기존 266개 + 1차 확장 60개)를 유지하면서 분야별 공간과 연결선 통로를 압축했다. 첫 재배치의 과도한 공백을 줄이되, 아이콘·이름판의 전체 면적과 다중 선행·배타선 통로를 확보한다. 기간·효과·선행 AND/OR·배타·표시 조건·AI는 그대로 두며 실제 화면에서 발견되는 간섭은 배치 범위 안에서 조정한다.

이 문서는 [전체 확장 설계](HOK_KOREAN_FOCUS_EXPANSION_PLAN.md)의 UI 후속 계획과 적용 기록이다. 450~470개로 늘리는 장기 콘텐츠 확장과는 별도 작업이다. [첫 60개 명세](HOK_KOREAN_FOCUS_FIRST_60_SPEC.md)는 상대 기준을 따라 계산한 새 기본 절대좌표를 기록하며, 파일에 적힌 상대값 및 조건부 이동과는 구분한다. 초기 문제 분석은 2절, 현재 적용·검증 상태는 7절에 남긴다.

| 구분 | 재배치의 범위 |
|---|---|
| 배치 변경 | 중점 `x`, `y`, `relative_position_id`와 절대/상대좌표 전환, 표시 위치를 옮기는 `offset` 값·적용 범위, 지속적 중점 패널 위치, 바로가기 목적지와 화면 이동 설정 |
| 보존 | 중점 수·ID·이름·설명·아이콘, 비용·기간·보상, 선행조건의 AND/OR 구조, 상호배타 관계, 우회·취소·시작·표시 조건, AI 가중치 |

| 제외 | 중점 추가·삭제, 보상 재조정, 선을 줄이기 위한 선행조건 삭제, 배치 문제를 감추기 위한 가지 숨김, 새로운 UI 시스템 도입 |

`offset`을 새 중점에 맞추는 경우에도 기존 이념 선택·표시 규칙의 의미를 유지한다. 표시 조건을 바꾸거나 연결 관계를 바꿔야만 해결되는 안은 이 배치 작업에 포함하지 않는다. 정적 대조에서 전체 ID와 배치 외 게임 진행 정의의 보존을 확인했으며, 조건별 실제 표시 결과는 별도로 검증한다.

## 2. 재배치 전 확인한 문제와 근거

아래는 최초 설계 당시의 기준선 기록이며 현재 좌표표가 아니다. 사용자가 대화에 첨부한 정치·외교 및 산업 화면에서는 긴 연결선이 다른 가지 영역을 가로지르고, 산업 화면의 지속적 중점 패널 아래로 연결선이 들어가는 모습이 보였다. 첨부 화면은 대화 자료이며 저장소에 별도 이미지 파일로 보존한 것은 아니다.

| 판단 | 근거와 한계 |
|---|---|
| `CONFIRMED` | 첨부 화면에 긴 연결선과 패널에 가려진 구간이 보인다. 다만 화면만으로 각 선의 출발·도착 ID를 모두 식별한 것은 아니다. |
| `CONFIRMED` | 아래 소스 예시에서 신규 중점과 기존 부모 중점의 세로 좌표 차이는 14~16이다. 일부 부모에는 조건부 이동이 있고 해당 신규 중점에는 없다. |

재배치 전 트리 상단에는 바로가기 세 개(11~14행)와 `continuous_focus_position = { x = 200 y = 1100 }`(18행)이 정의되어 있었다. 현재의 바로가기 8개와 패널 위치는 4.5절에 기록한다. 지속적 중점 패널 위치는 일반 중점의 `x`, `y`와 별도로 다루며, 두 설정의 숫자를 같은 격자 단위로 계산하지 않는다.

## 3. 겹침을 구분하는 기준

| 종류 | 확인할 내용 | 설계 목표 |
|---|---|---|
| 중점 ↔ 중점 | 중심 좌표뿐 아니라 아이콘 테두리·이름판의 실제 면적 | 동시에 표시되는 중점의 겹침 0건 |
| 선 ↔ 중점 | 관계없는 아이콘·이름판을 선이 통과하거나 뒤에서 가려지는지 | 관계없는 중점 통과 0건 |
| 선 ↔ 선 | 분기·합류와 무관한 교차, 다른 관계가 한 선처럼 보이는 중첩 | 불필요한 교차·중첩 최소화, 남는 사례 개별 기록 |

선이 자기 부모·자식에 연결되는 부분이나 의미 있는 분기·합류는 결함으로 세지 않는다. 동일한 `(x, y)`가 없다는 정적 결과는 첫 항목의 일부만 확인하며, 나머지 항목의 통과 근거가 될 수 없다. 기존 기능 검증 결과도 시각적 겹침 검증을 대신하지 않는다.

## 4. 배치 원칙

### 4.1 분야별 공간 확보

산업·교육, 육군, 해군, 공군, 정치·외교를 식별 가능한 구역으로 나눈다. 정치·외교 내부에서는 기존 이념 노선과 그 후속 가지가 섞이지 않도록 공간을 둔다. 각 구역의 실제 좌우 순서와 크기는 기존 연결 관계를 함께 보고 결정한다.

| 구역 | 배치 방향 |
|---|---|
| 산업·교육 | 기존 산업·연구 가지 주변에 전력·교육·생산·지역 사업 모듈 배치 |
| 육군 | 기존 군비·교리 가지 주변에 조달·통신·정비·참모 모듈 배치 |
| 해군·공군 | 각 기존 부모 가까이에 후속 모듈을 두고, 육군 구역과 충분한 간격 확보 |
| 민주 내정·외교 | 의회·행정, 의용군 지원, 아시아 연합 운영을 각각 실제 부모 주변에 배치 |
| 기타 정치 노선 | 현재 콘텐츠와 연결 관계를 보존하며, 인접 구역 이동의 영향을 함께 검토 |

신규 중점만 아래쪽 먼 줄에 모으지 않고, 각 모듈을 부모 가까운 옆이나 아래에 붙인다. 그 자리에 기존 가지가 있다면 양쪽을 묶어 재배치한다. 기존 중점을 옮길 때는 이동 대상의 모든 부모·자식·상호배타 상대까지 영향 범위를 확인한다.

### 4.2 연결선을 위한 빈 공간

- 형제 중점은 긴 한글 이름판까지 고려해 가로 간격을 둔다. 부모와 자식의 세로 간격도 아이콘과 선이 구분될 만큼 확보한다.
- 갈라지는 지점과 다시 합쳐지는 지점에 여백을 두고, 연결 대상의 좌우 순서를 맞춰 불필요한 교차를 줄인다.
- 긴 연결이 필요한 구역 사이에는 다른 중점을 놓지 않는 빈 통로를 둔다. 통로 폭은 실제 표시 배율에서 확인해 확정한다.
- 여러 부모를 가진 중점은 모든 연결을 함께 보고 배치한다. 하나의 선만 짧게 만들고 다른 선이 여러 가지를 가로지르게 하지 않는다.
- 상호배타 중점은 비교하기 쉬운 위치에 두고, 배타 표시와 선행 연결선이 이름판에 겹치지 않게 한다.

빈 통로는 엔진에 선의 경유점을 직접 지정한다는 뜻이 아니다. 이 문서에서는 개별 연결선의 꺾임을 직접 제어하는 방법을 확인하지 않았다. 중점 위치를 조정한 뒤 엔진이 실제로 그린 결과를 보고 반복 조정한다. 현재 선행 관계를 유지하면서 모든 선 교차를 완전히 없앨 수 있는지는 미확정이다.

### 4.3 채택한 좌표 방식: 절대 기준점과 상대 배치

원본 일본처럼 일부 기준 중점에는 절대좌표를 두고, 나머지는 `relative_position_id`로 기준을 지정해 상대 `x`, `y`를 사용한다. 후속 중점뿐 아니라 산업·군사 등 큰 구역의 시작점도 다른 기준 중점에 상대 배치할 수 있다. 모든 구역의 시작점을 절대좌표로 만드는 규칙은 두지 않는다.

개념적인 위치 참조 구조는 다음과 같다. 이는 게임 진행 순서나 확정된 한국 중점 연결도가 아니다.

```text
절대좌표 기준 중점
├─ 상대좌표 구역 기준 중점
│  ├─ 상대좌표 후속 중점
│  └─ 상대좌표 후속 중점
└─ 상대좌표 다른 구역 기준 중점
```

| 설정 | 역할 | 설계 기준 |
|---|---|---|
| 절대 `x`, `y` | 트리 안에서 기준 위치 지정 | 기존 중점 중 안정적인 기준을 선택; 배치만을 위한 새 중점은 추가하지 않음 |
| `relative_position_id`와 상대 `x`, `y` | 기준 중점에서 떨어진 위치 지정 | 구역·모듈의 간격을 관리하기 쉬운 기준을 선택 |
| `prerequisite` | 실제 진행에 필요한 선행조건과 연결선 관계 | 기존 반복 블록과 AND/OR 구조를 그대로 보존 |
| `offset` | 특정 상태에서 위치 보정 | 적용 조건과 이동을 담당할 기준점을 명세에 기록하고 실제 결과 확인 |

다중 선행 중점도 배치 기준은 하나를 선택한다. 그 선택으로 다른 부모를 제거하거나 선행조건을 다시 묶지 않는다. 직전 부모를 기준으로 삼는 방식과 같은 모듈의 기준점을 공유하는 방식을 비교해, 모든 연결선과 조건부 이동에 유리한 쪽을 선택한다.

기준 ID의 존재·유일성을 확인하고, 자기 자신을 기준으로 삼거나 A→B→A처럼 참조가 순환하지 않도록 한다. 각 참조 연쇄가 절대 기준점까지 이어지는지 기록한다. 이 위치 참조 관계는 중점 진행의 선행 관계와 별도로 관리한다. 기준 중점이 숨겨지거나 상호배타로 선택되지 않는 상태도 실제 표시 검수에 포함한다.

절대좌표를 상대좌표로 바꿀 때 기존 `x`, `y` 숫자를 그대로 남기지 않는다. 목표의 트리상 기본 위치에서 기준 참조 연쇄를 따라 계산한 기준 중점의 트리상 기본 위치를 빼 상대값을 정한다. 기준 중점 자체가 상대좌표라면 파일에 적힌 상대 `x`, `y`를 트리상 위치로 오인하지 않는다. 조건별 최종 위치는 별도로 확인한다. 좌표 체계 전환 자체가 간격 확대나 선 교차 해소를 보장하지 않으므로 4.1~4.2의 배치 원칙을 함께 적용한다.

### 4.4 조건부 좌표 이동

2026-09-21의 326개 압축 기준선은 직접 `offset` 4개의 기존 조건문을 보존하고 x/y 이동량을 모두 0으로 뒀다. HIDE에서 가지가 숨겨지는 조건은 유지하면서 구역 이동을 고정한 당시 동작이다. 150개 직접 offset을 4개로 정리하고 146개 자식을 상대 기준에 귀속시킨 과정은 [첫 재배치 이력](incidents/2026-09-21-korean-focus-layout.md)이며, 현재 정치 선택 후 압축의 offset 명세와 구분한다.

각 구역의 이동을 어느 기준 중점이 담당할지 정하고, 기존 `offset`을 자식마다 자동 복제하거나 일괄 삭제하지 않는다. SHOW, HIDE 조건 성립 전·후에서 최종 위치를 대조해 중복 이동·불필요한 잔여 보정·다른 구역과의 충돌 여부를 확인한다. 원본 일본에 같은 구조가 있다는 사실만으로 한국의 보정 수치가 맞다고 판단하지 않는다.

2026-09-21 기준선의 이동량 0 검수와 아래 현재 조건부 이동 검수는 구분한다. 조건 성립 전후의 가지 숨김과 표시되는 중점의 정렬을 확인하며, `available`로 선택이 막히는 상태와 화면에서 숨겨지는 상태도 구분한다. 선택할 수 없지만 화면에 남는 중점도 면적을 차지한다.

2026-09-22 승인된 정치 압축 구현은 이 고정 상태에서 **네 정치 경로의 선택 후 압축**으로 화면 동작을 바꿨다. F3까지 추가한 현재는 중점 366개·절대 기준 7개·상대 배치 359개이며 기본 범위 x0~204·y0~24는 유지한다. 직접 offset은 기존 공화국 공통 진입의 노선별 3개와 정치 기준점 4개를 보존한다. 이동 조건은 HIDE와 해당 분기 중점 완료다. SHOW·선택 전·진행 중에는 기본 배치를 유지하며, 현재 집권 이념이나 클릭만으로 이동하지 않는다. F3 추가는 기존 362개의 숨김·진행 조건·보상·AI·좌표와 공통 산업·군사·만주 위치를 바꾸지 않는다.

| HIDE에서 완료한 노선 | 정치 기준점 이동량 (x,y) | 계산한 기준점 x | 해당 정치 구역의 계산 x 범위 | 공화국 공통 진입 x |
|---|---|---:|---|---|
| 공산 | (-5,0) | 79 | 68~95 | 79 |
| 민주 | (-35,0) | 92 | 73~123 | 92 |
| 파시 | (-84,0) | 83 | 74~91 | 83 |
| 비동맹·왕정 | (-101,0) | 85 | 75~103 | 기존 조건대로 숨김 |

위 값은 조건과 상대 기준 사슬로 계산한 좌표이며 실제 화면 관측값이 아니다. 자손에 같은 offset을 다시 넣지 않고 구역 기준점의 이동을 한 번만 반영한다. F3까지 포함한 현재 366개 소스 SHA-256은 `91520275c5ce45e670e921355603b860fec524372ce0ee58c622b4c6d049b61f`다. F3는 군내 극우인사 포섭 `(167,3)`에서 `(174,4)` → `(173,5)/(175,5)` → `(174,6)`으로 연결한다. 을해군란 완료 조건은 유지하되 세계위에 군림하는 대한 완료를 더 이상 요구하지 않아 새 4개의 진입만 앞당겼다. 기존 362개와 새 보상·140일은 보존한다. 세부 조건과 좌표는 [정치 압축 계획](HOK_KOREAN_POLITICAL_COMPACTION_PLAN.md), [현재 좌표 명세](HOK_KOREAN_FOCUS_LAYOUT_COORDINATES.md), [F3 명세](HOK_KOREAN_FASCIST_MOBILIZATION_SPEC.md)를 따른다. 362개 정치 압축 검증과 F3의 이전 `6a5d06…f17a5d` 소스 정적 50·보상 130 PASS / 0 FAIL은 최종 소스 결과가 아니다. 이전 소스의 초기 HIDE에서 완료 아이콘·정신을 확인했으나, 확대된 분기 완료 HIDE에서 F2 합류선과 F3 진입선의 공선을 실제로 관측했다. 새 배치의 실제 이미지 크기를 사용한 무여백 SHOW/HIDE 사각형·선 접촉·공선 모델에서는 후보가 없었다. 8px 여유 모델의 을해군란 인근 후보 1개는 별도로 남긴다. 2026-09-23 최종 추가 정적 검사 44건·보상 재검사 130건과 진단 없는 새 게임 로드(53b0)·신규 정규화 오류 0건을 확인했다. 2026-09-23 별도의 정치 분기 완료 합성 새 게임에서 최종 F3 상단 구역의 HIDE와 SHOW를 각각 관측했다. 네 중점과 부모·을해군란·인접 F2의 선·아이콘·명판이 분리되어 있었고 SHOW의 인접 왕정 구역도 가리지 않았다. 이는 선택 전부터 완료 후까지의 압축 전환 검사가 아니다. 병역행정 명부의 UI 시작·35일 진행·완료와 이후 두 자식의 시작 가능 상태를 확인했다. 세부 근거는 [별도 구현 기록](incidents/2026-09-22-korean-fascist-mobilization.md)에 구분한다. 나머지 3개 정상 진행·최종 AND 차단·전체 140일·광택·패널·모든 바로가기·저장 후 재로드 검증은 남아 있다.

### 4.5 지속적 중점 패널과 바로가기

현재 지속적 중점 패널은 `continuous_focus_position = { x = 200 y = 1700 }`이다. 첫 재배치의 (200,3400)에서 압축 높이에 맞춰 조정했다. 패널 위치는 중점 격자와 별도 설정이다. 2026-09-21의 326개 압축본 HIDE 초기 상태, 1600×900·GUI 배율 1에서 패널 공간과 산업·만주 사이 여유를 확인했으며, 패널 뒤 중점이나 연결선의 가림은 관측되지 않았다.

압축 배치에서도 다음 바로가기 8개와 `scroll_wheel_factor = 0.65`를 유지한다. 전체 분야 검수에 활용했으며, 만주 목적지의 하단 걸림은 아래에 남은 한계로 기록한다.

| 구역 | 현재 목적지 ID | 화면 배율 설정 |
|---|---|---|
| 산업 | `KOR_devalue_the_won` | `0.65` |
| 군사 | `KOR_begin_rearmament` | `0.65` |
| 만주 | `KOR_the_manchurian_project` | `0.65` |
| 공산 | `KOR_long_live_the_dictatorship_of_the_proletariat` | `0.65` |
| 민주 내정 | `KOR_democracy_advance_forward` | `0.65` |

| 군주 | `KOR_urihwangsilsaranghoe` | `0.65` |

현재 압축 배치에서도 만주 바로가기의 목적지가 화면 하단에 걸리는 한계가 남아 수동 스크롤로 전체 15개를 확인했다. 첫 재배치에서 만주·아시아연합을 대상으로 한 factor 생략 비교와 첫 상단·반복 하단 잘림 관측은 [AA58 이력](incidents/2026-09-21-korean-focus-layout.md)으로 구분한다. 그 이력을 현재 아시아연합 버튼의 재검증 결과로 사용하지 않는다.

### 4.6 후속 정치 확장의 긴 직렬 가지 방지

2026-09-22 사용자 요청에 따라 파시즘·비동맹주의 확장에도 적용할 설계 기준이다. 비동맹주의에는 입헌군주·전제군주·환제국 후속 정책을 포함한다. [공산 병렬화 기록](incidents/2026-09-22-korean-communist-parallel.md)처럼 독립적인 정책 묶음을 직전 묶음의 끝에 계속 이어 붙여 한 줄이 길어지는 구조를 반복하지 않는다. 이 절은 향후 설계 규칙이며 기존 파시즘·비동맹 코드나 좌표를 변경한 기록이 아니다.

- 먼저 정책별 묶음과 적절한 공통 진입점을 정하고, 독립적인 묶음은 옆으로 갈라지게 설계한다. 한 묶음은 대체로 3~5개를 기준으로 검토하되 개수를 채우거나 억지로 잘라내지 않는다. 더 긴 필수 연쇄가 필요하면 정책·진행상의 이유와 다른 배치안 검토를 명세에 남긴다. 모듈 이름만 나누고 앞 묶음 전체 완료를 계속 요구하면 긴 직렬 진행은 해결되지 않는다.
- 같은 정치 경로 안의 병렬 정책은 원칙적으로 어느 쪽부터 진행해도 되고 모두 완료할 수 있게 한다. 실제 정책 대립이 있는 선택만 상호배타로 둔다. 입헌·전제 등 기존 정치 경로 사이의 배타 관계는 이 원칙과 별개로 유지한다. 국민정신 I→II, 국가 형성·영토 보유·전쟁 결과 등 필요한 내부 순서와 진입 조건도 유지한다.
- 그림만 좌우로 꺾거나 멀리 떨어진 합류점을 만들어 길이를 감추지 않는다. 전체 좌표를 계산하여 최대 필수 연쇄 길이와 표시 행 수를 따로 기록하고, 가로 폭·세로 깊이·주변 노선·이름판·연결선·패널·바로가기를 함께 검토한다. 공산 사례의 4~5개 길이, 상대좌표 ±2 또는 x73/x77 등의 실제 값은 다른 노선에 그대로 복사할 고정 규격이 아니다.
- 선행 변경으로 주요 보상·결정이 얼마나 일찍 열리는지, 모든 묶음을 완료하는 데 필요한 총 시간이 어떻게 달라지는지 기록한다. 보상을 줄여 배치 문제를 보정하지 않는다. 기존 ID·보상·기간·상위 국민정신 승계는 해당 구현 범위에서 변경이 명시되지 않았다면 보존한다. 기존 선행조건 수정은 배치만 바꾸는 작업과 구분한다.
- 어느 가지를 먼저 완료해도 공유 결정 범주가 표시되고 자기 사업만 해금되는지 확인한다. 개별 결정의 조건·비용·공유 실행 한도·취소·재착수, 국민정신 교체가 다른 가지 완료에 암묵적으로 의존하지 않도록 한다. 필요한 합류 조건은 AND/OR를 명확히 적어 잘못된 조기 해금을 막는다.
- 구현 전 명세에 진입점·병렬/필수 직렬 관계·최장 연쇄·폭/높이·보상 도달 시점·검증 조건을 넣는다. 구현 검증에서는 양쪽 진행 순서와 중요한 차단 조건, AI 선택, 초기 및 이념 선택 후 SHOW/HIDE를 구분한다. 정적 좌표 통과만으로 실제 화면 검수를 완료했다고 기록하지 않는다.

노선별 정책 묶음의 검토 방향은 [2차 확장 계획](HOK_KOREAN_SECOND_WAVE_PLAN.md)을 따른다. 이 규칙을 처음 문서화했을 때는 미적용 후보의 개수·ID·부모·보상을 확정하거나 기존 코드를 변경하지 않았다. 이후 승인된 파시즘 F1 군수계약과 F2 참모업무는 각각 독립된 기존 부모 아래 4개·3행 병렬 구조로 적용했다. F2는 `(172,6)` → `(171,7)/(173,7)` → `(172,8)`이며, 형제 중점 두 개를 모두 요구하는 AND 합류와 배치 기준을 구분한다. 현재 전체 범위 x0~204·y0~24를 유지하며, 후속 실제 화면 검증은 [F2 명세](HOK_KOREAN_FASCIST_STAFF_SPEC.md)와 해당 작업 기록에 별도로 남긴다. 이 추가분을 아래 326개 압축 검증에 포함하지 않는다.

## 5. 최초 설계의 구현 순서

아래 순서는 최초 설계의 절차다. 이번 압축에서는 AA58 기준선·명세·적용·정적 대조와 현재 소스의 HIDE 초기 상태 전체 분야 화면 검수를 마쳤다. HIDE/SHOW 12개 조건은 정적 위치 불변만 확인했으며 이념 전환·SHOW 런타임은 재실행하지 않았다. 첫 재배치의 초기 실행 결과를 압축 배치의 통과 결과로 재사용하지 않는다.

1. **기준선 기록:** 당시 작업 트리와 실제 로드되는 모드 경로, 게임 버전·플레이셋·해상도·UI 배율을 확인한다. 이번 문서의 근거는 기존 설치본 1.19.3 조사와 사용자 첨부 화면이며, 1.19.2 검증을 뜻하지 않는다.
2. **배치 명세 작성:** 현재 326개 전체의 기본 좌표·조건부 좌표·선행 관계를 정리한다. 절대/상대 구분, 상대 기준 ID와 참조 연쇄, 구역 배치도와 전후 좌표표를 작성한다. 정확한 기준 ID와 새 좌표는 이 단계에서 결정한다.
3. **구역별 조정:** 확정한 기준 관계에 따라 상대좌표를 계산하고 기존 부모와 후속 모듈을 묶어 이동한다. 주변 가지와 구역 사이 연결까지 확인하며 지속적 중점 패널 및 바로가기도 배치도에 포함한다.
4. **변경 범위 대조:** 기준 ID의 존재·유일성, 자기참조·참조 순환 여부를 검토한다. 좌표·배치 설정과 필요한 기여자 주석 외에 ID·비용·보상·선행·배타·조건·AI 등이 달라지지 않았는지 확인한다. 위치 참조와 진행 조건은 별도로 대조하며, 연결선 문제를 해결하려고 게임 규칙을 바꾸지 않는다.
5. **표시 상태별 확인:** 아래 상태표를 사용해 실제 화면에서 검수한다. 실행 전 로그를 보존하고, 최종 검증은 게임 전체 재시작 후 수행한다.
6. **결과 기록:** 전후 화면, 최종 좌표표, 남는 교차와 이유, 검증한 구성 및 미검증 구성을 기록한다. 실제로 확인하지 않은 구역을 완료 처리하지 않는다.

배치 명세에는 최소한 다음 항목을 둔다.

| 항목 | 기록 내용 |
|---|---|
| 대상 | ID, 한글 이름, 구역, 기존/신규 구분 |
| 진행 관계 | 부모 목록과 AND/OR 구조, 자식 목록, 상호배타 상대 |
| 위치 참조 | 현재/제안 좌표 유형(절대/상대), `relative_position_id`, 기준 참조 연쇄와 선택 이유 |
| 위치 | 현재/제안 절대 또는 상대 `(x, y)`, 계산한 기본 위치, 각 `offset` 조건과 조건별 최종 위치 |
| 표시 | 표시·숨김 조건, 선택 불가 상태에서의 표시 여부 |
| 여백 | 아이콘·이름판 범위, 연결선 통로, 패널과의 거리 |
| 판정 | 확인한 게임 상태·배율·화면 자료, 남는 문제와 조정 이유 |

## 6. 검수 상태표와 완료 기준

아래는 **검수 기준**이며 완료 목록이 아니다. 현재 압축 배치의 조건·구역별 실제 관측과 미검증 범위는 [현재 압축 기록](incidents/2026-09-21-korean-focus-compact.md)에 구분한다.

| 검수 상태 | 확인할 사항 |
|---|---|
| SHOW / 이념 선택 전 | 동시에 표시되는 전체 가지와 신규 모듈의 간격 |
| SHOW / 각 이념 선택 후 | 비활성 가지까지 포함한 선·이름판 간섭 |
| HIDE / 이동 조건 성립 전 | HIDE 설정만 선택한 초기 배치 |
| HIDE / 각 이동 조건 성립 후 | 숨김 결과와 모든 관련 `offset`, 이동하지 않는 인접 모듈과의 충돌 |
| 상대 기준의 표시 상태 변화 | 기준 중점이 숨겨지거나 선택되지 않은 상태에서 참조 중점의 위치, 보정 중복 여부 |
| 분기 선택 전·후 | 상호배타 표식, 다중 선행 연결, 완료·진행·잠금 표시 |
| 지속적 중점 패널 표시 상태 | 패널 테두리까지 포함한 노드·연결선 가림 |
| 바로가기 연속 사용 | 산업·군사·만주·공산·민주 내정·아시아 연합 외교·구국군·군주 8개를 순방향·역순·반복 이동하고 목표 가지와 버튼의 가림 확인 |
| 지원 화면 구성 | 현재 기록된 1600×900을 포함해 지원할 해상도·UI 배율·확대/축소 단계와 전체 스크롤 범위 |
| 지원 시작일 | 해당 작업에서 지원 대상으로 확정한 시작일별 초기 표시 상태 |

완료 판정은 다음을 모두 충족한 검증 범위에 한정한다.

- 326개 중점과 모든 게임 진행 규칙이 보존된다.
- 배치 기준 ID가 유효하며 자기참조·기준 참조 순환이 없다. 검수한 상태에서 상대 배치와 조건부 보정이 의도한 최종 위치를 만든다.
- 검수한 상태에서 중점끼리 겹치거나 관계없는 중점의 이름·아이콘을 선이 통과하지 않는다.
- 지속적 중점 패널이 주요 가지를 가리지 않으며, 바로가기와 스크롤로 각 구역에 접근할 수 있다.
- 관계를 오인하게 하는 선 중첩은 해소한다. 남는 선 교차는 위치·관계·이유를 기록하고, 미해결인 경우 완료 보고에 명시한다.
- 검사한 해상도·배율·표시 규칙·이념 상태와 미검증 범위를 구분한다. 일부 화면의 통과를 전체 트리 무겹침으로 확대하지 않는다.

## 7. 첫 재배치와 2026-09-21 압축 기준선 이력

최초 문서화에서 보존 범위와 넓은 배치 원칙을 정했고, 후속 구현에서 326개를 절대 7개·상대 319개로 재배치했다. 첫 배치의 최종 소스는 AA58, 범위는 x0~636·y0~42였다. 만주 유전 (52,32) 조정, 황실 루트 (570,0), HIDE/SHOW 대표 관측, 바로가기 비교와 진단 제거 후 d00f 실행은 [첫 재배치 기록](incidents/2026-09-21-korean-focus-layout.md)에 보존한다.

이후 과도한 폭을 줄이라는 요청으로 2026-09-21의 326개 압축 배치를 적용했다. 범위는 **x0~194·y0~24**, 절대 기준점은 7개, 상대 중점은 319개다. 직접 offset 4개의 조건문을 유지하고 이동량은 모두 (0,0)으로 바꾸었다. 패널은 (200,1700)이다. 현재 만주 유전은 (34,15), 황실 루트는 (176,0)이다.

AA58과 당시 326개 압축본의 focus 블록에서 좌표·상대 기준·offset 이동량과 주석을 제외한 토큰이 동일함을 확인했다. 기간·효과·선행 AND/OR·상호배타·조건·AI는 보존했다. 통합 정적 중점 상자·연결선 기둥 모델의 후보는 0개지만, 실제 아이콘·이름판 가림과 연결선 렌더링의 통과 판정은 별도다.

당시 326개 압축본의 korea.txt SHA-256은 `23049d0d607ecbdfe5454da644c292a55e7d903a4dca1b4f3d930105cde66242`다. 이 절의 좌표·검수는 과거 기준선 이력이며, 현재 366개 소스와 조건부 이동은 4.4절·[현재 좌표 명세](HOK_KOREAN_FOCUS_LAYOUT_COORDINATES.md)·[F3 명세](HOK_KOREAN_FASCIST_MOBILIZATION_SPEC.md)를 따른다. 362개 당시 정치 압축 검증은 [해당 구현 기록](incidents/2026-09-22-korean-political-compaction.md)과 구분한다. 당시 전후 좌표는 [좌표 명세](HOK_KOREAN_FOCUS_LAYOUT_COORDINATES.md), 60개 후속 중점은 [첫 60개 명세](HOK_KOREAN_FOCUS_FIRST_60_SPEC.md)에 기록한다.

**당시 326개 압축본은 HIDE 초기 상태에서 전체 분야 화면 검수를 마쳤다.** HOI4 1.19.3·27bf, 새 1936 한국 게임 일시정지, 1600×900·GUI 배율 1에서 산업·군사·공산·민주·외교·구국군·황실·만주의 위아래·좌우와 지속적 중점 패널을 확인했다. 28개 화면에서 아이콘·이름판 겹침과 관계없는 선의 중점 가림은 0건 관측했다.

HIDE/SHOW 12개 조건은 정적 위치 불변 검사이며 이번 실행에서 이념 전환·SHOW를 재실행하지 않았다. 공유 부모 연결선과 정상적인 3자 상호배타 연결은 유지된다. 모든 선의 무교차나 모든 상태의 전체 326개 UI 검증 완료를 주장하지 않는다. 만주 바로가기의 하단 걸림은 남아 수동 스크롤로 전체를 확인했다. 실행 구성과 관측 범위는 [현재 압축 기록](incidents/2026-09-21-korean-focus-compact.md)에 기록한다.

콘텐츠 확장 기능의 PASS 104와 86c5 실행은 [1차 확장 기록](incidents/2026-09-21-korean-focus-expansion.md)의 이전 이력이다. 첫 재배치의 AA58/d00f 결과도 현재 압축 검증으로 세지 않는다. 이번 문서 갱신에서 게임 실행·production 수정·커밋·푸시·배포는 수행하지 않았다.
