# 공산주의 후속 개발 — 농촌 기술보급과 계획행정

작성: 2026-09-22. 시작 기준: `b300b409`, 한국 중점 345개. 이번 범위는 남은 공산 후보 Y3의 5개와 P3의 4개다. 아래 수치는 [중점 보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)에 따라 이번 구현에서 채택한 **설계 최종값**이며, 사용자가 각 숫자를 직접 지정한 것으로 기록하지 않는다. 이전 미적용 후보의 PP50·안정도 2%p·연구 50%를 그대로 적용하는 안이 아니다.

## 범위와 연결

이번 9개를 적용하면 한국 중점은 **345 + 9 = 354개**, 2차 확장 적용분은 **19 + 9 = 28개**가 된다. 여운형과 박헌영은 각각 14개씩이며, 공산 경로의 초기 28개 후보를 모두 구체화하는 묶음이다. 다른 정치 경로·만주·공통 분야의 후보 106개는 미적용 설계로 남는다. 전체 450~470개 목표까지의 차이는 96~116개다. 이 수량 관계는 적용 범위를 뜻하며 전체 확장이나 정상 플레이 검증의 완료 선언은 아니다.

- 여운형은 현재 `HOK_KOR_yeo_cooperative_federation`의 해석 좌표 `(75,13)`에서 이어진다. 최초 구현의 부모 `HOK_KOR_yeo_social_compact`와 후보의 초기 부모 `KOR_pain_sharing`을 사용하지 않는다.
- 박헌영은 현재 `HOK_KOR_pak_heavy_industry_dispatch`의 해석 좌표 `(98,13)`에서 이어진다. 최초 구현의 부모 `HOK_KOR_pak_integrated_output_plan`과 후보의 초기 부모 `KOR_park_heon_young_as_the_leader`를 사용하지 않는다.
- 최초 9개 추가 때 기존 345개 정의·좌표를 보존했다. 이후 사용자가 승인한 병렬 개편은 위 두 시작 중점의 선행조건과 네 묶음의 시작 배치를 변경한다. 앞선 [경제정책 10개](HOK_KOREAN_SECOND_WAVE_FIRST_10_SPEC.md)는 그대로 유지하며, [후속 내정 9개](HOK_KOREAN_COMMUNIST_GOVERNANCE_SPEC.md)는 위치만 바꾼다. 모든 중점의 ID·보상·기간·AI·기존 상호배타 선택과 각 묶음 내부 선행 순서는 보존한다. 기존 정책의 어느 상호배타 대안을 선택했어도 같은 지도자의 후속 개발을 진행할 수 있다.
- 후속 내정과 후속 개발은 같은 경제정책 말단에서 갈라지는 병렬 가지이며, 서로 상호배타가 아니다. 어느 묶음을 먼저 진행할지 고를 수 있고 두 묶음을 모두 완료할 수 있다.
- 모든 새 중점은 기본 35일(`cost = 5`)이다. 공산정부, 내전 없음, 해당 지도자 선택 중점 완료를 요구하며 항복 중 시작할 수 없다. 조건 상실 시 취소하고 계속 진행하지 않는다. 지도자 조건은 여운형 `KOR_yeo_woon_hyung_as_the_leader`, 박헌영 `KOR_park_heon_young_as_the_leader`의 완료 여부이며 현재 인물 이름만으로 판단하지 않는다.

각 묶음의 첫 중점은 위 경제정책 말단을 `relative_position_id`와 선행으로 사용하고 상대값 `(2,1)`을 준다. 나머지는 직전 부모 기준 `(0,1)`이다. 부모를 먼저 선언하며 배치 기준과 진행 조건은 각각 기록한다. 현재 Y3는 x77·y14~18, P3는 x100·y14~17이며, 나란히 놓이는 Y1은 x73·y14~17, P1은 x96·y14~18이다. 경제정책 뒤에 한 줄로 이어졌던 9개를 최대 5행의 두 묶음으로 나누어 공산 추가분의 범위를 y10~22에서 y10~18로 줄인다. 전체 범위 x0~204·y0~24와 기존 326개·첫 경제정책 10개의 위치는 유지한다. 중점을 숨겨 공간을 만들지 않는다. 실제 이름판·연결선·SHOW/HIDE 검수는 정적 중심점 비교와 구분한다.

## 국민정신과 기존 효과 보존

이번 국민정신은 새 계열 4개다. 표의 II는 I에 더하는 수치가 아니라 **교체 후 최종값**이다.

| 정신 ID (`HOK_KOR_` 접두사) | I | II |
|---|---|---|
| `yeo_technical_extension_1/2` | `research_speed_factor = 0.05`, `production_speed_infrastructure_factor = 0.15` | 연구 속도 0.10, 기반시설 건설 속도 0.25 |
| `pak_planning_administration_1/2` | `line_change_production_efficiency_factor = 0.15` | 효율 유지 보정 0.25, `production_factory_start_efficiency_factor = 0.10` |

같은 계열의 I은 II로 교체하며 둘을 중첩하지 않는다. 하위 정신이 없는 상태에서 해당 말단 중점을 완료하면 상위 정신을 직접 지급한다. 공산정부 상실 시 새 정신을 제거하며, 정권 복귀만으로 자동 재지급하지 않는다. 기존 공동구매·자율금융·설비확충·현행생산과 노농 협약·국가 생산계획 정신은 이번 단계 교체에서 제거하지 않는다.

여운형은 이미 있는 연구기관과 조합 작업장 사이의 기술 전달 및 기반시설 시공을 보강한다. 새 학교나 연구소를 다시 설립하거나 연구 슬롯을 추가하는 보상으로 해석하지 않는다. 박헌영은 기존 계획기관의 중앙·지방 연락과 설비 전환 절차를 보강한다. 기존 P1의 효율 성장·상한이나 P2의 건설·공장 생산량 보상을 다른 수치로 덮어쓰지 않는다.

생산 효율 성장, 효율 상한, 전환 시 유지 보정, 기본 생산 효율은 서로 다른 수정치다. 이번 P3의 효과를 군수공장 생산량 증가나 기존 P1의 성장 보너스로 설명하지 않는다. 실제 장비 간 전환에서 남는 효율은 해당 전환과 다른 기술·수정치의 영향을 받으므로 유지 보정값만으로 최종 효율을 단정하지 않는다.

## 기간제 사업과 기존 범주 공유

별도 사업 범주나 동시 실행 슬롯을 추가하지 않는다. 신규 4개는 기존 `HOK_KOR_communist_governance_programs`에 합류한다. 기존 후속 내정 4개와 이번 4개, **총 8개가 같은 `HOK_KOR_communist_governance_active` 및 `HOK_KOR_communist_governance_cooldown`을 공유**한다. 실제로 보이는 선택지는 완료한 지도자 경로와 해금 중점에 따라 달라진다. 병렬 개편 후 원래 한국인 국가에서 지방협의회 정례화·생산능력 정기점검·공동업무 회계 공개·현장 기술대표단 중 하나만 완료해도 범주를 표시한다. 후속 개발을 먼저 진행해도 그 사업이 숨지 않도록 공개 조건의 OR 목록을 네 개로 늘리며, 각 사업의 개별 해금·지도자·정부 조건은 바꾸지 않는다.

| 결정 ID (`HOK_KOR_` 접두사) / 이름 | 해금 중점 | 90일 동안만 적용하는 효과 |
|---|---|---|
| `yeo_mobile_technical_training_project` / 순회 기술교육 | 공동업무 회계 공개 | 연구 속도 +10% (`research_speed_factor = 0.10`) |
| `yeo_rural_infrastructure_project` / 농촌 기반시설 지원 | 공동업무 회계 공개 | 기반시설 건설 속도 +30% (`production_speed_infrastructure_factor = 0.30`) |

- 각 새 사업은 정치력 **150만** 지불하고 민간공장을 점유하지 않는다. 사람과 AI의 민공 수량 요건도 두지 않는다. 효과는 진행 중인 90일에만 적용하며 종료 보상으로 연구 혜택·공장·정치력을 반복 지급하지 않는다.
- 후속 내정 범주 전체에서 최대 하나만 진행한다. 어느 사업이든 종료·취소되면 진행 플래그를 해제하고, 기존 사업을 포함한 같은 범주의 모든 선택에 공통 90일 재착수 대기를 적용한다.
- 원래 한국, 해당 기존 지도자 선택 완료, 해당 해금 중점 완료, 공산정부, 비내전·비항복 상태를 요구한다. 정부·원국가·경로 조건 상실, 내전 또는 항복 시 취소하고 효과를 회수한다. 취소 시 정치력은 환급하지 않는다.
- 기존 후속 내정 4개의 보상·비용·기간·개별 해금 조건을 바꾸지 않는다. 이번 변화는 같은 운영 한도 안에서 선택할 사업이 늘어나는 것이다. 90일 대기를 우회하는 새 플래그나 별도 슬롯은 만들지 않는다.
- 기존 경제정책 범주 `HOK_KOR_communist_policy_projects`와 그 별도 진행·대기 플래그는 유지한다. 앞선 설계대로 경제정책 하나와 후속 내정 하나를 동시에 운영할 수 있으며, 이번 추가로 세 번째 동시 사업을 허용하지 않는다.

국민정신 보유 여부를 사업 해금 조건에 추가하지 않는다. 기존과 같이 지도자·중점 완료와 현재 정부 조건을 확인한다. 공산정부 복귀 후 사업을 다시 시작할 수 있는지와 제거된 영구 정신의 자동 복구 여부는 별개다.

## 누적량과 운영 선택

아래는 지정한 효과만 더한 **부분 합**이며 국가 전체의 최종 효과나 실제 생산 결과가 아니다. 국민정신 I·II나 동시에 실행할 수 없는 두 사업은 합산하지 않는다.

- 여운형 기술보급 II의 연구 속도 +10%와 공통 야간학교 정신 +10%, 순회 기술교육 +10%가 적용되면 연구 속도 수정치의 부분 합은 +30%다. 순회 교육을 실행하는 동안 같은 후속 내정 범주의 지역민생·노사협약·기반시설 지원 사업은 실행할 수 없다.
- 기술보급 II의 기반시설 건설 +25%와 농촌 기반시설 지원 +30%의 부분 합은 +55%p다. 자율금융 선택으로 해금되는 기존 **지역 금융 순환 사업**(`HOK_KOR_yeo_rural_credit_project`)의 전체 건설 속도 +10%가 별도로 적용되면 세 효과의 기반시설 건설 기여분은 +65%p다. 이 기존 사업의 정치력 75·민간공장 2개 비용은 유지한다. 공동구매 사업은 민간공장 건설 전용 +15%이므로 같은 기반시설 예시에 더하지 않는다. 새 기반시설 사업과 기존 후속 내정의 지역민생 사업도 동시에 더하지 않는다.
- 박헌영 계획행정 II의 효율 유지 보정 +25%, 공통 유연생산 II의 +40%, 생산공정 전환 관리의 +20%를 선택했다면 같은 수정치의 부분 합은 +85%p다. 공통 대량생산을 선택했다면 유연생산 +40%는 없고 기존 전환 불이익 -5%를 그대로 보존한다.
- 계획행정 II의 기본 생산 효율 +10%p, 공통 품질관리 +10%p, 신규 생산선 가동 지원 +15%p의 부분 합은 +35%p다. 가동 지원은 전환 관리와 동시에 실행하지 않는다. 이 숫자로 모든 생산선의 실제 초기 효율을 단정하지 않는다.

새 박헌영 사업은 기존 국가 생산계획의 물자 배정 재조정·생산계획 전환 지원과 운영 한도를 공유한다. 자원 부족 완화, 효율 성장, 전환 유지, 초기 가동 중에서 상황에 맞는 사업 하나를 고르는 구조다. 비슷한 이름이라도 기존 전환 지원의 효율 성장 +25%와 새 전환 관리의 효율 유지 +20%를 혼동하지 않도록 설명한다.

## 검증 상태와 확인 범위

**현재 병렬 배치와 새 선행 경로의 런타임 검증은 아직 진행 전이다.** 최초 개발 9개 추가 때는 기존 345개 중점·좌표와 기존 사업 정의를 보존했고, 새 9개·4정신·4사업·34개 대응 현지화 키와 이미지 17개를 통합해 참조·괄호·인코딩·해시 검사를 통과했다. 이 보존·검사 기록은 병렬 개편 전의 상태다. 상세 결과와 런타임의 실제 실행 범위는 [이번 작업 기록](incidents/2026-09-22-korean-communist-development.md)을 따른다. 앞선 후속 내정 199 PASS 및 첫 10개 149 PASS를 새 병렬 경로의 검증 결과로 사용하지 않는다.

병렬 개편에서는 기존 326개와 첫 경제정책 10개의 보존, 나머지 18개의 보상·기간·AI·선택 보존, 의도한 시작 선행조건 두 개와 배치 변경을 분리해 확인한다. 354개 ID·선행·상대좌표, 국민정신 단계 교체와 기존 정신 유지, 연구 보너스의 범주·크기·횟수, 사업의 실제 비용·조건·90일 효과·취소·공유 대기도 확인 대상이다. 후속 개발을 먼저 진행할 때 공유 범주와 해당 사업이 표시되는지, 두 병렬 묶음을 모두 완료할 수 있는지, 신규 사업을 실행할 때 기존 후속 내정 사업도 막히는지와 별도 경제정책 사업은 의도대로 함께 운영할 수 있는지를 확인해야 한다.

강제 중점 완료·스크립트 사업 활성화는 정상 35일 진행, UI 정치력 차감, 실제 전환 효율 보존이나 신규 생산선 시작 효율, 연구 혜택 소모, 자연 90일 종료·대기 만료·재착수를 대신하지 않는다. 정권 변경 때의 합계 수정치는 다른 정치·국민정신 변화와 분리하여 해석한다. 장기 AI, 저장 호환, 다른 DLC·언어 구성, 멀티플레이와 실제 SHOW/HIDE 화면 검증도 실행 여부를 별도로 기록한다.

병렬화 후 소스·좌표·선행·보상 보존과 가지별 도달성의 정적 검사 결과는 [병렬 배치 기록](incidents/2026-09-22-korean-communist-parallel.md)을 따른다. 게임 실행 결과와는 구분한다.
