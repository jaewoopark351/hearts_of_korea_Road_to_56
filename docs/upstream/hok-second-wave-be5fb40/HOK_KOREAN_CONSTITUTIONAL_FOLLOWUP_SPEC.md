# 입헌군주 후속 정책 C1–C4 명세

작성: 2026-09-23. 시작 기준은 `feat/korean-focus-expansion-ai`의 `3f3b706`, 한국 중점 378개다. 남은 확장을 순서대로 구현하라는 요청에 따른 의도적인 후속 콘텐츠 개발이며 호환성 복구와 구분한다. 이 명세의 적용 범위는 입헌군주 14개와 국민정신 7개다. 기존 378개 중점의 ID·보상·조건·배치 및 기존 왕정 외교 효과는 보존한다. 전체 확장의 수량과 검증 결과는 [2차 계획](HOK_KOREAN_SECOND_WAVE_PLAN.md)과 최종 작업 기록을 따른다.

## 진입·병렬 구조

모든 신규 중점은 `cost = 5`(명목 35일), `has_government = democratic`, `has_civil_war = no`, `has_completed_focus = KOR_nomination_prime_minister`를 요구한다. 기존 총리 지명 중점은 실제 집권 이념을 민주주의로 바꾸므로 비동맹 정부 조건을 적용하지 않는다. 왕정 가지에 속한다는 정치 경로 조건과 현재 정부 상태는 별개다.

`cancel_if_invalid = yes`, `continue_if_invalid = no`, `available_if_capitulated = no`로 진입 조건 상실 시 진행을 취소한다. 신규 `ai_will_do`는 `factor = 2`이며 기존 중점의 AI 또는 김구 역사 AI 목록을 바꾸지 않는다. 실제 선택 순서는 런타임 검증 대상이다.

각 시간은 기존 정치 선행, 조건 대기, 저장된 중점 진행도를 제외한 명목값이다. 신규 14개를 모두 완료하는 명목 시간은 490일이다. C1~C4는 다른 신규 묶음의 완료를 요구하지 않는다. 두 병렬 자식은 모두 완료할 수 있고 실제 정책 충돌이 없으므로 상호배타를 만들지 않는다. AND 합류는 두 개의 별도 `prerequisite` 블록으로 표현한다. C3의 진료지원은 자기 부모가 부여한 정신을 강화하며 공익시설 개선기금 완료는 요구하지 않는다.

C4는 기존 연합국 가입·합동훈련 경로와 실제 세력 가입을 요구한다. 기존 영국 초청 이벤트, 전쟁·외교 규칙, 세력 가입 효과를 새로 실행하지 않는다. 세력 이름·특정 지도국을 추가로 고정하지 않아 기존 정치 경로 완료 후 실제 가입 상태를 기준으로 한다.

## 국민정신·수명·누적 효과

공통 정의는 `allowed = { original_tag = KOR }`, `allowed_civil_war = { always = yes }`, `removal_cost = -1`다. C1~C3의 6개 정신은 민주정부를 잃으면 제거한다. C4 연락체계는 민주정부 또는 세력 가입 상태를 잃으면 제거한다. 기간제가 아니며 정부·세력에 복귀하는 것만으로 자동 복구하지 않는다. 다른 기존 정신을 제거하거나 교체하지 않는다.

I→II는 하위 정신이 있으면 `swap_ideas`, 이미 제거됐으면 상위 정신만 `add_ideas`로 부여한다. 하위·상위를 누적하지 않고 이전 효과를 전부 유지 또는 강화한다. 중점 취소와 이미 얻은 보상의 수명을 구분한다. 내전 발생은 신규 중점 진행을 취소하지만 기존 공익·사법 제도를 자동 제거하는 사유가 아니며 민주정부 여부가 해당 정신의 수명을 결정한다. 지급된 정치력·경험치·안정도와 미사용 연구 혜택은 조건 상실 시 회수하지 않는다.

`political_power_gain`은 고정 일일 정치력이다. `political_advisor_cost_factor`는 정치 고문 고용 비용의 비율이며 모든 법률·설계사·MIO 비용을 낮추는 효과가 아니다. `stability_factor`는 정신이 있는 동안 안정도에 더해지는 퍼센트포인트이며 매주 증가량이 아니다. `consumer_goods_factor`는 소비재에 배정할 공장 수에 대한 계수 보정이며 경제법의 소비재 비율을 5%p 또는 10%p 직접 낮추는 효과가 아니다. `army_org_factor`는 사단 조직력, `planning_speed`는 계획 보너스가 쌓이는 속도이며 최대 계획 보너스가 아니다.

14개를 모두 완료했을 때 이번 묶음의 일회 보상은 정치력 600, 안정도 5%p, 육군 경험치 75·해군 25·공군 25, 산업 150% 혜택 2회와 전자공학 100% 혜택 2회다. 각 연구 혜택은 해당 중점에서 1회씩 별도 부여되며 한 연구에 300%·200%를 일괄 부여한다는 뜻이 아니다. 최종 상시 정신은 책임내각 II·권리구제 II·공익후원 II·연락체계로, 안정도 합계 +25%p, 소비재 공장 계수 합계 −15%, 일일 정치력 +1.2, 정치 고문 비용 −15%, 사단 조직력 +5%, 계획 수립 속도 +15%다. 기존 입헌 보상에 더해지며 안정도 상한·다른 경제 보정에 따라 실제 추가 이득은 달라진다. 이 검토를 이유로 기존 혜택을 삭감하지 않는다.

## 좌표·이미지

14개 모두 기존 왕정 기준점의 상대좌표 체인을 사용한다. 민주정부로 바뀌어도 실제 왕정 경로의 HIDE 이동 −101x를 한 번 상속하며 별도 offset을 추가하지 않는다. C1은 (204,10)에서 3행, C2는 (210,8)에서 3행, C3는 (206,8)에서 2행, C4는 (202,14)에서 2행이다. C2·C3는 총리 지명에서 표시선을 연결하고 실제 사법부 독립·현대의 세종대왕 완료를 각각 가용 조건으로 유지해 진입 시점이 빨라지지 않게 한다. 전체 왕정 후속 모듈 및 공통 가지와 함께 배치하며, 확정 좌표와 SHOW/HIDE 사각형·연결선 검사는 [현재 좌표 JSON](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)에 통합한다. 정적 모델은 게임 화면 검증과 구별한다.

이미지는 중점 14개·정신 7개다. 모두 입헌 민주정의 짙은 청색(`democracy`) 계열을 사용하고 정권 변화에 따라 이미지를 바꾸지 않는다. 책임내각은 봉인 문서·깃펜, 사법은 저울·법전, 민생은 왕관·열린 손·의료가방, 동맹 연락은 관측안경·교범·견장을 중심 소재로 한다. 정신은 연결 중점과 같은 소재·색을 공유하며 실제 강화 정신 6개에만 I·II를 쓴다. 연락체계에는 가상의 단계 표시를 붙이지 않는다.

중점 sprite는 `GFX_HOK_KOR_focus_cm_*`, 정신 `picture`는 `HOK_KOR_icon_cm_*`다. 완성 DDS·GFX·광택 마스크와 오버레이는 프로젝트 내부 실제 파일 및 상대경로로 연결한다. 자산 출처·합성·해시는 전체 잔여 확장의 이미지 기록을 따른다. 새 결정이 없어 결정용 아이콘은 추가하지 않는다.

14개와 국민정신 7개·이미지를 총 460개 소스에 통합했다. 기존 378개 또는 파시즘의 검증 횟수를 재사용하지 않고 잔여 82개 전체 정적 896/0·좌표 335/0, 최종 세 보상 시나리오 1,213/0에서 함께 검사했다. 진단 없는 최종 로드 `clean-03`은 신규 고유 오류 0개다. 통합 횟수를 입헌 14개만의 독립 검사 수로 표현하지 않는다.

실제 UI에서는 C1 첫 중점만 35일 진행·완료했고, C4 정신은 합성 세력 가입 뒤 실제 날짜를 진행하여 세력 이탈 시 제거됨을 확인했다.
