# 구국군 후속 정책 — 참모업무 체계

작성: 2026-09-22. 시작 기준은 `691ffa37740237feddf0b44fc68cfa47b10d76bf`와 미커밋 파시즘 F1 군수계약 구현을 포함한 한국 중점 358개다. [보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)과 [독립 정책 묶음 원칙](HOK_KOREAN_FOCUS_LAYOUT_PLAN.md#46-후속-정치-확장의-긴-직렬-가지-방지)에 따른 신규 개발이다. 아래 수치는 이번 구현에서 채택한 설계 최종값이며, 사용자가 개별 수치를 직접 지정한 것으로 기록하지 않는다.

## 범위와 기존 내용 보존

파시즘 후보 F2의 중점 4개와 국민정신 2개를 적용했다. 적용 후 전체는 **362개**, 2차 확장 적용분은 **36개**, 남은 후보는 **98개**다. 파시즘 후보 24개 중 F1·F2의 8개가 적용되고 16개가 남는다. 2차 국민정신은 20개, 기간제 사업은 기존 14개다. 최종 450~470개 목표까지는 88~108개가 더 필요하며, 미적용 후보 수량·보상은 확정 목록이 아니다.

실제 진입점은 선군주의(`KOR_prussia_in_the_far_east`)다. 기존 참모 기구의 보직 분담·작전 기획·야전 보고·승인 절차를 보강한다. 기존 계룡대와 공통 참모 훈련, 독일 협력을 통한 한국의 장군참모 제도를 다시 창설하거나 교체하는 내용이 아니다. 작전기획국의 설명 역시 기존 기구 안에서 담당 업무를 정비하는 것으로 한정하며, 실제 역사상 기관의 존재나 설립 시기를 주장하지 않는다.

F1 군수계약을 완료하지 않아도 F2를 진행할 수 있고 반대 순서도 가능하다. F1의 중점·국민정신·결정·진행 및 대기 플래그는 바꾸지 않는다. 이번 F2에는 별도 사업이나 결정 범주를 추가하지 않는다. 공통 군사·기존 정치·외교 경로의 조건과 보상, 기존 358개 중점의 위치·기간·연결은 보존한다.

## 중점과 배치

표의 새 ID에는 `HOK_KOR_` 접두사가 붙는다. 모든 새 중점은 35일(`cost = 5`)이며, 파시즘 정부·내전 없음·`KOR_establishment_of_the_national_salvation_army` 완료를 요구한다. 항복 중 시작할 수 없고 조건 상실 시 취소하며 계속 진행하지 않는다. 기존 정치 경로의 상호배타 조건은 유지한다.

| ID / 이름 | 실제 선행 | 해석 좌표 | 최종 보상 |
|---|---|---|---|
| `nrsc_staff_registry` / 참모보직 정비 | `KOR_prussia_in_the_far_east` | (172,6) | 육군 경험치 50 |
| `nrsc_operations_directorate` / 작전기획국 | 참모보직 정비 | (171,7) | 참모업무 체계 I: 계획 수립 속도 +15%, 최대 계획 보정 +10% |
| `nrsc_field_report_system` / 야전보고 체계 | 참모보직 정비 | (173,7) | 전자공학 연구 혜택 100% × 1회, 육군 경험치 25 |
| `nrsc_staff_regulations` / 참모업무 규정 | 작전기획국 **AND** 야전보고 체계 | (172,8) | 참모업무 체계 I→II: 계획 수립 속도 +20%, 최대 계획 보정 +15% |

참모보직 정비는 기존 부모 `(169,5)` 기준 `(3,1)`이다. 작전기획국·야전보고 체계는 참모보직 정비 기준 `(-1,1)`·`(1,1)`, 참모업무 규정은 같은 기준 `(0,2)`다. 상대 기준은 반드시 먼저 선언한다. 최종 중점의 배치 기준과 두 개의 필수 선행조건을 구분하고, AND 연결을 별도 `prerequisite` 블록 두 개로 작성한다.

가운데 두 중점은 상호배타가 아니며 어느 순서로도 모두 완료할 수 있다. 새 묶음은 x171~173·y6~8, 중심점 기준 가로 2칸·세로 2칸의 3행이다. 전체 x0~204·y0~24 범위는 늘리지 않는다. 인접한 기존 구국군·친독/친일 외교·황실 가지, 이름판과 연결선의 실제 여백은 화면 검증 대상으로 남긴다. 중점 격자는 화면 픽셀이 아니며 중심점이 다르다는 사실만으로 아이콘·명판 비겹침을 증명하지 않는다.

참모보직 정비부터 가장 긴 선행 사슬은 3개다. 첫 육군 경험치 50은 35일, 국민정신 I 또는 전자공학 연구 혜택은 해당 갈래를 먼저 진행하면 70일, 두 가운데 중점을 모두 완료하는 데 105일, 국민정신 II까지 전체 4개는 **140일**이다. 전체 육군 경험치 보상은 75다. 기존 부모까지의 시간·중단·조건 대기는 제외하며, 병렬 배치가 두 중점의 동시 진행을 뜻하지 않는다.

## 국민정신과 연구 보너스

정신 ID는 `HOK_KOR_nrsc_staff_administration_1/2`, 표시 이름은 참모업무 체계 I/II다. I의 `planning_speed = 0.15`, `max_planning_factor = 0.10`을 II에서 각각 `0.20`, `0.15`로 교체한다. II는 두 수정치를 각각 5%p 높인 최종값이며 I와 II를 합산하지 않는다. 하위 정신을 보유하면 같은 계열만 교체하고, 이미 제거됐다면 II를 직접 지급한다. 파시즘 정부를 상실하면 제거하며 정권 복귀만으로 자동 복구하지 않는다. 다른 기존 참모 국민정신은 제거하거나 교체하지 않는다.

최대 계획에는 **`max_planning_factor`**를 사용한다. 별도 키인 `max_planning`과 구분하고, 최종 계획 보너스에 고정 15%p를 더한다고 설명하지 않는다. 계획 수립 속도와 최대 계획 보정은 서로 다른 효과이며 공격력·조직력 증가로 바꿔 서술하지 않는다.

연구 보너스는 고유 이름 `HOK_KOR_nrsc_field_report_system`, `bonus = 1.0`, `uses = 1`, `category = electronics`다. 영구 연구 속도나 앞서가기 불이익 감소를 지급하지 않는다. 야전 보고·통신 장비 연구의 성격이지만 실제 적용 범주는 전자공학 전체임을 설명한다. 기존 무선 지휘망 표준화의 무전 기술 한정 보너스를 삭제·변경하지 않는다.

## 기존 보상과 누적값

기존 공통 참모 정신은 I의 계획 수립 속도 +10%에서 II의 +20%·조직적 협동 +6%로 강화된다(`common/ideas/HOK_KOR_military_expansion.txt:30–53`). 계룡대는 계획 수립 속도 +10%와 최대 지휘력 30을 준다(`common/ideas/korea.txt:477–490`). 한국의 장군참모 중점은 독일·파시즘·비종속·추축 가입 경로 조건 아래 `general_staff`를 지급한다(`common/national_focus/korea.txt:8023–8052`). 설치본의 해당 정신은 계획 수립 속도 +25%·육군 조직력 +5%다(`common/ideas/GER.txt:24–39`).

| 실제 함께 보유한 정신 | 계획 수립 속도 부분 합 | 별도 보존 효과 |
|---|---:|---|
| 새 참모업무 체계 II만 | +20% | 최대 계획 보정 +15% |
| 새 II + 공통 참모 II | +40% | 최대 계획 보정 +15%, 공통 정신의 조직적 협동 +6% |
| 위 두 정신 + 계룡대 | +50% | 위 효과와 계룡대 최대 지휘력 30 |
| 위 세 정신 + 기존 `general_staff` | +75% | 위 효과와 기존 육군 조직력 +5% |

위 표는 명시된 정신을 실제 함께 보유할 때의 같은 수정치 부분 합이다. F2 진행만으로 계룡대·공통 참모 II·독일 장군참모를 자동 지급하지 않으며, 독일 협력 경로를 모든 플레이에서 선택한다고 가정하지 않는다. 기술·교리·장군·다른 국가 보정을 포함한 최종 전투값이나 준비 완료 시간은 실제 게임에서 따로 확인한다.

## 문법 근거와 AI

설치본 HOI4 1.19.3.0.c01a / Steam build 25205862의 동일 문맥을 확인했다.

- `common/ideas/czechoslovakia.txt:2483–2485,2509–2510,2532–2533`: 국가 국민정신 `modifier` 안에서 `planning_speed`와 `max_planning_factor`를 함께 사용한다. 별도 `CZE_planning_bonus`의 `max_planning = 0.15`(`:4444`)는 이번에 선택한 factor 키와 다르다.
- `common/national_focus/japan.txt:16782–16784`: 중점 `completion_reward`에서 `army_experience = 50`을 지급한다.
- `common/national_focus/japan.txt:25661–25665`: 중점 완료 보상의 `add_tech_bonus`에 `uses = 1`, `category = electronics`가 있다. `common/national_focus/sweden.txt:10304–10308`에는 `bonus = 1`의 전자공학 보너스가 있으며 해당 가지는 La Resistance 대체 보상 문맥이다.
- 설치본 `documentation/modifiers_documentation.html:3404–3413,4490–4494`는 계획 관련 키를 서로 구분해 등록한다. `localisation/english/modifiers_l_english.yml:754–760`도 계획 수립 속도·최대 계획·최대 계획 보정의 별도 이름을 제공한다.

이번 보상은 국가 국민정신·육군 경험치·기술 범주 보너스만 사용하며 정보기관·MIO·특정 DLC 장비나 교리 항목을 호출하지 않는다. 별도 DLC 게이트를 도입하지 않는다. 이는 다른 DLC 구성의 실제 검증을 완료했다는 뜻이 아니다. 기존 F1과 공산 정책의 같은 계열 정신 교체·정부 상실 취소 구조를 대조하되, 기존 파일은 변경하지 않는다.

새 중점의 기본 AI 가중치는 2다. 두 가운데 정책의 순서를 강제하지 않고 기존 민주 역사 AI 목록에 삽입하지 않는다. 공통 참모 훈련·군수계약·기존 정치·외교와의 선택 경쟁, 육군 경험치 사용과 실제 보상 도달 시점은 장기 AI 검증 대상이다.

## 이미지와 검증 상태

중점 4개와 국민정신 2개는 해당 파시즘 가지의 차콜·갈색 바탕을 사용한다. 보직 명부와 교차 지휘봉·작전 지도와 제도 도구·야전무전기와 지도·업무 교범의 소재를 구분하고 실제 국민정신 단계에만 I·II를 표시한다. 허용된 공개 소재를 재합성하고 지휘봉·무전기 도형을 직접 그렸다. 이미지·마스크·광택과 GFX는 프로젝트 내부의 실제 파일과 상대경로로 연결했다. 배경색은 현재 집권 이념이 아니라 F2가 속한 정치 가지에 고정한다. 별도 결정이 없으므로 이번 묶음의 결정 아이콘은 추가하지 않는다. [출처·가공 기록](HOK_KOREAN_FASCIST_STAFF_ICON_CREDITS.md), [매니페스트](data/HOK_KOREAN_FASCIST_STAFF_ICON_MANIFEST.json), [실제 크기 미리보기](assets/korean-fascist-staff-icons/contact-sheet.png)에 이미지 근거를 남겼다.

구현 후 정적 검사는 **84 PASS / 0 FAIL**이다. 기존 358개 중점 원문과 기존 미커밋 runtime 파일 중 중점 파일을 제외한 16개를 보존했고, 현재 362개는 절대 기준 7개·상대 배치 355개다. 현재 중점 파일 SHA-256은 `8a721a8739834bac5a0ed30f3d3335ced9ceaf4bc63439b1db8bfe2c14299aa8`이다. 설치본 1.19.3에서 별도 새 게임 3회로 강제 완료 보상을 확인하여 **125 PASS / 0 FAIL**을 기록했다. 두 정책 순서와 하위 정신 부재 시 II 직접 지급, 육군 경험치 75, 전자공학 보너스 범주 존재, I·II 수정치 및 기존 정신 보존을 확인했다. 연구 혜택의 100%·1회는 소스 검사이며 실제 소모는 확인하지 않았다. 진단 없는 최종 소스도 새 게임 로드를 확인했다(ee60). 화면 제어 도구의 native pipe 연결 오류로 실제 화면은 확인하지 못했다. 확정된 결과와 미검증 범위는 [작업 기록](incidents/2026-09-22-korean-fascist-staff.md)에 따로 남긴다. 기존 F1의 68 PASS 및 공산 검증 횟수를 F2의 결과로 합산하지 않는다. 두 정책 순서, 최종 AND 차단, I→II 및 하위 부재 시 II 지급, 기존 정신 보존, 파시즘 상실 시 제거, F1과의 독립 접근을 구분해 확인한다.

강제 완료를 통한 보상 관측과 정상 35일 진행·연구 혜택 소모·실제 전투 계획 효과·장기 AI·기존 저장·다른 DLC·멀티플레이 검증은 별도다. 초기 및 정치 선택 후 SHOW/HIDE의 이름판·연결선·아이콘 상태와 주변 가지도 실제 화면으로 확인해야 한다. 소스·좌표 검사만으로 화면 검증 완료를 주장하지 않는다.
