## 진입·취소·유지 조건

전제군주 A1~A4의 공통 착수 조건은 원래 한국, 비동맹 정부, 내전 없음, `KOR_reconstruction_confusian_order` 완료다. 아래 부모 완료도 요구한다. 비변사·군제개혁·황제 특성과 기존 보상은 그대로 둔다. 비동맹 정부를 잃거나 내전이 발생하면 진행 중인 신규 중점은 취소한다.

환제국 H1~H4의 공통 착수 조건은 원래 한국, 내전 없음, 독립국, 기존 `KOR_empire_of_hwan` 완료, 기존 만주 운영 대상 8개 주 중 적어도 하나의 **소유와 완전 통제**다. 대상은 716·745·328·717·714·761·715·610이며 기존 다민족 포용 등의 대상 범위를 재사용한다. 해당 주가 핵심인지 여부는 요구하지 않아 기존 통합·핵심화와 충돌하지 않는다. 모든 적격 거점을 잃으면 신규 운영 중점을 시작할 수 없고 진행 중인 중점은 취소된다.

H3·H4에는 `KOR_hwan_world_order` 완료, 평시, 경기(525)의 소유와 완전 통제를 더 요구한다. 재전쟁이나 경기 상실은 두 후속 묶음의 진행을 취소한다. 세계질서 완료만으로 실제 영토 운영이 증명되는 것은 아니므로 거점 조건을 별도로 둔다. 세계 전체 점령이나 대환국 결정 완료를 요구하는 설계는 아니다.

**환제국에는 비동맹 정부를 일괄 요구하지 않는다.** 기존 형성 중점은 비동맹 이외 정부에 대한 외형 분기도 이미 가지고 있다. 이번 운영은 기존 형성에 연결하되 후보의 일률적인 `neutrality` 제한을 제거한다. 다른 이념에서 얻은 기존 형성 경로를 막거나 왕정 복귀를 강제하지 않는다. 기존 세력 이탈·가입/창설 금지·전쟁 정당화·괴뢰국 규칙·주장·승전 플래그는 변경하지 않는다.

모든 새 중점은 `cancel_if_invalid = yes`, `continue_if_invalid = no`, `available_if_capitulated = no`다. 배치 기준과 진행 부모는 구분한다. 화면 연결 때문에 묶음 시작의 표시 부모를 더 이른 기존 진입점으로 잡더라도 아래 실제 부모 완료 조건은 `available`에 보존해야 한다. 기존 정치 경로가 숨겨졌을 때의 신규 자손 표시와 조건별 압축은 통합 검증 대상이다.

### 획득한 혜택의 수명

- 전제 정신은 비동맹 정부를 잃으면 제거되고 정권 복귀만으로 자동 복구되지 않는다. 상위 중점을 나중에 완료할 때 하위 정신이 없으면 상위 정신을 직접 지급한다.
- 환제국 정신은 실제 형성 완료에 연결된 국가 운영 제도다. 단순한 이념 변경·재전쟁·영토 상실은 이미 획득한 제도를 삭제하지 않는다. 해당 사건은 이후 중점의 착수·진행 조건으로 처리한다. 형성 완료 상태가 없는 국가에는 정신을 유지하지 않는다.
- 하위 I→상위 II는 동일 계열만 `swap_ideas`로 교체한다. 그 외 정신·연구 혜택·인력·경험치·정치력은 제거하지 않는다. 정상 진행에서 하위·상위가 중복되지 않아야 한다.
- 정치력·안정도·인력·경험치의 일회 보상은 이후 조건 상실 때 회수하지 않는다. 연구 혜택은 사용 전까지 남는 1회 보상이며 영구 연구 속도와 구분한다.

AI 기본 가중치는 2로 각 경로 안에서 선택 가능하게 한다. 앞 모듈을 강제로 먼저 완료시키거나 민주 역사 AI 목록에 이 중점을 넣지 않는다. 전제는 자신의 정부 조건을, 환제국은 형성·소유·통제·평시 조건을 만족한 때만 진행한다. 타 중점과의 실제 우선순위 및 주요 보상 도달 시점은 장기 AI 검증 대상이다.
