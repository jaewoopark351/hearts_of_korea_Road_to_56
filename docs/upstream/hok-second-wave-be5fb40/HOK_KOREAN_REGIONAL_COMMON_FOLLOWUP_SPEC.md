# 만주 개발·공통 산업군사 후속 명세

작성: 2026-09-23. 사용자 승인 후속 개발. 기준 커밋 `3f3b706`, 기존 378개 보존. HOI4 설치본 Operation Postern 1.19.3을 문법 근거로 사용한다. 후보 M1~M4 20개와 G1~G5 20개를 정책 묶음별로 재설계한다. 구현과 실제 플레이 검증은 작업 기록에서 구별한다.

## 연결과 기간

각 중점은 35일(`cost = 5`), 기본 AI 가중치 2이며 내전·항복 중 진행하지 않는다. M1~M4와 G1~G2는 진입 → 독립 두 정책 → 두 정책을 모두 요구하는 합류 → 종합 정책의 5개 구조다. 하나의 최단 필수 경로는 4단계이며, 두 정책 모두를 완료하는 데는 175일이 든다. G3는 진입 → 독립 두 정책 → AND 합류의 4개·140일이다. G4·G5는 진입 → 독립 두 후속의 3개·105일이다. 대기·중단과 기존 진입 중점의 기간은 제외한다. 새로운 상호배타 선택은 없다.

M3는 기존 병기창 이후 자원탐사 완료도 요구하며, G2는 함경도 지하자원과 운산금광 개발을 모두 요구한다. 이는 각각 자원 조사와 복수 광산의 회수망을 갖춘 뒤 새 정책을 시작하는 조건으로, 기존 초안 진입보다 기존 35일 중점 하나가 추가된다. G1은 원화 평가 절하에서 선을 연결하되 기존 경공업 수출 지원 완료를 가용 조건으로 보존한다.

기존 다민족 포용과 주민 추방 경로는 상호배타이며, 국내성 신도시는 후자의 후속이다. 따라서 M2와 M4를 한 정상 경로에서 함께 완료할 수 없다. 새로운 배타 조건을 더하지 않고 이 기존 선택을 보존한다. 정상 경로에서 가능한 만주 신규분은 M1·M3와 M2 또는 M4의 15개·525일이다.

## 만주 지역 효과와 수명

만주 제도는 전국 국민정신이 아닌 **지정된 주의 동적 변동치**다. M1·M2·M4는 328, M3는 328·714·717에만 적용한다. 착수·진행·사업에는 `tag = KOR`와 모든 대상 지역의 소유·완전 통제가 필요하다. 원래 한국 태그에서 갈라진 별도 내전 국가에는 고정 KOR 소유 지역의 혜택을 지급하지 않는다. M2는 기존 민주 경로 조건을 유지한다. 전쟁 자체는 M 사업을 금지하지 않는다.

| 제도 | I → II 최종값 | 90일 집중 사업의 추가 효과 |
|---|---|---|
| 공공서비스 | 해당 주 건설 속도 +15 → +20%, 지역 보급 +10 → +20% | 해당 주 철도 건설 +25%, 지역 보급 +25% |
| 공동체 지원 | 지역 인력 +15 → +25%, 해당 주 건설 +10 → +15% | 지역 인력 +25%, 해당 주 건설 +25% |
| 원료 회수 | 해당 주 자원 +15 → +25%, 군수공장 건설 +15 → +20% | 해당 주 자원 +25% |
| 도시 운영 | 지역 건설 슬롯 +10 → +20%, 민간공장 건설 +15 → +20% | 해당 주 건설 +25% |

위 값은 비율 보정이다. 즉시 인력·자원·공장을 생성하는 효과나 공장 생산량 보정과 혼동하지 않는다. I은 각 묶음의 두 번째 중점에서 지급하고 종합 정책에서 제거한 뒤 II로 교체한다. 하위 제도가 이미 제거됐다면 II를 직접 지급한다. 제도는 대상 지역 소유·완전 통제와 한국 비항복 조건을 `enable`에서 확인하고 조건 상실 시 `remove_trigger`를 통해 엔진의 일일 갱신에서 제거된다. M2는 민주정부 상실도 처리한다. 외국이 점령·취득한 지역에 한국 제도의 혜택이 승계되지 않는다.

각 묶음의 일회 보상은 정치력 300, 안정도 +5%p와 연구 1회다. M1·M2는 전자공학 100%, M3는 채굴 150%, M4는 건설 100%다. 이미 받은 연구·정치력·안정도는 영토 상실 시 회수하지 않는다. 정상 경로의 세 묶음 합계는 정치력 900·안정도 +15%p·연구 3회다. 전체 정의의 이론적 합계 정치력 1,200·안정도 +20%p·연구 4회를 정상 경로 획득량으로 표현하지 않는다. 소유 지역이 겹치는 서로 다른 유효 제도의 효과는 합산된다.

종합 정책에서 각자 사업을 해금한다. 범주는 네 종합 정책 중 하나만 완료해도 표시하지만, 개별 사업은 해당 종합 정책을 요구한다. 모든 사업은 정치력 150, 민간공장 점유 0, 지속 90일이다. 네 사업 사이에 하나의 동시 실행 슬롯과 종료·취소 후 공통 90일 대기시간을 공유한다. UI에서 지불한 비용은 취소 시 환급하지 않는다. 기간제 효과만 종료 시 제거하며 영구 제도 II는 유효 조건을 만족하면 유지한다.

내전·항복·태그 변경·필요 지역 중 하나의 소유/통제 상실·필요 정부 조건 상실 시 사업을 취소하고 모든 사업 대상의 기간제 효과를 제거한다. 여러 지역을 대상으로 하는 M3에서도 하나를 잃으면 사업 전체를 종료한다. 나머지 한국 소유 지역의 유효한 영구 제도는 보존한다. 지역을 되찾은 것만으로 영구 제도를 자동 복구하지 않으며, 대기시간이 끝난 뒤 이미 해금한 사업을 시작하면 해당 지역의 II를 복구한다. 국가 전체를 매일 순회하는 새 `on_action`은 추가하지 않는다.

## 이미지와 AI

중점 40개, 공통 국민정신 10개, 지역 변동치 12개, 소형 사업 4개와 범주 1개의 전용 이미지를 프로젝트 내부에 둔다. 산업·지역 운영은 산업색, M2는 민주 경로 청색, 육군·해군·공군은 각 분야색을 고정한다. 단계가 있는 제도만 I·II를 표시한다. 아이콘·마스크·광택은 프로젝트 상대경로로 연결하고 결정 본문은 32×32, 범주는 51×40 별도 자산을 사용한다. 출처·가공·해시는 전체 후속 이미지 매니페스트에 기록한다.

새 AI 중점 가중치는 기존 경로와 경쟁하는 기본값 2다. 사업 가중치는 0.5이며 정치력 150 미만이면 0이다. 가용성 조건에서 동시 슬롯·대기·정부·영토를 함께 제한한다. 기존 민주 역사 중점 순서 목록에 다른 정치 경로를 일괄 삽입하지 않는다. 파싱·정적 도달성은 실제 AI 선택 시점의 증거가 아니다.

## 설치본 근거와 검증 계약

설치본 `common/dynamic_modifiers/0_dynamic_modifiers.txt`는 주/국가 범위·지속일·일일 갱신을 설명한다. `GoE_dynamic_modifiers.txt`의 아프가니스탄 전력화는 ROOT가 효과를 받는 주라는 설명과 소유 기반 제거·지역 건설·자원·슬롯을 제공한다. `aat_dynamic_modifiers.txt`의 ICE·NOR는 지역 건설·인력·군수공장 건설 예시다. 각 프로젝트는 기존 `HOK_KOR_industry_expansion`의 소유/통제와 `HOK_KOR_communist_governance`의 공유 활성·대기 규칙을 참고하되 별도 ID를 사용한다.

공통 국민정신 modifier는 설치본 `congo.txt`(무역), `argentina.txt`(자원), `comchina.txt`(부족), `czechoslovakia.txt`(연료), `army_spirits.txt`(이동), `navy_spirits.txt`(철수·수리), `british_raj_goe.txt`(해군 범위), `air_spirits.txt`(사고), `siam.txt`(기상)의 같은 문맥 예시를 확인했다. 연구 범주는 설치본 기술 파일을 따른다.

검증은 (1) 기존 378개 보존·참조·좌표·BOM·자산, (2) 새 게임 파싱·강제 보상·정신 교체, (3) 실제 정상 35일 진행·UI 비용, (4) 90일 만료·대기·재착수, (5) 실제 소유/통제 상실·정부 변경·복구, (6) 화면 SHOW/HIDE·저장 재로드·장기 AI를 구분한다. 각 병렬 선택 순서·하위 제도 부재·잘못된 소유국으로의 강제 완료도 별도 확인 대상이다. 코드의 조건 존재만으로 엔진의 실제 갱신이나 비용 지불을 통과했다고 기록하지 않는다.

## 적용 후 검증 현황

40개와 공통 국민정신 10개·지역 변동치 12개·사업 4개·범주·그림을 통합했다. 잔여 82개 전체의 정적 896/0·좌표 335/0·세 강제 보상 시나리오 1,213/0와 별도로 `projects-02`의 네 사업 즉시 검사 147/0를 기록한다. 가용성 부정식과 사례 간 기준값을 수정한 진단이며 production 기대값은 바꾸지 않았다. 취소 본문을 직접 실행한 즉시 검사는 실제 일일 자동 취소를 증명하지 않는다.

M1은 UI 정치력 150 지불·90일 자연 만료·기간제 제거·II 유지와, 별도 실행의 통제 상실 후 자동 취소·II 제거·탈환 후 비자동 복구·공통 90일 대기 종료·UI 재착수 정치력 150·II/기간제 복구를 확인했다. M2는 합성 활성화 뒤 실제 일일 진행에서 민주정부 상실로 취소·제거되고 정부 복원만으로 제도가 돌아오지 않았다. M1 소유권 상실의 별도 일일 검사도 8/0이며 UI 최초 정치력 150 지불·day 4 취소·제도 제거·재확보 후 비자동 복구를 확인했다. 이 결과를 M2~M4의 전체 UI 비용·90일 수명이나 M3 다지역 상실의 모든 조합으로 확대하지 않는다.

HIDE 1600×900·GUI 1.0에서 M1~M4와 G3 전체의 짧은 가지·연결과 새 겹침 없음을 관측했다. G1 전체 연결도 확인했으나 시작 아이콘은 상단 경계에 걸려 있었다. G2/G4/G5 전체와 SHOW·정치 전환·패널은 미검수다. 기존 만주 바로가기 직후 시작 제목이 하단에 걸리는 현상은 남지만 추가 스크롤로 새 M1~M4 전부에 접근 가능하다. 최초와 재착수의 소형 아이콘·90일 표시, 활성/대기 조건의 최종 한국어 툴팁도 확인했다. 전체 정상 중점 진행·연구 사용·장기 AI·저장·다른 DLC·멀티플레이와 실행별 결과·보존 증거는 [최종 작업 기록](incidents/2026-09-23-korean-remaining-followup.md)에서 구분한다.
