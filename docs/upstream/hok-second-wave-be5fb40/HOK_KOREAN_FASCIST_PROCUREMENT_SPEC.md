# 구국군 후속 정책 — 군수계약 감독

작성: 2026-09-22. 시작 기준: `691ffa37740237feddf0b44fc68cfa47b10d76bf`, 한국 중점 354개. [보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)과 [독립 정책 묶음 원칙](HOK_KOREAN_FOCUS_LAYOUT_PLAN.md#46-후속-정치-확장의-긴-직렬-가지-방지)에 따른 신규 개발이다. 아래 수치는 이번 구현에서 채택한 설계 최종값이며, 사용자가 개별 수치를 직접 지정한 것으로 기록하지 않는다.

## 범위와 기존 내용 보존

파시즘 후보 F1의 4개 중점·국민정신 2개·기간제 사업 2개를 구현한다. 적용 후 한국 중점은 **358개**, 2차 확장 적용분은 **32개**, 미적용 후보는 **102개**다. 전체 450~470개 목표까지는 92~112개가 남으며, 파시즘 후보 24개 중 후속 20개는 미구현이다.

실제 기존 부모는 `KOR_taming_the_jaebeol`이다. 이 중점의 삼성·현대·SK 주문 해금을 보존하고, 기존 주문의 원가·납기를 정비하는 후속 정책으로 만든다. 첫 후보의 이름 ‘군수조달본부’는 기관을 다시 설립하는 표현을 피하도록 ‘군수조달 실무정비’로 바꾼다. 후보 ID는 유지한다. 기존 공통 군수조달의 무기 연구·MIO 지원·효율 상한·보급 효과, 원작 재벌 주문의 비용·효과·조건은 변경하지 않는다.

## 중점과 배치

표의 새 ID에는 `HOK_KOR_` 접두사가 붙는다. 모든 새 중점은 35일(`cost = 5`)이며, 파시즘 정부·내전 없음·`KOR_establishment_of_the_national_salvation_army` 완료를 요구한다. 항복 중 시작할 수 없고 조건 상실 시 취소하며 계속 진행하지 않는다. 기존 정치 경로의 상호배타 조건은 유지한다.

| ID / 이름 | 실제 선행 | 해석 좌표 | 최종 보상 |
|---|---|---|---|
| `nrsc_procurement_board` / 군수조달 실무정비 | `KOR_taming_the_jaebeol` | (160,7) | 정치력 150 |
| `nrsc_contract_audits` / 군수계약 원가심사 | 군수조달 실무정비 | (158,8) | 군수계약 감독 I: 군수공장 생산량 +10% |
| `nrsc_delivery_schedules` / 군수 납기 조정 | 군수조달 실무정비 | (162,8) | 산업 연구 혜택 150% × 1회, 기간제 사업 2종 해금 |
| `nrsc_supply_contracts` / 통합 군수계약 체계 | 원가심사 **AND** 납기 조정 | (160,9) | 감독 I→II: 군수공장 생산량 +15%, 자원 부족 생산 불이익 -10% |

실무정비는 기존 부모 `(165,6)` 기준 `(-5,1)`이다. 원가심사·납기 조정은 실무정비 기준 `(-2,1)`·`(2,1)`, 통합 체계는 실무정비 기준 `(0,2)`다. 상대 기준은 반드시 먼저 선언한다. 통합 체계의 배치 기준과 두 필수 선행조건을 구분하여 작성한다.

가운데 두 중점은 상호배타가 아니며 어느 순서로도 모두 완료할 수 있다. 새 묶음은 x158~162·y7~9, 중심점 기준 가로 4칸·세로 2칸에 놓이며 전체 x0~204·y0~24 범위를 늘리지 않는다. 인접한 미국 접촉·한미조약 `(156,7/9)`, 고구려의 기억 `(164,9)`, 구국군 중앙 가지의 명판·연결선은 실제 화면에서 확인해야 한다.

실무정비부터 가장 긴 선행 사슬은 3개다. 첫 보상은 35일, 원가심사의 정신 또는 납기 조정의 사업은 우선 진행하면 70일, 두 갈래를 모두 끝내는 데 105일, 통합 체계까지 전체 4개는 **140일**이다. 기존 부모까지의 시간·중단·조건 대기는 제외한다. 병렬 배치는 국가가 중점 두 개를 동시에 진행한다는 뜻이 아니다.

후속 F2 참모 운영·F5 삼군 조정은 기존 `KOR_prussia_in_the_far_east`, F3 동원은 `KOR_stop_democracy`에서 독립적으로 설계한다. 이 F1 말단을 다른 묶음의 필수 선행으로 만들지 않는다. F4 점령 행정·F6 재건은 실제 영토·전쟁 결과 조건을 별도로 명세하며 이번에 해금하지 않는다.

## 국민정신과 연구 보너스

정신 ID는 `HOK_KOR_nrsc_procurement_oversight_1/2`, 이름은 군수계약 감독 I/II다. I의 `industrial_capacity_factory = 0.10`을 II에서 `0.15`로 교체하고 `production_lack_of_resource_penalty_factor = -0.10`을 추가한다. II 수치는 I에 가산하는 값이 아니다. 하위 정신이 있으면 같은 계열만 교체하고, 이미 제거됐다면 II를 직접 지급한다. 파시즘 정부 상실 시 제거하며 정권 복귀만으로 자동 복구하지 않는다.

산업 보너스는 `bonus = 1.5`, `uses = 1`, `category = industry`이며 고유 이름 `HOK_KOR_nrsc_delivery_schedules`를 쓴다. 영구 연구 속도나 앞서가기 불이익 감소로 설명하지 않는다. 기존 공통 조달 정신과 원작 국민정신은 제거·교체하지 않는다.

## 기간제 사업과 운영 선택

범주 ID는 `HOK_KOR_fascist_procurement_programs`다. 원래 한국인 국가에서 구국군 창설과 군수 납기 조정을 완료하면 범주를 공개한다. 원가심사나 통합 체계 완료를 추가 요구하지 않아 납기 조정을 먼저 선택해도 사업을 사용할 수 있다.

| 결정 ID | 이름 | 90일 효과 |
|---|---|---|
| `HOK_KOR_nrsc_emergency_deliveries_project` | 긴급 군수납품 | `industrial_capacity_factory = 0.15` |
| `HOK_KOR_nrsc_material_contracts_project` | 원자재 계약조정 | `production_lack_of_resource_penalty_factor = -0.20` |

두 사업은 각각 정치력 **150**, 민간공장 점유 **0**이며 사람·AI의 민공 수량 요건도 두지 않는다. `HOK_KOR_fascist_procurement_active`와 `HOK_KOR_fascist_procurement_cooldown`을 공유하여 동시에 하나만 진행한다. 종료·취소 뒤 공통 90일이 지나면 둘 중 다시 선택할 수 있다. 진행 중의 보정만 주며 공장·장비·정치력을 반복 지급하지 않는다.

사업은 원래 한국, 구국군 경로 완료, 군수 납기 조정 완료, 파시즘 정부, 비내전·비항복 조건을 요구한다. 조건 상실 시 효과를 회수하고 진행 플래그를 해제하며 공통 대기를 부여한다. 취소 시 정치력은 환급하지 않는다. 영구 정신 보유 자체를 해금 조건으로 추가하지 않는다. 기존 재벌 주문과 새 사업의 동시 효과는 허용하며, 기존 사업의 조건이나 슬롯을 새 제한에 편입하지 않는다.

AI는 실제 선행·정부·경로 조건 아래에서 정책과 사업을 평가한다. 중점 기본 가중치는 2, 두 사업 기본 가중치는 0.5다. 사업은 정치력 150 미만에서 가중치 0이며, 둘 다 전시에는 2배다. 자원 부족을 직접 감지하는 별도 AI 조건은 두지 않았다. 기존 민주 역사 AI 목록은 바꾸지 않는다. 두 가운데 중점의 선택 순서, 정치력 비용, 원작 주문과의 경쟁을 포함한 실제 AI 진행은 별도 검증 대상이다.

## 누적 효과와 근거

새 감독 II 단독은 군수공장 생산량 +15%, 긴급 군수납품까지 함께 적용하면 +30%다. 원작 `KOR_jaebeol`의 +20%를 실제 보유한 경우에만 해당 부분 합이 각각 +35%·+50%가 된다. 파시즘 경로에서 그 정신을 반드시 얻는다고 가정하거나 새로 지급하지 않는다. 다른 기술·법률·국민정신은 이 부분 합에서 제외한다.

감독 II와 원자재 계약조정을 함께 적용하면 같은 자원 부족 불이익 수정치의 부분 합은 `-0.30`이다. **원자재 소비량 자체가 30% 줄어드는 효과가 아니다.** 서로 동시에 사용할 수 없는 두 사업이나 정신 I·II를 합산하지 않는다. 미결인 보병장비 한정 생산량 +10%를 이번 일반 군공 산출 보상으로 해결했다고 기록하지 않는다.

설치본 HOI4 1.19.3.0.c01a / Steam build 25205862의 `common/ideas/japan.txt:637,2045`에서 군공 생산량·자원 부족 불이익의 국민정신 문맥을, `common/decisions/SWI.txt:1265,4496`에서 기간제 결정 문맥을 확인했다. 사업 플래그·종료·취소 구조와 정신 단계 교체는 기존 공산 정책 구현을 대조한다. 문법 근거는 설계 수치의 실제 효과나 장기 균형 검증을 대신하지 않는다.

중점·정신은 파시즘 가지의 갈색·차콜 바탕과 청동 장식을 사용한다. 계약서·원가 장부·화물과 시계·공장과 계약서의 소재를 구분하고 실제 정신 단계에만 I·II를 표시한다. 모든 이미지·마스크·GFX는 프로젝트 내부 상대경로로 연결하며, 결정은 별도 32×32, 범주는 51×40 이미지를 사용한다. 차콜·갈색 RGB(70,60,48)은 배경 레이어에만 적용했다. ## 검증 상태

정적 참조·ID·좌표·괄호·인코딩·이미지 검사는 통과했다. 별도 새 게임의 시작 직후 강제 보상 검사는 원가심사 우선 30개, 납기조정 우선 38개로 **68 PASS / 0 FAIL**이다. I→II 및 하위 부재 시 II 지급·즉시 수정치·연구 보너스 범주·각 사업 활성 효과·원작 정신 보존을 확인했다. 진단 없는 운영 소스로 새 한국 게임 로드와 신규 오류0도 확인했다. 결과와 실행별 근거는 [작업 기록](incidents/2026-09-22-korean-fascist-procurement.md)을 따른다.

강제 완료나 스크립트 활성화만으로 정상 35일 진행·정치력 차감·연구 혜택 소모·실제 생산량·장기 AI·기존 저장·멀티플레이·SHOW/HIDE 화면 검증까지 완료했다고 표현하지 않는다. 이전 공산 경로의 PASS 수치는 이 모듈의 검증 결과가 아니다. 장기 진단은 첫날 말 이후 로그 날짜 진행이 멈춰 중단했으므로, 자연90일 만료·대기 만료·정권 변경 취소는 미검증이다. 화면 제어 연결이 없어 사업 공개 UI·AND 차단·배치·상태별 아이콘 역시 확인하지 못했다.
