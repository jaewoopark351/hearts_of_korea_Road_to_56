## 세력 템플릿의 구체적인 동작

정의는 `common/factions/templates/HOK_KOR_factions.txt`에 두며 `visible = { always = no }`로 생성 UI의 전역 후보에서 제외한다. 기존 스크립트가 생성할 때만 사용한다. 설치본 `FACTION_DEFAULT_TEMPLATE`이 가리키는 공용 fallback의 `joining_rule_neighbors_only`, `joining_rule_has_no_offensive_war`, `dismissal_rule_offensive_war`를 네 템플릿에 명시적으로 유지한다. 이 규칙들은 새 템플릿에 자동 상속되지 않는다. 새 가입 이념·지역 제한을 추가하지 않으며 기존 초대 사건 코드는 보존한다. 원본 공용 fallback처럼 세력 지도국의 다른 세력 가입을 허용한다. 기존 세력 지도국인 독일에는 새 템플릿을 덮어씌우지 않는다.

| 템플릿 접미사 | 이름·창설국 | 헌장과 초기 목표 | 명시한 규칙 |
|---|---|---|---|
| `asian_liberation_front` | 아시아 해방전선·한국 | 공산주의 확산 / 산업 확장, 영토 해방, 핵 경쟁 | 해방 중심 평화회의, 산업에 따른 지도국 변경 |
| `asian_union` | 아시아 연합·한국 | 단결을 통한 힘 / 군사기지, 무역 동맥, 제해권 | 망명정부 허용, 산업에 따른 지도국 변경 |
| `organization_of_free_nations` | 자유국가기구·미국 | 민주주의 수호 / 무역 동맥, 핵 경쟁, 제해권 | 망명정부 허용, 산업에 따른 지도국 변경 |
| `central_powers` | 기존 `GER_central_powers_faction`·독일 | 평화 수호 / 산업 확장, 군사기지, 영토 해방 | 산업에 따른 지도국 변경 |

전체 ID는 `HOK_KOR_faction_template_<접미사>`다. 모든 헌장·목표·규칙은 설치본의 해당 등록 ID를 참조한다. 표의 지도권 기준은 공용 fallback의 인력 기준을 산업 기준으로 바꾸는 의도적인 C4 설계다. 새 자동 전쟁이나 자동 가입 효과는 추가하지 않는다. 목표의 달성·보상과 평화회의 규칙 역시 의도적인 새 기능이며, NCNS에서의 가입·추방·지도권·목표 적용은 실제 실행 확인과 구분한다.

변경 호출은 한국 중점의 `KOR_preparing_for_asian_liberation`, `KOR_founding_of_the_asian_union`, 독일 왕정과의 기존 동맹 중점 및 `kor_events.34`의 미국 창설 부분이다. 사건의 수락/거절 확률, 후속 사건, 초대·가입 효과와 기존 이름 키를 보존한다. 일본의 별도 HoK 민주 경로 등 다른 국가의 세력 생성은 이번 범위에서 일괄 치환하지 않는다.

세력 그림 4개는 설치본의 공산 연대·민주주의·연합국·공용 문양을 프로젝트 내부로 바이트 그대로 복사했다. 원작자 Paradox Interactive, 같은 게임용 모드 내 바닐라 자산 재사용이며 새 그림이나 새 라이선스를 주장하지 않는다. `interface/HOK_KOR_factions.gfx`가 내부 상대경로와 기존 2프레임 구조를 연결한다. [출처·해시·크기 매니페스트](data/HOK_KOREAN_FACTION_ASSET_MANIFEST.json)에 선택한 원본 사본과 최종 경로를 기록했다. 100×100 첫 프레임의 별도 검토 그림을 외부 진단 루트에 보존했다.

- [구현·검증 기록](incidents/2026-10-31-korean-feature-integration.md): 실행 구성, 실제 통과·실패·차단과 미검증 사례.

교리 이전의 1939 진척은 구형 기술과 현행 숙련도의 수학적인 1:1 대응을 주장하지 않고, 같은 원래 노선의 원본 독일 전환값을 적용한다. 이전 저장에 교리를 강제로 다시 지급하는 `on_action`이나 자동 마이그레이션은 추가하지 않는다. 기존 저장에서 새 중점 보상이 소급 지급된다고 약속하지 않으며, 일반 저장 호환과 새 합성 저장의 재불러오기를 구분한다.

정적 보존·파싱·참조 검사는 엔진 등록, 실제 효과·비용·수여·구매·습격 결과·14일 정상 진행·세력 외교·저장·장기 AI·멀티플레이를 증명하지 않는다. 실행 검증을 완료하지 않은 기능을 완료로 표시하지 않는다.
