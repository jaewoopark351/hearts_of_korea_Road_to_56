기반시설·공장은 공유 주 건물이므로 건물 피해는 두 주 단위로 적용된다. 프로빈스 한 곳의 공장만 파괴한다고 표시하지 않는다. 네덜란드 원본의 비용·작업 기간과 비교 가능한 제한된 피해를 사용하되, 원본 네덜란드의 장기 민원 이벤트는 추가하지 않는다.

각 피해 명령은 해당 건물이 실제로 존재할 때만 실행한다. 건물이 없는 경우 새 건물을 만들거나 다른 유형으로 피해를 옮기지 않는다. 기존 건물에 적용되는 수치와 순서는 그대로다. 이 보호 조건은 아래 실제 실행에서 확인된 미존재 건물 오류에 대한 후속 수정이다.

초기판의 두 결정 `ai_will_do`는 모두 0이다. 자동으로 자국 산업을 손상시키는 AI 판단을 이번 첫 적용에 포함하지 않는다. 플레이어 사용은 가능하며, 위협 판정·AI의 실제 방어 효용은 후속 검증과 별도 설계 대상이다.

## 침수 값과 안전 수명

설치본 HOI4 1.19.3 `common/modifiers/00_static_modifiers.txt:147`의 `flooded`와 같은 값을 별도 `HOK_KOR_soyang_flooded` 정적 수정치로 정의한다. 다른 국가나 댐 파괴가 사용하는 공유 `flooded`를 제거하지 않기 위한 분리다.

- 방어 +50%, 이동속도 -50%, 참호 구축 속도 -20%.
- 이동 중 조직력 손실 +0.25, 보급 -40%, 트럭 소모 +3. 수치의 엔진 표시는 실제 툴팁으로 확인한다.
- 고유 전역 플래그로 준비·침수·정상화 상태를 관리한다. 한국 소멸 뒤에도 세계에 남은 프로빈스 효과를 제거할 수 있어야 한다.
- 범용 일일 콜백은 관리 플래그와 `525 = { is_controlled_by = ROOT }`를 먼저 확인한다. 경기의 현재 지배국만 한국 한 국가·두 고정 프로빈스·춘천 댐의 안전 검사를 담당하도록 한정하므로 한국이 병합된 뒤에도 정리할 수 있다. 별도 전체 국가·주·부대 iterator를 쓰지 않는다.
- 평화, 항복, 한국 소멸, 두 주 소유권 또는 두 프로빈스 통제 상실, 댐 상실 시 전용 효과와 관리 플래그를 정리한다. 통제 변경·평화·항복·병합 콜백에서도 같은 멱등 정리 경로를 사용한다. 매일 검사는 콜백이 포착하지 못한 변화와 저장 불일치의 보완 수단이다.
- 정리 함수는 두 프로빈스의 `HOK_KOR_soyang_flooded`만 제거한다. 다른 프로빈스, 공유 `flooded`, 다른 국가의 플래그를 바꾸지 않는다.
- 준비·정상화 중에는 다른 수문 작업을 시작할 수 없다. 자동 안전 정리가 진행 작업의 유효성도 취소한다.

## 문법·화면 근거

- 결정의 기간·완료 시 효과·취소 구조 및 프로빈스 침수: 설치본 `common/decisions/HOL.txt:377–566`, `common/decisions/IRQ.txt:511–623`.
- 춘천의 실제 댐 확인은 설치본 `common/ai_strategy/ENG.txt:3070`의 `any_province_building_level` 구조에 `province = { id = 13418 }`, `building = dam`, `level > 0`을 사용한다. 추측한 `has_building` 문법을 쓰지 않는다.
- `on_daily`, `on_peace`, `on_capitulation`, `on_annex`와 통제 변경의 범위는 설치본 `common/on_actions/_documentation.md`, `00_on_actions.txt`를 따른다. 설치본 `05_lar_on_actions.txt:1445`의 범용 `on_weekly`는 국가 범위의 조건을 직접 평가한다.
- 확장팩 다수가 비활성인 복사 프로필 실행의 로그에는 SAU 등을 비롯한 여러 국가의 `ROOT`·`THIS` 출력이 있었다. 최초 검색은 엔진이 출력서식으로 처리한 `[CADENCE]` 접두사를 그대로 찾아 미호출로 잘못 판정했다. 이는 진단 검색 문제였으며 production 일일 훅의 실패 증거가 아니다. 경기 지배국 분기를 둔 원래 범용 훅을 유지하고 진단 표식을 괄호 없는 문자열로 바꾸었다. 후속 실행의 구분 가능한 실제 기록과 침수 정리 결과는 아래와 같다.
- 기존 한국 수문 이름은 재사용한다. 신규 설명·효과·조건은 한국어/영어 대응 파일에 같은 키로 추가하고 UTF-8 BOM 및 각 locale 헤더 바로 뒤 동일한 기여 주석을 유지한다.
- 결정 행은 32×32, 카테고리 헤더는 51×40 전용 DDS와 프로젝트 소유 GFX를 사용한다. 네덜란드 수문 원본의 선택된 그림을 프로젝트 내부 작업 경로에 보관하고 크기·여백을 조정한다. 원작자는 Paradox Interactive이며 같은 게임 모드용 바닐라 재사용 자산으로 기록한다.

### 합성 침수의 자동 정리 관측

통합 담당자가 별도 복사 설치·프로필에서 실행한 PID `5012`, 체크섬 `f6c5`의 새 1936 한국 게임을 사용했다. 이 체크섬은 외부 진단 모드를 포함한 실행이며 최종 진단 없는 소스의 체크섬이 아니다. 실제 조건 로그는 `Gotterdammerung`, `Thunder at Our Gates`, `No Step Back`, `By Blood Alone`, `No Compromise, No Surrender`가 없고 `Man the Guns`는 있다고 기록한다. 실행 디렉터리의 `dlc0` 명칭을 모든 DLC가 없다는 판정으로 사용하지 않는다.

1. 1936.1.1.12 일시정지 상태에서 외부 진단 버튼으로 서울·춘천에 `HOK_KOR_soyang_flooded`와 공유 `flooded`를 각각 추가하고 관리·활성 플래그를 설정했다. 전쟁·중점·DLC·건물 조건을 위조하지 않았으며 공장 피해도 이 준비 버튼에 넣지 않았다. 이는 평화 시 안전 정리만을 위한 합성 상태다.
2. 즉시 저장한 `KOR_1936_01_01_12.hoi4`와 일반 시간 진행 후 저장한 `KOR_1936_01_09_23.hoi4`를 비교했다. 강제 정리 버튼은 누르지 않았다.
3. 실제 직렬화된 두 프로빈스의 `custom_modifiers`는 전용 수정치 **2→0**, 공유 `flooded`는 **2→2**다. 공유 수정치의 `-1` 값도 동일하다. 전용 수정치 이름은 이후 저장 전체에서 0건이다.
4. 전역 관리·침수 활성 플래그는 앞 저장에 있고 뒤 저장에는 없다. 개방·정상화 진행 플래그도 뒤 저장에 없다. 저장 구조를 식별해 실행한 외부 비교는 **13 PASS / 0 FAIL**이다. 이는 상태·효과 보존 검사이며 13회의 게임 실행을 뜻하지 않는다.

콜백 비교 로그는 괄호 없는 표식으로 범용 국가별 기록 **91개·91개 태그**, 경기 지배국 분기 **1개(KOR)**, 진단용 `on_daily_KOR` 비교 **1개(KOR)**를 구분했다. 모두 `ROOT=THIS`이며 국가별 기록은 `1936.01.01.13`부터 `1936.01.02.12`까지 분산된다. 경기 지배국 분기는 `1936.01.01.24`에 기록됐다. 진단은 자체 1회 플래그가 있으므로 이 수치를 모든 날짜·모든 미계측 호출의 횟수로 확대하지 않는다. 자동 정리의 정확한 단일 틱 시각을 두 저장만으로 계측했다고 주장하지 않는다.

로그 20개와 두 불변 저장 사본은 `C:/hoi/test/feature-integration-20261031/runs/5012-fixture-dlc0/`에 보존했다. 외부 결과는 `validation/soyang-save-comparison.json`, `validation/daily-cadence-observation.json`이며 전용 비교 도구는 `validation/assert_soyang_saves.py`다. 자료의 파일 해시와 실제 프로빈스·전역 플래그 값은 결과 JSON에 있다.

### 보호 조건 적용 후 새 프로세스 강제 효과 회귀

### 전쟁 중 영토 변경 관측의 한계

같은 PID `12008` 게임의 1936.5.10.24 발진 전 저장과 1936.5.19.15 첫 습격 결과 저장에는 소양강 전용 수정치 두 개와 관리·활성 플래그가 계속 남아 있다. 경기 `525`·강원 `1029`의 소유국은 한국이며, 5.10 저장의 강원 주 지배국은 명시적으로 일본이다. 그러나 서울 `7125`·춘천 `13418`의 프로빈스 지배국 필드는 직렬화되지 않았고, 그 부재를 한국 또는 일본 지배라고 임의 해석하지 않는다. 주 작업자의 제한된 지도 확인도 일본 지배 `7021`·`13422`까지만 확인했으며 `13418`은 확인하지 못했다. 따라서 이 관측은 실제 특정 타일 통제 상실 뒤의 자동 정리 성공도, 정리 실패도 입증하지 않는다. 일반 주 지배국 변경은 두 타일의 통제 상실과 동일한 조건이 아니다.

### 남은 검증

중도 취소·재시작, 정상 반복 사용, 각 건물의 정확한 순간 피해량, 전쟁 종료·정확한 대상 타일 통제 상실·한국 항복/소멸·댐 상실의 개별 정리 경로, 정상 개방·정상화 작업 중 재로드와 구현 이전 기존 저장 호환성은 미검증이다. 보호 조건을 적용한 뒤의 일반 결정 14일 전체 반복도 별도로 수행하지 않았다. 원본·최종 그림의 정적 확인이나 실제 수문 결정 표시를 전체 게임 그래픽/UI 통과로 취급하지 않는다. 북쪽 로고 화면은 서울로 카메라를 옮기자 실제 지형·도시·부대가 표시됐으므로 새 그래픽 결함으로 분류하지 않았다. 장기 AI·멀티플레이도 미검증이다.

소스 검토, 강제 효과, 정상 진행, 저장 직렬화 검사와 재로드, 실제 화면을 구분한다. 모든 테스트·로그·스크린샷·저장은 `C:/hoi/test/feature-integration-20261031/`에 두며 커밋·푸시·업로드는 하지 않는다.
