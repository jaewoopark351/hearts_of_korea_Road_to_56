## 상대좌표와 H1 변경

중점 `(x,y)`는 화면 픽셀이 아닌 중점 격자다. 상대 중점은 `기본 위치 = 기준 중점의 해석된 기본 위치 + script_xy`로 계산한다. `relative_position_id`와 진행의 `prerequisite`는 별도 필드다.

환제국의 부활 `KOR_empire_of_hwan`은 호환판에서 `(178,10)`으로 해석되고 H1 시작보다 먼저 선언된다. 시작의 실제 선행도 이 ID로 교체한다. 자식 셋의 상대값·기준·진행 선행은 보존한다. 결산통일은 물자관리와 지방 순찰의 별도 singleton 선행 그룹 두 개를 유지해 둘 다 요구한다. H1 네 중점의 기존 형성·독립·내전·영토 조건은 이번 배치 변경으로 제거하지 않는다.

이 이동은 야뫼도 정복 가지 오른쪽, 형벌부대 아래 공간에 3행 물자 묶음을 배치하는 원본 의도를 따른다. 주변 정복·형벌·H3 복구·H4 장병 복귀·전제군주 가지의 실제 연결선과 명판 간격은 호환판 화면에서 별도 확인한다.

JSON은 460개 ID의 선언 순서, 전후 상대 기준·소스 상대값·기본 절대값·선행 그룹·전체 기준 연쇄를 기록한다. `anchor_chain`은 자기 ID부터 절대 기준까지 포함한다. 소유한 offset과 조상에서 상속하는 offset의 ID를 구분하며 7개 원문을 `offset_definitions`에 보존한다.

H1 시작의 새 연쇄는 환제국 → 북방복고 → 사상적 광신 → 황국주의자 숙청 → 계연수 섭정 → 왕의 귀환 → 헌법 개정 → 덕수궁 평의회 → 방송 장악 → 우리황실사랑회로 연결된다. 이 연쇄에서 offset 소유자는 `KOR_urihwangsilsaranghoe` 하나이며 한 번만 만난다. H1과 자식에 직접 offset을 추가하지 않는다.

왕정 offset의 현재 조건은 `obsolete_focus_branches_visibility = HIDE`와 `KOR_urihwangsilsaranghoe` 완료이고 이동은 `(-101,0)`이다. SHOW 및 왕정 진입 미완료 초기 HIDE는 기본 좌표를 사용한다. 왕정 진입 완료 HIDE 모델에서는 같은 offset을 한 번 더해 위 표의 위치를 계산한다. 이는 구문과 연쇄에 따른 정적 계산이며 실제 상속·트리 갱신·숨김의 실행 결과는 아직 증명하지 않는다.

JSON의 조건부 상태는 SHOW, 초기 HIDE, 왕정 진입만 완료한 HIDE다. 위치는 숨겨질 수 있는 정의에도 기록한다. `all_defined_node_bounds`는 모든 정의의 계산 범위이며, 실제 표시 가지의 범위·엔진 스크롤 한계·픽셀 여백이 아니다. 다른 정치 경로 완료 상태는 이 명세의 모델 범위 밖이다.

## 배치 이력과 화면 확인 기준

[2026-09-21 압축 기록](../../hearts_of_korea/docs/incidents/2026-09-21-korean-focus-compact.md)의 넓은 배치·장거리 선 문제와 [정치 경로 압축 기록](../../hearts_of_korea/docs/incidents/2026-09-22-korean-political-compaction.md)의 조건부 이동 이력을 참고한다. 그 문서의 과거 수량·좌표·관측·0 이동량은 현재 호환판 결과가 아니다. [최신 원본 왕정 명세](../../hearts_of_korea/docs/HOK_KOREAN_ROYAL_PREREQUISITE_LAYOUT_PLAN.md)와 이 호환판 연쇄 계산을 함께 사용한다.

상대좌표를 사용하거나 중점 중심이 다르다는 사실만으로 화면 간섭을 배제하지 않는다. 실제 아이콘 외곽·한국어 제목판·다중 선행 합류·배타선·클릭 영역을 확인하고, 정당한 공유 연결과 관계없는 가지를 가리는 선을 구분한다. 일반적인 직선·직각 근사 모델을 엔진의 확정 라우팅으로 취급하지 않는다.

확인할 상태는 SHOW와 초기 HIDE, 정상 왕정 선택 전후 HIDE, 기준 중점이 숨겨지거나 배타 경로가 선택된 상태다. 각 상태에서 H1 네 중점, 환제국 진입선, 야뫼도·황하 정복 줄, 형벌부대, H3/H4, 오른쪽 전제군주 가지를 함께 본다. 지원 해상도·GUI 배율·확대 단계와 패널·바로가기·스크롤 접근을 기록한다. 검수되지 않은 상태까지 무겹침을 주장하지 않는다.

## 정적 근거와 남은 실행 검증

독립 소스 해석에서 고유 ID 460개, 누락·앞선 선언 위반·순환 참조 0개, 유한한 전체 좌표, H1 네 개만의 기본 위치 변화와 나머지 456개 보존을 확인했다. 7개 offset 원문은 보존되며 H1 네 연쇄의 왕정 offset은 각각 한 번이다. 이 확인은 좌표와 참조의 정적 근거이며 아이콘·제목판·선·게임 진행의 검증 횟수가 아니다.

호환판에서 전체 재시작한 새 게임과 실제 UI 확인, 정상 35일 진행, 한쪽만 완료한 AND 차단과 양쪽 완료의 착수, 조건 상실 취소, H2 형성 전 정신 유지·I→II 교체·하위 부재 지급을 구분해 검증해야 한다. 강제 효과 진단은 정상 진행과 별도 기록한다. AI·저장 재로드·기존 저장·다른 DLC·언어 의존성·멀티플레이도 실제 수행한 범위만 판정한다.

현재 이 명세에 대한 호환판 런타임 결과는 **UNPROVEN**이다. donor의 초기 SHOW/HIDE 화면·정적 결과·체크섬·로그를 포트의 통과 결과로 재사용하지 않는다. 새 검증 증거는 저장소 밖의 승인된 테스트 경로에 보관하고, 이 두 파일은 공개 가능한 좌표 명세로 유지한다.
