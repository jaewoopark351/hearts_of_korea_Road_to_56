## 남은 범위와 한계

완료 사례는 합성된 정부·선행 중점 표식·세력 조건에서 실제 생산 `complete_national_focus`를 실행했다. 복사한 available/prerequisite 조건식은 엔진에서 판정했지만 정상 UI 경로가 아니다. 시험 코드가 검증 대상 보상을 대신 지급하지는 않았다. 정치력 상한 간섭을 피하려고 검사 직전 100으로 설정했으므로 자연 플레이의 자원 흐름을 증명하지 않는다.

여섯 정책 사례는 같은 공유 슬롯의 동시 실행을 피하면서 비지역 사업 14개의 실제 활성·기간 경과·90일 cooldown을 검사했다. 89일째 활성, 91일째 비활성 및 cooldown, 179일째 cooldown 유지, 181일째 해제를 관측하고 두 번째 회차도 같은 경계를 확인했다. 그중 10개는 같은 ID 재착수·정부 상실 취소까지 확인했다. 시작 후 하루 대기를 포함한 367일 일정을 모두 완료했다. 다만 취소 조건이 모든 중간 tick에서 계속 거짓이었다는 증거는 아니므로 관측 간격의 과도한 해석은 피한다.

지역 사례는 45개 이벤트 진입, 고유 검사 201개, 중점 34개·정신 8개·수정치 12개·사업 4종의 7회 활성화를 확인했다. M1은 소유권 상실 취소·실제 cooldown 경과 후 재착수, M2는 첫 기간 종료 후 시험용 cooldown 초기화와 재활성화·정부 상실 취소, M3는 통제권만 상실했을 때 취소·시험용 초기화 후 재착수, M4는 기간 종료 관측이다. M4의 취소·같은 ID 재착수는 미검증이다. M1의 첫 관측 시 cooldown 나이 `<1일`은 통과했지만 조용한 각 시간별 관측의 개별 타임스탬프가 없으므로 불확실성이 정확히 1시간 이내라고 증명하지 않는다. 지역을 잃은 직후 available=false에는 이미 활성인 사업의 조건도 작용하며, H 거점 조건의 동적 대표 사례는 328/941 묶음이다. 상세 날짜·검사 행·한계는 `C1-geography-v3/coverage-review.json`에 있다. 지역 사례 사이 초기화는 정상적인 단일 플레이 경로의 증거가 아니다.

현재 **UNPROVEN**: 정상 중점 소요 기간과 클릭 경로, 결정 UI 비용·구매 가능성, 실제 초상·중점·정신 아이콘 렌더링, 연구 보너스 횟수·소모, 안정도 보상 수치, 정상 AI 선택·균형, DLC 비활성 조합, 1939 북마크, 저장/불러오기·기존 저장 호환, 멀티플레이/OOS, 일반 종료. 강제 완료 통과로 대체하지 않는다.

임시 코드 제거 후 `python tools/validate_port.py`를 재실행하여 **20 PASS / 0 WARNING / 1 ERROR**를 확인했다. `migrate_doctrines.py --check`의 불일치는 `history/countries/KOR - Korea.txt` 한 파일이며, 내용 차분은 MtG 분기의 생성기 기대 `set_war_support = 0.05`와 기존 `0.1#20260922_kpopmodder` 한 줄이다. 해당 파일의 기존 SHA-256 `243FC1FBDE8DB75B82CCFEBD6BB01CA7001DABCD944CA8534E7324413705BE30`을 유지했다. `final-static-validation.txt`, `final-history-check.txt`, 줄바꿈을 동등하게 비교한 `final-history-content-diff.txt`에 근거를 보존한다. 정적 검사의 일반적인 RUNTIME NOT PROVEN 안내는 그 도구 자체의 검증 범위이며 이 문서의 별도 실행 증거와 구분한다.

## 제거·복원 완료

완료·중단 사례마다 설치·제거 영수증을 보존했다. `postflight.json`에서 실행 경로의 임시 파일 두 개 부재와 생산 파일 400개 해시 유지를 확인했다. 한국 중점 SHA-256도 `6F9F76036B21D22E9716ACE44C124D20BBF2CAF3751AAEE5313C758FC3B8F162`로 유지됐다. 이후 임시 코드 없는 C0/C1은 각각 새 프로세스에서 시작했다. 모든 검증용 게임은 종료됐으며 정상 메뉴 종료를 검증한 것은 아니다. 사용자의 기존 저장을 불러오거나 저장 명령을 수행하지 않았고 시험 중 자동 저장은 꺼져 있었다.

복원 기준은 시험 직전 백업한 **4개 모드 목록**이다. `restoration.json`은 17:00:58 KST에 `dlc_load.json` SHA-256 `76B07E3B31BC943D4ED5E3E0BE69D51862DD14236358E4CD2DCC992A2D057A66`, `settings.txt` SHA-256 `8FDACBF3F1ACE0881A7E8655A98FB33095A6C39F4A6E2450F020ABB7212432FD`의 원본 바이트 복원을 기록한다. 첫 설정 쓰기는 접근 거부였으나, 변조 여부를 다시 대조한 뒤 정확한 백업 파일 복사로 복원했다. ACL은 변경하지 않았다. 게임이 추가했던 종료 상태·로딩 화면 목록도 원본으로 돌아갔다.

종료 시 RT56 manifest `7475007536894105204`와 호환판 HEAD `c84fd9faa543a9d2f3aabd8bebe7691984dc6cc3`를 재확인했다. `git diff --check`는 exit 0이다. 원시 로그와 임시 코드 생성기·후보본은 무시되는 `.local-artifacts` 아래 감사 증거로 남기며 실행·배포 파일로 설치되어 있지 않다.

이번 실행 검증을 위해 생산 게임플레이를 고치거나 커밋·푸시·게시·업로드하지 않았다. 문서·임시 진단 변경은 미커밋 상태다.
