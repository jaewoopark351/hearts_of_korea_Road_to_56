# ADR-0006: 한국 6도 분할의 RT56 통합과 새 게임 범위

날짜: 2026-11-07, Asia/Seoul. 상태: **채택·구현·이번 범위 검증·환경 복구 완료**(2026-11-08 KST). 실제 관측·최종 suite 190 PASS / 0 MISMATCH / 10 UNVERIFIED·기존 정적 오류와 출시 제약은 구현 기록을 따른다.

## 조건과 근거

한국 주 분할·영토 조건·보상·이름 키 또는 관련 생성기를 변경하기 전에 이 결정을 읽는다. 실제 파일·검사와 잔여 범위는 [구현 기록](../implementation/2026-11-07-korean-state-split-port.md), [대응표](../data/HOK_KOREAN_STATE_SPLIT_PORT_MAPPING.json), [분할 잠금](../../tools/hok_state_split_lock.json)을 함께 읽는다. donor 입력을 재사용할 때는 [출처 안내](../upstream/hok-state-split-20261107/README.md)를 먼저 확인한다.

원본 `0d73d49726abbfa435c73f1bf8cc24d4a5af014b` 위의 미커밋 변경은 한국을 9주에서 15주로 분할한다. donor의 신설 주 ID `1086–1091`은 RT56의 외국 주와 충돌한다. 기존 한국 콘텐츠는 주 번호를 영토 전체, 도시·자원 거점, 후보 membership, 특정 시설과 서로 다른 뜻으로 사용한다. 신규 주 파일만 복사하거나 숫자를 일괄 대체하면 영토 조건·고정 보상·내전·분쟁·AI 의미가 달라진다.

기준은 호환판 `3d9355b70152794ed974dcf183323c24206d900a`, HOI4 `1.19.4.2.2da5`, RT56 manifest `7553774178744855191`이다. 이 결정은 과거 전체 생성기의 지문을 갱신하거나 실행 통과를 선언하지 않는다.

## 결정

1. 기존 호환판의 한국 6개 부모 ID를 한 후속 도에 유지하고 신규 6개를 `1148–1153`으로 배정한다. `920/1148` 경북/경남, `1145/1149` 충남/충북, `919/1150` 전북/전남, `527/1151` 평남/평북, `918/1152` 함남/함북, `917/1153` 황남/황북이다. RT56 외국 주와 기존 province ID를 재번호하지 않는다.
2. 경계는 기존 province의 연결 집합을 재배정하는 게임 해상도 구획이다. 역사 GIS 경계나 인구 조사 재현이라고 부르지 않는다. donor province 이전 `13414–13447 → 13535–13568`을 유지하며 새 RGB·비트맵·해안선을 만들지 않는다.
3. 부모별 인구·원자원·공장·승점과 고정 보상 총량은 보존한다. 각 자식의 부모 카테고리·초기 기반시설 유지로 기본 슬롯 `33 → 57`, 인프라 레벨 합 `14 → 23`은 의도적으로 증가한다. 국가 시작 공장 `9·4·1`과 전역 상한은 유지한다.
4. 옛 도 전체의 소유·통제는 자식 AND, 후보 membership·목록은 OR/확장, 한쪽 상실 취소는 실패 OR로 처리한다. 원래 ROOT/subject/CONTROLLER scope와 연결자를 보존한다. 슬롯·해안·기지 수용량은 실제 단일 수혜 주에서 검사한다. 지급 횟수·원래 비용·기간·AI·refund 정책을 복제하거나 완화하지 않는다.
5. 한국 전체 15·북부 6·남부 9·제주 제외 14를 구별한다. 함남·황남은 북부다. 내전의 경기 포함/제외와 경상 전체 제외, 만주 목록과 기존 거점 집합은 보존한다. 중국 평남 CONTROLLER 및 중복 방지 proxy는 유지하고 generator만 평남·평북으로 확장한다.
6. 표시 키 `HOK_KOR_STATE_<donor ID>`는 안정적인 논리 ID로 보존한다. 숫자 접미사는 포트 state scope가 아니다. 한영 현지화에 별도 12키를 두며 RT56 외국 `STATE_1086–1091`을 덮어쓰지 않는다. 별개로 쓰시마 `1147`의 잘못된 기존 표시 참조만 이미 정의된 `STATE_1147`로 정렬한다. 기존 해군·핵 연구망 툴팁의 주 이름도 실제 우선 대상인 경남/함남 논리 키로 맞추되 기존 4키·조건·보상은 변경하지 않는다.
7. 한국 콘텐츠는 기존 포트 출력 위의 정확한 donor 전후 delta로 합성한다. 일본·중국·공유 정의는 [ADR-0004](0004-hok-korean-content-priority.md)에 따라 현재 물리 RT56/vanilla를 기반으로 한국 연결만 병합한다. 새 `common/national_focus/japan.txt`도 현재 RT56 중점이며 donor whole-file import가 아니다. 포트 전용 WTT PRC·RT56 일본 이벤트 소비자도 포함한다.
8. 초기 45개 출력에 기존 연구망 한영 파일 2개의 표시 참조 보완을 더해 최종 계층은 **47개 런타임 출력**을 소유한다. 신규 경로는 계속 9개이고 기존 경로 변경은 38개다. 동결 입력·현재 물리 호스트·기존 HOK 연결이 적용된 메모리 중간 출력·최종 출력의 해시를 분리한다. 역사적 핀은 유지하고, 검증된 최종 분할 바이트만 이전 출력으로 역투영해 과거 계약을 검사한다. 새 실제 출력의 유효성은 별도 분할 gate가 검사한다. 45출력의 초기 C0 관측은 47출력의 후속 검증과 구별한다.
9. **새 게임 기준**으로 취급한다. 기존 9주 저장 변환은 구현하지 않았다. 후속 실행에서는 새 분할 지도의 45출력으로 만든 저장을 47출력의 별도 프로세스에서 불러와 추가 진행한 경로만 확인했다. 현재 RT56 `common/bookmarks/blitzkrieg.txt:3–4`는 날짜 `1939.8.14.12`의 시나리오를 지원하지 않는다고 명시하며 실제 새 게임 UI에도 1936 카드만 표시됐다. 한국 15주의 날짜 이력 보존은 그 bookmark의 지원 증거가 아니다. 날짜/CLI를 강제하거나 host bookmark를 수정하지 않는다. 전역 host 리베이스·기존 지리 버그 수선·경제 재조정·멀티플레이 지원을 자동 포함하지 않는다.

## 대안과 제외한 변경

donor ID 그대로 사용은 RT56 외국 주 충돌 때문에 제외했다. 신설 주만 복사는 기존 소비자의 영토 축소·보상 오배치 때문에 제외했다. 양쪽에 원래 보상을 그대로 복제하거나 모든 부분 조건을 한국 전체 15주로 바꾸는 안은 원래 총량·예외를 바꾸므로 채택하지 않았다.

고정 총량을 보존해도 주별 개발 비용·점령·저항·해방·임의 적격 주 선택과 슬롯 포화 시점은 달라진다. 이 결과를 호환 수리만으로 설명하지 않고 원본의 의도된 한국 지리·산업 공간 확장으로 기록한다. 표시 앵커 하나의 RT56 기하 적응은 `map_adaptations`에 별도 기록하고 source 입력은 그대로 보존한다.

건물 비교는 부모를 제외한 payload로 donor의 실제 신규 172행을 분리하고, 기존 경북 선호 기지와 중복되는 2개를 뺀 170개만 선택한다. 이전 한국 배치 546행의 비ID 필드를 보존하고 원본의 기존 재부모화 209행을 새 행처럼 일괄 복원하지 않는다. 기존 RT56 경상 기지가 모두 경북에 놓이는 경우에는 경남의 원본 공군기지 `4810.00;11.45;1239.00;4.32`와 로켓 위치 `4817.00;9.90;1237.00;4.79` 두 행만 별도로 복원한다. 정확한 source 행·육지 소속·유일성 검사와 source/선택/복원 역할을 함께 기록한다.

초기 7,170개 검사 뒤에 확인된 소수 표기/신규 행 분류 공백은 별도 수선·필드 비교·변형 거부로 다룬다. 초기 검사 수만으로 전체 건물 필드나 실제 화면이 증명됐다고 하지 않는다.

새만금 충청 보상, 비해안 항구 요새, 일본 기존 요새 범위, floating-harbor 비해안 앵커는 별도 문제로 남긴다. 장기 AI·실제1939·화면·정상 정책 진행·DLC·저장·멀티플레이의 완료 여부는 구현 기록의 실제 관측으로만 판정한다. 이 문서의 채택은 커밋·푸시·게시 승인이 아니다.
