# ADR-0007: 15주 포트 위의 국토개발·표시·지리 참조 통합

결정일: 2026-11-08, Asia/Seoul. **소스 통합 결정**이며 실제 UI·효과·저장 검증의 통과 선언이 아니다. 후속 상태는 [구현·검증 기록](../implementation/2026-11-08-hok-upstream-content-port.md)을 따른다.

## 배경과 읽을 조건

사용자는 원본 업데이트의 문서화와 설명 뒤 전체 구현을 승인했고, 이어 실제 검증에 필요한 사용자 프로필·모드 선택·언어·자동저장·시험용 `.mod`의 임시 변경과 게임 실행을 별도로 승인했다. [계획](../plans/2026-11-08-hok-upstream-content-port-plan.md)의 최초 문서화 전용 상태는 역사로 보존한다. 커밋·푸시·외부 게시·업로드는 요청되지 않았다.

이 계층을 수정하거나 재생성할 때 [AGENTS.md](../../AGENTS.md), [ADR-0006](0006-korean-state-split-integration.md), [입력 안내](../upstream/hok-content-update-20261108/README.md), [새 잠금](../../tools/hok_upstream_content_lock.json)을 먼저 읽는다. 기존 15주 지도와 이전 source pins는 보존한다. 그림을 변경할 때는 [개발 자료 안내](../HOK_DEVELOPMENT_ARTIFACT_ARCHIVE.md)와 입력 안내의 원본 artwork 출처를 추가로 읽는다.

## 결정

1. donor `596b221bb994d93fce552d3ee1ba70fa9b5640f1`의 추가 검토36경로에서 **32개 출력을 선택**한다. 기존 경로13개와 신규 경로19개다. 원본 일반 CHI 수선·MON 도전 모듈은 RT56/기존 제외 정책을 유지하며, 연구망 한영2개는 이미 포트에 적용된 경남·함남 표시를 유지한다. 후보 수와 이식 출력 수를 구분한다.
2. 기존 47출력 분할을 새 계층의 명시적 조상으로 유지한다. 새 생성기는 동결 `compat_before`에 reference→civic→CNDP 순서로 필요한 차이만 적용한다. 기존 생성기에는 소유자별 최종화와 정확한 최종 해시일 때만 가능한 역투영을 연결한다. 알 수 없는 런타임 변경은 자동 덮어쓰지 않는다.
3. CNDP는 새 게임13개·체계 표식 없는 저장의 구형7개를 분리한다. 기존15주 포트의 구형 블록을 보존하며 저장 소급 이전·옛 완료 추정·기존 타이머 재시작은 추가하지 않는다. 주별 보상·비용·기간·민공 점유·소유/완전통제·취소·완료1회 계약은 계획의 최종 배분표를 따른다. 이는 9주 저장의 지도 마이그레이션이 아니다.
4. 숫자 종류를 문맥별로 이전한다. 강원 동해 province1148과 경남 state1148은 구분한다. 한국 해주 항구는 비해안13540/강원1144에서 해안13559/황해남917로 교정하고 해안요새3을 유지한다. 일본 중점의 해주 육상요새3도 실제917 부모와 통제 검사로 분리한다.
5. 한국 노선의 외국 지리는 RT56 실제 주를 사용한다. 난징11913의 부모는1114이므로 KCH 수도를1114로 정렬한다. 일본 본토의 신규 RT56 주1105–1107은 관련 조건·KJP 코어·이전 경로에 함께 연결한다. 동남아·호주·뉴질랜드는 실제 RT56 지역 집합을 사용하고 일반 일본/중국 트리의 비한국 수선은 호스트에 남긴다.
6. RT56 인도차이나는 FRA 종속 FRI 소유라는 별도 적응이 필요하다. 한국 중점의 기존 FRA 직할/VIN 종속 대안을 보존하고 FRA 종속 FRI가 해당9주를 모두 소유·완전통제하는 대안을 추가한다. 수락 선택지와 실제 효과 직전에 FRA/VIN/FRI의 종주·동일9주 소유·완전통제를 다시 검사한다. 요청 후 독립·종주국 변경·영토 상실 때 제3국 영토를 이전하지 않는 의도적 경계다. 기존 VIN 진입 대안보다 수락 검사가 엄격한 차이를 명시하며 실제 지연 수락은 별도 검증한다.
7. 해협식민지 수락은 RT56 Singapore의 state336을 ENG 소유·완전통제·MAL core일 때만 MAL로 이전한다. Penang은 이미 MAL 소유 Kedah914에 속하므로 해당 주 전체를 추가 이전하지 않는다. 새 core·다른 말레이 영토를 이 수락 효과에 복제하지 않는다.
8. 코민테른/SOV 연결은 donor의 짧은 중복 전역 정의 파일을 복사하지 않는다. **같은 상대 경로의 전체 호스트 파일**을 유지한 합성 출력2개를 사용한다. RT56 `common/scripted_effects/SOV_scripted_effects.txt`의 내전 정리에서918 endpoint4개만1152로, vanilla `common/script_constants/state_groups.txt`의 `comintern_starting_border`에 있는 옛 한국1028 한 항목만1152로 바꾼다. 다른 효과·상수·목록 순서·다른 국가 내용은 보존하고 실제 유효 정의의 유일성을 검사한다.
9. 두 전체 호스트 파일은 동일 경로 재정의에 필요한 로컬 병합 입력/출력이며 원본 RT56·게임 설치는 수정하지 않는다. 물리 원본·동결 사본·HOK delta·최종 출력의 해시와 공급자를 구분해 기록한다. HOK·RT56·Paradox의 기존 기여를 보존하며 새 저작·포괄 재배포 허가를 주장하지 않는다. 출시 준비 시 필요한 공개 크레딧·라이선스 고지는 별도 검토한다.
10. 시민사회 변수·조건·비용·효과·365일 표식은 유지하고 기존 공개 사건의 sync8곳 표시와 숫자 metadata29곳을 수리한다. 회복 사건 `.3/.13`의 같은 표시 위험은 원본에도 남아 있으므로 실제 화면 전까지 별도 미검증 후보로 둔다. 영어 채널은 영어로 작성하며 donor 일반판 번역의 한국어 English 채널 정책을 가져오지 않는다.

## 대안·한계

전체 donor 파일 교체, 외국 state 번호 일괄 치환, 새 `replace_path`, 지도 재분할, RT56의 전역 건설 상한 변경은 채택하지 않았다. CNDP 부지 전용3종의 보수적 여력 판정은 정확한 공유 슬롯 getter가 아니며 저점유20–24칸을 차단할 수 있는 기존 원본 제한을 남긴다.

원본 실행 기록은 포트 실행 증거로 쓰지 않는다. 기존 전체 검사11개 source/descriptor 부채의 핀도 이번 기능을 통과시키기 위해 갱신하거나 면제하지 않는다. 신규 소스 검사, 정상 UI, 강제 진단, 실제 기간 경과, 새 저장/이전 저장, 장기 AI·DLC·멀티플레이의 검증 상태는 구현 기록에서 구분한다.
