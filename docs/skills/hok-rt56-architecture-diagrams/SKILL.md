# HOK×RT56 구조 문서 도표

작업 모드와 권한은 [AGENTS.md](../../../AGENTS.md)를 먼저 적용한다. 이 스킬을 읽는 행위는 게임 코드·설정·입력 캐시 수정, 테스트·게임 실행·렌더러 설치를 승인하지 않는다. 기존 승인 범위에서 작업한다.

- 대상 도표를 찾기 전에 [구조 목차](../../architecture/README.md)를 읽는다. 도표 작성·갱신·미리보기·내보내기 전에는 [유지 안내](../../architecture/maintenance.md)를 읽고 원본·파생물·갱신 조건을 확인한다.
- Mermaid는 해당 주제 Markdown 한 곳을 편집 정본으로 삼는다. PNG/SVG·갤러리를 별도의 내용 원본으로 편집하지 않는다. 도표의 관계가 바뀌면 승인된 범위에서 해당 파생물·링크·manifest도 갱신하고 관계가 같으면 유지 이유를 기록한다.
- Mermaid 원본에 `theme: dark`를 명시한다. Markdown 이미지/미리보기·PNG/SVG·갤러리·확대/다운로드·내보내기도 항상 다크로 유지한다. OS·뷰어의 라이트 설정이나 과거 테마 저장값이 이를 해제하지 않게 하며 글자·선·도형 대비를 함께 확인한다.
- 실제 RT56+승인된 HOK delta를 설명한다. donor는 읽기 전용 출처, 일반 세계/공유 시스템은 RT56 소유다. 개발 생성기·잠금·역투영과 게임 실행 수명주기를 분리한다. 실제 영어·한국어와 번역 덮어쓰기 후보도 구분한다.
- 지리/주를 다루면 [주 참조 스킬](../hok-rt56-state-reference-review/SKILL.md), 표시/키를 다루면 [현지화 스킬](../hok-rt56-localisation-review/SKILL.md)과 [변경 영향 절차](../../HOK_CHANGE_COVERAGE_REVIEW.md)를 적용한다. 도표는 ADR·대응표·실제 소스·구현 기록을 찾아가는 안내이며 그 정본을 복제하지 않는다.
- helper·설치 도구·임시 HTML·프로필·초안·백업·검사 보고서는 먼저 정한 `C:/hoi/test/<task-or-run-id>/`에 둔다. 저장소에는 승인된 유지 문서·최종 다크 파생물·오프라인 갤러리·manifest만 둔다. source cache를 렌더 작업 공간으로 사용하지 않는다.
- 현재 구현/설계안/미확인과 소스 읽기/렌더링/표시 확인/게임 UI·효과·저장 검증을 따로 기록한다. UML 모양을 실제 엔진 클래스라고 설명하거나 Mermaid 배치를 실제 HOI4 좌표 검증으로 취급하지 않는다. 원본의 과거 실행을 포트 통과로 합산하지 않는다.
