## 범위와 기준선

사용자가 지정한 일반판 영어 번역을 재사용하되 두 모드의 차이를 반영하는 작업이다. 호환판의 기존 영어 현지화만 바꾸고 한국어·게임플레이·지도·그림·GUI·descriptor·의존성은 보존한다. 일반판 번역 저장소와 HOK donor, 설치된 RT56·게임·사용자 데이터는 읽기 전용이다. 커밋·푸시·Workshop 동작은 수행하지 않았다.

출력은 기존 36파일·2,743키다. 일반판의 일본 민주정 전용 파일 등은 추가하지 않는다. 2,691개 재사용 항목 전체의 문장별 재번역은 수행하지 않았으며, 기존 일반판 번역의 검토 이력을 출처로 사용한다. 다른 원문 25개와 전용 27개는 한국어·연결 스크립트·영어를 별도로 대조했다.

이전 일반판 주 이름을 무조건 복사하면 `STATE_1028` Hamgyeong이 RT56 Dalarna 등을 덮는다. 최종 출력은 기존 호환판 키만 보존한다. 주 이름은 `917` Hwanghae, `918` Hamgyeong, `919` Jeolla, `920` Gyeongsang, `1144` Gangwon, `1145` Chungcheong, `1146` Jeju Island, `1147` Tsushima다. 일반판 번역의 쓰시마 키 `STATE_1088`은 호환판의 `STATE_1147`로 명시적으로 대응한다. 승점 12개도 기존 호환판 `13535–13568` 범위의 해당 키에 기존 영어 이름을 연결했다. 지도 데이터나 persistent ID 자체를 바꾼 작업이 아니다.

만주 설명에 들어가는 `$STATE_328$`, `$STATE_941$`와 8주 지역 집합의 치환 순서·개수는 한국어와 같다. RagnaROK의 1938년 1월 1일·전 세계의 대(對)한국 전쟁·민주 김구 경로 고정과 신규 사건의 영국 주도 진영을 유지한다. 필리핀 형용사는 RT56 기존 영어의 `Philippine`을 따른다.

같은 상대 경로의 RT56 영어 파일 충돌은 없다. 공통 키 중 75개는 기존 한국어 호환판도 이미 소유한 한국 국가명·정당·장비·중점·로딩 팁·지명·난이도 문구다. [ADR-0004](../decisions/0004-hok-korean-content-priority.md)에 따라 그 HOK 표시 소유권만 유지하고 일반판 전용 MON/RAJ/JAP 등은 유입시키지 않는다. 전용 지명은 기존 승인된 지도 이주를 따른다. 파일 분류는 기존 `ADD`를 유지하며 원장의 별도 영어 열에 번역 출처와 이전/최종 해시를 추가했다.

## 생성기와 출처 보존

- `tools/hok_english_translation_lock.json`: 원본 37개 Git blob·SHA-256, 호환판 이전 출력 36개 해시, 변경 25키·전용 27키의 확정 영어, 제외 255키와 보존 한국어 해시를 고정한다.
- `docs/upstream/hok-english-20261020/source/`: 영어 출처 Git blob을 바이트 그대로 보존한다. `previous/`에는 기존 호환판 영어 채널의 정확한 이전 바이트를 보존한다. 출처 댓글·기여 주석과 기존 HOK/RT56 귀속을 유지하며 새 번역으로 사칭하지 않는다.
- `source_snapshot.py`의 영어 계층과 기존 focus/pruning/ID 생성기가 최종 영어 출력을 재현한다. 한국어 채널은 모든 파일이 기존 SHA-256과 같다. 생성 파일을 수동으로 수정하거나 언어 헤더·파일명·키 순서·줄바꿈 형식을 바꾸지 않았다.
- 기존 역사 검증은 최종 번역 바이트가 고정 출력과 정확히 일치할 때만 번역 전 바이트로 투영해 검사한다. 한국어 본문 일치·과거 출처 해시 검사를 삭제하거나 느슨하게 하지 않았다. 실제 영어 출력은 별도 전체 키·토큰·헤더·BOM 검사로 확인한다.
- 통합 원장 1,446행의 기존 출처 열을 유지하고 영어 36행의 추가 출처 열을 기록한다. 상속된 versionless 현지화 키 18개도 기존 정적 검사가 포함하도록 수정했다.
- 후속 커밋 준비에서 `.gitattributes`에 영어 원본/이전 출력 보관본의 `-text`, 입력 잠금의 LF, 생성 영어의 CRLF 기본값을 명시했다. 기존 영어 LF 예외 3개는 우선순위를 유지한다. Git의 자동 줄바꿈 변환이 출처·재현 해시를 바꾸지 않도록 하는 저장소 속성이며 런타임 본문 변경은 없다.
- 변경된 `KOR_anti_air_equipment_2` 행의 기존 줄 끝 공백 하나만 제거해 diff 공백 검사를 통과시켰다. 그 외 기존 파일 형식을 유지한다.

## 검증 상태

검증 근거와 일회성 스크립트의 저장 위치는 `C:/hoi/test/hok-rt56-english-20261020/`다. `source_snapshot.py --english-check`에서 전체 영어 36파일·2,743키, 재사용/변경/전용/제외 집합, BOM·헤더·버전·키 순서·보호 토큰·이스케이프 줄바꿈·한글 잔존·한국어 바이트 보존이 통과했다. 별도 비교에서도 확정 52개 값과 영어 원본 37개 Git blob, manifest 36개 행의 출처·최종 해시가 일치했다.

전체 검사·표적 검사 결과와 기존 실패는 아래에 별도로 기록한다. 최초 집계 실행은 도구 편집과 겹쳐 임시 ImportError가 포함됐으므로 완전한 사전 기준선으로 사용하지 않는다. 기존 호스트 오류는 변경 전 Git `bf2b997`의 검증 코드와 의존성을 메모리에서 읽어 `verify_inputs`/`verify_sources`만 실행한 `pristine-host-drift-baseline.json`으로 확인했다. RT56 railway 1개, 공용 파일 3개, 일본 파일 2개, GER history 1개 등 총 7개의 기존 핀 불일치이며 이 번역 작업에서 재고정하지 않았다.

추가 기존 실패는 civic 보존 목록의 `descriptor.mod` 바이트 핀이다. Git의 LF 바이트는 기대값 `AA150D6C…BE247`과 일치하고 실제 기존 checkout의 CRLF 바이트는 `D68DCE62…141CB`다. 줄바꿈을 제외한 본문은 완전히 같으며 이번 작업의 descriptor diff도 없다. `descriptor-baseline.json`에 따로 확인했다. 이 핀을 느슨하게 하거나 descriptor 인코딩을 바꾸지 않았으므로 전체 second-wave/civic 검사는 계속 여기서 중단된다.

`UNPROVEN`: 실제 영어 UI·동적 치환·지명·만주 조건·긴 사건의 표시, 현 플레이세트의 유효 우선순위, C0/C1 언어 모드 조합, 정상 진행·저장·DLC 조합·AI·멀티플레이. 기존 일반판 영어 서브모드는 호환판 영어 검증에서 꺼야 하며 현재 설정을 자동으로 바꾸지 않았다. 이 작업은 일반판의 GUI 변경이나 긴 사건 표시 개선을 가져오지 않는다. 새 런타임 호환성·출시 준비 완료를 주장하지 않는다.
