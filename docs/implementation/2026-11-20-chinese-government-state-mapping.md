# 2026-11-20 산둥 정부의 중국 본토 RT56 지리 대응

작성일: 2026-11-20, Asia/Seoul. **지역 대응 입력 채택·독립 소스 확인 완료 / 별도 승인된 강제 진단의 실제 효과·저장 대조와 제한된 UI 관측을 후속 기록**. 원본 업데이트와 구조 문서의 전체 도입을 승인한 구현 작업의 지리 대응을 기록한다. [최초 계획](../plans/2026-11-19-korean-democratic-support-intelligence-port-plan.md)의 문서화 전용 단계, 초기 소스 확인, 이후 승인된 실행을 구분한다. 전체 실행·복원 상태는 [전체 이식 기록](2026-11-20-korean-democratic-support-intelligence-port.md)을 따른다.

## 읽을 조건과 범위

산둥 출범·중국 재건 인정의 본토 집합, 핵심주, 후보 영토, 거점, 인접 확장 또는 관련 생성 입력을 수정하기 전에 이 문서와 [대응 JSON](../data/HOK_KOREAN_CHINESE_GOVERNMENT_RT56_MAPPING.json), [주 참조 스킬](../skills/hok-rt56-state-reference-review/SKILL.md), [변경 영향 절차](../HOK_CHANGE_COVERAGE_REVIEW.md)를 읽는다. 기존 지도 ID·한국 15주·한국 경로의 외국 지리 계약은 [ADR-0002](../decisions/0002-map-id-migration.md), [ADR-0006](../decisions/0006-korean-state-split-integration.md), [ADR-0007](../decisions/0007-november-content-integration.md)를 따른다. 한국 후속 정부와 일반 중국 콘텐츠의 소유권은 [ADR-0004](../decisions/0004-hok-korean-content-priority.md)를 따른다.

이 작업은 한국 경로가 쓰는 **지역 선택 입력**을 만든다. 실제 지도·state history·province 정의·국경·RT56 국가 이력을 바꾸지 않는다. 지원 비율·소유/통제 보호·초기 거점 정책·고정 보상과 DLC 요건을 지리 변환 명목으로 변경하지 않는다. 일반 CHI/JAP·군벌 콘텐츠 전체를 복사하지 않으며 Git·게시·업로드 작업도 하지 않는다.

## 제외·거점·국가 대상

만주는 원본 8주에 대응하는 RT56 **15주** `328,610,714,715,716,717,745,761,941–947`를 제외한다. host에서 분리된 Andong·Jiandao·Binjiang·Longjiang·Heihe·West Xing'an·Jinzhou를 빠뜨리지 않는다. 소유국이 CHI나 SND로 바뀌어도 이 제외는 유지한다. 섬·조차지 `326,524,591,728,729`도 제외한다. 중국 코어가 있다는 이유로 홍콩·타이완·하이난·광저우만·마카오를 다시 넣지 않는다.

출범 거점과 수도 선택은 **597 산둥 / 743 칭다오**를 유지한다. 현 합성 지도 비트맵에서 743의 육지 이웃은 597뿐이며 597↔1117 지난이 연결된다. 경계 픽셀 수는 743↔597이28, 597↔1117이89다. 743↔1117 직결은 없다. 따라서 보호된597을 건너뛰려고1117을 새 초기 거점으로 넣지 않는다. 적격597/743과 SND 소유의 적격 본토 전체를 먼저 선택하는 원본 정책에는 RT561117도 포함된다. 다른 donor는 기존 인접·지지도 예산 규칙을 따른다.

정식 대상은 기존 **CHI·PRC·SHX·GXC·YUN·XSM·SIK·GDC·SND·SIC·NXM·GSM·XIC·KHM·KUM·HBC**를 유지한다. 모두 현재 vanilla 국가 태그 등록과 RT56의 전용 country history 파일이 있다. RT56이 `common/country_tags` 전체를 replace하지 않으며, 포트의 새 KCH 태그를 만들 필요도 없다. RT56 SND 이력은 수도1117을 쓰고597/1117에 SND 소유 이력이 있다. 기록된 소스의 존재를 실제 플레이의 모든 DLC·시점에서 국가가 존재한다는 보장으로 확대하지 않는다. 원본 `exists=yes`, `is_dynamic_country=no`와 Japanese subject guard를 그대로 적용해야 한다.

601은 기존 KCH 재건의 캄 지역 코어 예외로 유지한다. 현재 TIB 소유이지만 TIB를 지원 대상으로 추가하지 않는다. 611·612·1122는 본토 코어 의도에 남지만 MEN을 16태그에 추가하지 않는다. KOR 소유 또는 통제 지역 보호, 전 주 단일 적격 controller 요구, 일본·일본 직속/2단계 종속국 보호를 완화하지 않는다.
