- 반복 착수 직전 **4월 3일 07시** 저장에서 포항제철 완료, 정치력 `560.492`, 두 사업 비활성을 확인했다. 강원 `1144`에는 저장에 직렬화된 석탄 추가분 `+9`가 생겼다. 착수 전의 해당 필드는 미기록이었으며, 주 history의 시작 석탄 `4`와 구분한다. 경상 `920`의 직렬화된 강철 추가분은 중점 완료 직후 `25`에서 첫 회차 완료 후 `34`로 늘었다. 두 값은 생산 보정 후 자원량과 구분한다. 외부 `profile/runs/live-probe-evidence/cycle1-save-analysis.json`에서 두 주와 한국 범위를 확인했으며 저장 해석 오류는 0건이었다.

### 반복 완료와 취소

- 두 번째 회차도 각각 90일 뒤 **7월 2일 24시**에 완료됐다. 사업 가용 민공은 총수 39가 같은 상태에서 다시 **6 → 24**로 돌아왔다. **7월 4일 13시** 두 사업을 세 번째 착수할 때 화면의 정치력은 **620 → 595 → 570**으로 줄었다.
- 시험 도구로 강원 `1144`의 소유권과 완전 통제를 함께 넘겼다. **7월 6일 24시** 강원 사업만 취소됐고 포항은 유지됐다. 민공 총수 39에서 사업 가용 민공은 **6 → 15**, 정치력은 **572.185 → 573.386**이었다. 이어 경상 `920`의 소유권과 완전 통제를 넘기자 **7월 8일 24시** 포항도 취소됐다. 민공 총수 37에서 사업 가용 민공은 **15 → 24**, 정치력은 **574.587 → 575.788**이었다. 양쪽 모두 점유한 민공 9개를 반환했고 정치력은 일일 증가분 `1.201`만 늘었다.
- 첫 회차, 두 번째 회차, 취소 후의 텍스트 저장을 대조했다. 직렬화된 강원 석탄 추가분은 **9 → 18 → 18**, 경상 강철 추가분은 **34 → 43 → 43**이었다. 두 번째 완료에서도 각각 +9가 누적됐고 취소에는 자원 보상이 없었다. 취소 후 저장은 두 대상 주의 일본 소유와 양쪽 사업 비활성을 기록한다. 세 저장에서 포항제철 완료는 유지됐고 대조 주 `525`, `1029`, `1030`에 추가 자원 필드가 나타나지 않았다. 원본 파일명과 해시는 외부 `saves/*.copy.json`, 비교는 `cycle1-cycle2-cancel-raw-comparison.json`에 있다.
- `profile/runs/probe/logs/game.log`에 위 전환이 기록됐다. `setup.log`는 새 생산 디시전 2개를 등록했고 `error.log`에서 두 ID·파일명·아이콘·포항제철 중점 ID·시험 이름공간과 일치하는 오류가 발견되지 않았다. 시험 저장은 파일 이름 변경 오류로 `_temp.hoi4`에 남았으나 실제로 재로드해 두 사업의 상태를 확인했다. PRC 고문 재로드 오류 18건은 [과거 RT56 단독 대조](../audits/2026-09-22-korean-update-runtime.md)에서도 재현된 별도 현상이다. 이번 단독 대조는 새 게임만 진행했다.

### 한국어 표시와 신아리랑

- C1의 `자원 전망` 범주에서 **강원도 탄광 확장**과 **포항 제철소 확장**의 이름·설명·아이콘을 확인했다. 새 게임에서 두 사업 모두 건설 II·민공·정치력 조건이 충족되지 않아 비활성이었고, 포항에는 포항제철 중점 조건도 표시됐다. 툴팁은 두 사업의 90일·민공 9개·자원 +9와 각 대상 주를 표시했다.
- 설정의 음향 탭에서 음악 플레이어를 열어 기본 사운드트랙의 **신아리랑 (Sinarirang)**을 재생했다. 곡 길이 `02:19`와 경과 시간 `00:02 → 00:18 → 00:47`을 관측했다. 같은 곡을 `00:47`에서 일시정지한 뒤 재개하자 `00:49`로 진행했다. 같은 HOI4 프로세스와 Windows 출력 세션의 정규화 피크 중앙값은 재생 `0.260630`, 일시정지 `0.002833`이었다. `audio/c1-sinarirang-playing-peak.json`과 `audio/c1-sinarirang-paused-peak.json`에 측정값을 보존했다.
- 실제 재생을 포함한 C1, Probe, R0의 보존 로그를 실행별 20개씩 비교했다. `Sinarirang` 및 샘플레이트 관련 경고와 범위 내 디시전·GFX·툴팁 오류는 검색 결과 0건이었다. 로그 검색식과 집계는 `audio/archived-log-review.json`에 있다. [이전 실행의 샘플레이트 경고](../audits/2026-09-23-second-wave-runtime.md)와 구분한다. 현재 실행에도 이식 범위 밖의 엔진·스크립트 오류가 기록됐다.
- 시험 전후 `runtime-source-fingerprints-*.json`과 `runtime-language-*.json`은 각각 바이트가 일치했다. 범위 출력 8개, 설치 RT56·vanilla 입력 13개, 실행 파일, 음원 등록 및 대상 주 history, RT56 한국어 번역 manifest `3192804258057474440`과 descriptor를 대조했다.

정치력 24/25와 가용 민공 8/9의 정확한 경계, 정상 연구와 중점 진행, 통제만 상실한 경우와 항복에 따른 개별 취소, 구버전 저장·DLC 조합·장기 AI·멀티플레이는 이번 시험에 포함하지 않았다.
