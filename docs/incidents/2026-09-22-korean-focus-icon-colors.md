# 한국 신규 중점·국민정신 배경색 구분

작업일: 2026-09-22. 상태: **배경색 구현 완료 / 정적 검증 통과 / 89개 전수 정적 시각 검수 / 런타임 미실행**.

## 범위와 변경 의도

사용자가 [색상 계획](../HOK_KOREAN_FOCUS_ICON_COLOR_PLAN.md)의 구현을 요청하고, 기존 합성 방식에서 배경 부분만 조정하는 방식을 선택했다. 대상은 [앞선 아이콘 구현](2026-09-22-korean-focus-icons.md)의 신규 중점 60개와 국민정신 정의 29개다. 이번 작업은 정책 가지의 시각적 구분을 위한 후속 개발이며, 호환성 복구나 밸런스 변경이 아니다.

중심 그림·금속 테두리·장식·기존 I·II·III 단계 표식을 유지하면서 원판·방패 등 배경의 색상만 조정한다. 기존 원작 공산·파시즘·비동맹 중점과 국민정신은 제외한다. 정치색은 해당 가지에 고정하고, 공통 분야색은 정책 용도에 고정한다. 현재 집권 이념에 따른 이미지 분기나 외국 협정 수혜국의 이념 조건을 추가하지 않는다.

게임 효과·보상·AI·좌표·선행조건·기간·국민정신 획득 및 교체 조건·현지화·저장 식별자·GFX 이름과 참조는 변경 대상이 아니다. 앞선 구현의 미커밋 코드 변경은 그대로 보존한다.

## 원인과 배정

`CONFIRMED`: 신규 중점 60개에 같은 `Focus Backgrounds/Circle with Ribbon2.png`를 선택하여 붉은 원판이 반복됐다. 원인은 공통 배경의 디자인 선택이다. 다운로드나 DDS 변환이 배경을 공산주의 이미지로 바꿨다는 근거는 없다. 정책별 중심 소재는 보존하고 배경의 계열색을 구분한다.

이 수량은 최종 색상 분류 대상의 수다. 중점 60개·국민정신 22개의 DDS 82개를 수정했다. 기존 해군 국민정신 4개와 공군 국민정신 3개는 이미 의도한 군종색을 사용하므로 바이트 그대로 유지했다. 89개의 변경 전·후 해시를 모두 대조했다.

민주 경로의 농촌교육·의료·의용군·경제 협정은 민주색을 따른다. 군종 소속 학교·연구·정비는 해당 군종색을 따른다. 경상 수출조선 지원은 지역 산업 가지의 조선소 건설 정책이므로 산업색으로 배정했다. 공산 짙은 적색, 파시즘 갈색·차콜, 비동맹 밝은 회색·은색은 앞으로 적용할 정치색 기준으로만 남긴다.

29개 국민정신 정의에는 강화 단계와 외국 협정 수혜국용 정의가 포함된다. 한국에서 동시에 29개를 표시하는 변경이 아니다. 연결된 중점과 국민정신은 같은 중심 소재와 계열색을 공유하고, 실제 강화 관계는 기존 단계 표식으로 구분한다.

## 제작·재현 기록

기존 합성기의 배경 레이어를 분리해 색조를 조정한 뒤 기존 중심 소재와 장식을 다시 합성한다. 완성 DDS 전체에 일괄 색조 필터를 적용하지 않는다. 게임용 출력은 기존 파일명·경로·크기·알파·DDS 형식을 유지한다.

설치된 1.19.3의 `interface/goals.gfx:9580` 및 `interface/ideas.gfx:619`에서 해당 sprite 구조를 확인했다. 바닐라 `focus_generic_electrification.dds`는 100×88, `generic_production_bonus.dds`는 60×68이며 모두 비압축 BGRA32·알파 형식이다. 기존 HOK 출력과 광택 참조는 이 규격을 사용하며 이번 색상 작업에서는 GFX를 수정하지 않는다.

원본은 Ultimate HOI4 GFX 커밋 `3626dc83c8573d6603fa497138090b04b64a15ba`의 기존 채택 소재다. 원문 CREDITS의 적용 범위·기여자 표시는 [크레딧 기록](../HOK_KOREAN_FOCUS_ICON_CREDITS.md)을 유지한다. 배경의 색상 가공을 원본 소재의 신규 저작으로 표시하지 않는다.

- 대상별 원본·색상 분류·가공·최종 해시: [기존 경로의 매니페스트](../data/HOK_KOREAN_FOCUS_ICON_MANIFEST.json).
- 새 색상 비교 미리보기: [배경색 비교 갤러리](../assets/korean-focus-icon-colors/index.html). 게임 캡처가 아닌 정적 비교다.
- 파생 배경 10개와 마스크 10개: `docs/assets/korean-focus-icon-colors/backgrounds/`. RGB 기준·음영 계산식·마스크 조건은 매니페스트의 `color_revision`에, 항목별 경로와 해시는 `color_background`에 보존했다. `pre_color_sha256`은 직전 DDS 해시다.
- 로컬 재현·검증: `.local-artifacts/korean-focus-icon-colors/`의 `before/`, `reproduction/`, `prepare-colors.ps1`, `BackgroundColors.cs`, `build-colors.ps1`, `foreground/`, `pixel-validation.json`, `reference-validation.json`, `independent-validation.json`. 원본 부품·합성기·배치 recipe는 기존 `.local-artifacts/korean-focus-icons/`를 사용했다. 로컬 작업 파일은 Git 제외 대상이며 게임 패키지에 넣지 않았다.
- 최초 원본 합성기를 별도 경로로 재실행하여 직전 DDS **89개 모두 동일 해시**로 재현한 뒤 배경색을 바꿨다. 실제 변경은 82개, 그대로 유지한 출력은 7개다.

문서에 따른 이번 작업의 게임 실행 승인은 없으므로 런타임을 실행하지 않았다. 앞선 아이콘 구현의 1936 UI 표본은 이전 색상의 기록이며, 새 색상의 가독성·광택·국민정신 표시를 입증하지 않는다. 정적 결과를 런타임 호환성 또는 세이브·멀티플레이 검증으로 확대하지 않는다.

합성 전 중심 소재와 단계 배지의 색·알파·배치는 그대로다. 반투명 소재 경계와 기존 알파 248의 배지 바탕은 아래 배경색에 따라 최종 합성 픽셀이 달라질 수 있다. 별도 전경 렌더와 비교했을 때 알파 255로 반올림된 전경 픽셀 및 배지 내부의 최대 RGB 차이는 채널당 1이었다. 이를 완성 DDS의 모든 중심 픽셀이 바이트 동일하다는 주장으로 확대하지 않는다. 배경 원본 마스크 밖 픽셀과 최종 DDS 알파는 정확히 동일하다.

기존 작업 트리 변경을 보존하며 이 작업의 배경색·가공 기록만 추가한다. 커밋·푸시·업로드·Workshop 메타데이터 변경·외부 계정 작업은 수행하지 않는다. 원작 `2898629778`과 현재 descriptor의 후속 항목 ID `3793992662`를 구분하며, 어느 쪽도 이번 작업의 게시 대상으로 사용하지 않는다.
